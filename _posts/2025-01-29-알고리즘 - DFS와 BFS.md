# DFS와 BFS 기초

그래프를 탐색하는 두 가지 기본 방법, **깊이 우선 탐색(DFS)**과 **너비 우선 탐색(BFS)**을 알아본다.  
두 방법 모두 그래프의 모든 정점을 방문하는 것이 목표지만, **어떤 순서로 방문하느냐**에 차이가 있다.

---

## 그래프 표현하기

그래프를 코드로 표현하는 가장 간단한 방법은 **인접 리스트(adjacency list)**다.  
각 정점마다 연결된 정점들의 목록을 리스트로 저장한다.

```python
graph = [[] for _ in range(n+1)]   # 1번부터 n번 정점까지

# 간선 추가 (무방향)
graph[a].append(b)
graph[b].append(a)
```

**인접 리스트**의 장점은 메모리를 $$O(V+E)$$만 사용하고, 특정 정점의 이웃을 빠르게 조회할 수 있다는 것이다.

---

## DFS (Depth-First Search)

DFS는 **한 우물을 깊게 판다**는 전략으로, 가능한 한 깊이 들어가다가 더 이상 갈 곳이 없으면 되돌아온다.

### 재귀를 이용한 DFS

재귀 함수로 구현하면 코드가 매우 간결하다.

```python
def dfs(u):
    visited[u] = True
    print(u, end=' ')           # 방문한 정점 처리
    for v in graph[u]:
        if not visited[v]:
            dfs(v)
```

**주의**: 재귀 깊이가 너무 깊어지면 파이썬의 재귀 한도(기본 1000)를 초과할 수 있다.  
그럴 때는 `sys.setrecursionlimit(1000000)`으로 늘리거나, 반복문(스택) 버전을 사용한다.

### 스택을 이용한 반복 DFS

```python
def dfs_iter(start):
    stack = [start]
    while stack:
        u = stack.pop()
        if visited[u]:
            continue
        visited[u] = True
        print(u, end=' ')
        # 스택은 LIFO이므로, 원하는 방문 순서를 위해 역순으로 넣는다
        for v in reversed(graph[u]):
            if not visited[v]:
                stack.append(v)
```

**언제 DFS를 사용할까?**
- 그래프의 모든 정점을 방문해야 할 때
- 경로의 존재 여부, 연결 요소 찾기
- 백트래킹이 필요한 문제 (모든 경우 탐색)

---

## BFS (Breadth-First Search)

BFS는 **가까운 곳부터 퍼져나간다**는 전략으로, 시작점으로부터 **거리가 가까운 순서**로 방문한다.  
큐(queue)를 사용하여 구현한다.

```python
from collections import deque

def bfs(start):
    q = deque([start])
    visited[start] = True
    while q:
        u = q.popleft()
        print(u, end=' ')
        for v in graph[u]:
            if not visited[v]:
                visited[v] = True
                q.append(v)
```

BFS의 가장 큰 특징은 **무가중치 그래프에서 시작점부터 각 정점까지의 최단 거리**를 구할 수 있다는 점이다.

```python
def bfs_shortest(start):
    q = deque([start])
    dist = [-1] * (n+1)
    dist[start] = 0
    while q:
        u = q.popleft()
        for v in graph[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

**언제 BFS를 사용할까?**
- 최단 거리 문제 (간선 가중치가 없거나 모두 동일할 때)
- "몇 단계 만에 도달하는가?" 같은 문제
- 물이 퍼져나가는 시뮬레이션 (다중 시작점 가능)

## 2차원 격자에서의 DFS/BFS

많은 문제가 2차원 배열(격자) 형태로 주어진다.  
이때는 상하좌우 4방향(또는 8방향)으로 이동하며 탐색한다.

### 방향 벡터

```python
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]
```

### BFS 템플릿 (격자 최단거리)

```python
from collections import deque

def bfs_grid(start_x, start_y):
    n, m = len(grid), len(grid[0])
    dist = [[-1]*m for _ in range(n)]
    q = deque([(start_x, start_y)])
    dist[start_x][start_y] = 0
    while q:
        x, y = q.popleft()
        for i in range(4):
            nx, ny = x + dx[i], y + dy[i]
            if 0 <= nx < n and 0 <= ny < m:
                if grid[nx][ny] == 0 and dist[nx][ny] == -1:   # 통과 가능한 칸
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))
    return dist
```

**격자 BFS에서 주의할 점**
- 경계 체크 (`0 <= nx < n and 0 <= ny < m`)는 항상 먼저 한다.
- 방문 여부는 큐에 넣을 때 체크해야 중복을 막을 수 있다.

## 간단한 실전 예제

### 1. 연결 요소 개수 세기 (DFS/BFS)

그래프가 몇 개의 연결된 덩어리로 이루어져 있는지 구하는 문제다.  
방문하지 않은 정점을 시작점으로 DFS/BFS를 수행하고, 수행 횟수를 센다.

```python
def count_components():
    visited = [False]*(n+1)
    def dfs(u):
        visited[u] = True
        for v in graph[u]:
            if not visited[v]:
                dfs(v)
    cnt = 0
    for i in range(1, n+1):
        if not visited[i]:
            cnt += 1
            dfs(i)
    return cnt
```

### 2. 미로 최단거리 (BFS)

0은 지나갈 수 있는 칸, 1은 벽이라고 할 때, (0,0)에서 (n-1,m-1)까지의 최소 이동 횟수를 구한다.

```python
def shortest_path(grid):
    n, m = len(grid), len(grid[0])
    dist = [[-1]*m for _ in range(n)]
    q = deque([(0,0)])
    dist[0][0] = 0
    while q:
        x, y = q.popleft()
        if (x, y) == (n-1, m-1):
            return dist[x][y]
        for i in range(4):
            nx, ny = x+dx[i], y+dy[i]
            if 0 <= nx < n and 0 <= ny < m:
                if grid[nx][ny] == 0 and dist[nx][ny] == -1:
                    dist[nx][ny] = dist[x][y] + 1
                    q.append((nx, ny))
    return -1   # 도달 불가능
```

### 3. 토마토 (다중 시작점 BFS)

익은 토마토(1)가 여러 개 있을 때, 모든 토마토가 익는 최소 일수를 구한다.  
처음에 모든 익은 토마토를 큐에 넣고 동시에 퍼뜨린다.

```python
def tomato_bfs(box):
    n, m = len(box), len(box[0])
    q = deque()
    for i in range(n):
        for j in range(m):
            if box[i][j] == 1:
                q.append((i, j))
    while q:
        x, y = q.popleft()
        for i in range(4):
            nx, ny = x+dx[i], y+dy[i]
            if 0 <= nx < n and 0 <= ny < m:
                if box[nx][ny] == 0:
                    box[nx][ny] = box[x][y] + 1
                    q.append((nx, ny))
    # 결과 계산 (모두 익었는지, 최대 일수)
```

## DFS vs BFS 선택 기준

| 상황 | 추천 |
|------|------|
| 최단 거리 구하기 | BFS |
| 모든 경우를 탐색하며 가지치기 필요 | DFS (백트래킹) |
| 그래프가 매우 깊고 재귀 깊이 우려 | BFS 또는 반복 DFS |
| 연결 요소 찾기 | 둘 다 가능 |
| 퍼져나가는 과정(시뮬레이션) | BFS |
| 경로의 존재 여부만 확인 | 둘 다 가능 |

---

## 시간 복잡도와 메모리

- 인접 리스트를 사용하면 DFS와 BFS 모두 $$O(V+E)$$ 시간에 동작한다.
- 공간 복잡도: 방문 배열 $$O(V)$$ + 큐/스택 $$O(V)$$.

---

## 실전 팁

- **입력 속도**: `import sys; input = sys.stdin.readline`을 사용한다.
- **재귀 한도**: DFS를 재귀로 구현할 땐 `sys.setrecursionlimit(10**6)`을 설정한다.
- **방문 시점**: BFS는 큐에 넣을 때 방문 표시를 해야 중복 삽입을 막을 수 있다.
- **경계 검사**: 격자 문제에서는 범위 체크를 가장 먼저 한다.

---

## 마무리

DFS와 BFS는 그래프 탐색의 기본이며, 대부분의 코딩 테스트 문제에서 필수적으로 등장한다.  
처음에는 재귀 DFS와 큐 BFS를 반복해서 연습하고, 격자 형태의 문제를 통해 익숙해지는 것이 좋다.  
두 방법 모두 기본 템플릿을 암기한 후, 문제에 맞게 상태를 추가하거나 변형하는 능력을 키워 나가자.
