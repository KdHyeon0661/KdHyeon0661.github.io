# 그리디 알고리즘

## 그리디란?

그리디(Greedy)는 **매 순간 가장 좋아 보이는 선택**을 하는 알고리즘입니다.  
한 번 선택한 것은 되돌리지 않고, 그 선택이 전체 문제의 최적해로 이어지기를 기대합니다.

텍스트 다이어그램으로 표현하면:

```
[문제] → [현재 상태] → [가장 좋은 선택] → [다음 상태] → 반복
```

### 필수 조건

그리디가 올바른 답을 보장하려면 다음 두 조건을 만족해야 합니다.

| 조건 | 의미 |
|------|------|
| 탐욕 선택 속성 | 지금의 최적 선택이 전체 최적해의 일부가 될 수 있음 |
| 최적 부분 구조 | 문제의 최적해가 부분 문제의 최적해로 구성됨 |

대부분의 그리디 문제는 **정렬**과 함께 사용됩니다.  
“정렬한 뒤 한 번 순회하면서 조건에 따라 선택한다”는 패턴이 가장 흔합니다.

---

## 그리디가 통하는 경우와 그렇지 않은 경우

### 통하는 예: 동전 거스름돈 (한국 화폐)

한국 동전은 500원, 100원, 50원, 10원처럼 **큰 단위가 작은 단위의 배수**입니다.  
이 경우 가장 큰 동전부터 최대한 사용하는 그리디가 최적해를 보장합니다.

### 통하지 않는 예: 동전 {1, 3, 4}

목표 금액 6원을 만들 때  
- 그리디: 4 + 1 + 1 = 3개  
- 실제 최적: 3 + 3 = 2개  

이처럼 단위가 배수 관계가 아니면 그리디가 실패할 수 있습니다.

## 대표 문제 풀이

### 동전 0 (BOJ 11047)

**문제**  
동전 종류가 주어지고, 목표 금액을 만들 때 필요한 최소 동전 개수를 구합니다.  
(단, 동전 단위는 배수 관계)

**풀이**  
가장 큰 동전부터 차례로 사용합니다.

```python
n, k = map(int, input().split())
coins = [int(input()) for _ in range(n)]
coins.sort(reverse=True)

cnt = 0
for c in coins:
    if k == 0:
        break
    cnt += k // c
    k %= c
print(cnt)
```

### ATM (BOJ 11399)

**문제**  
사람마다 인출 시간이 다릅니다. 줄을 적절히 서서 모든 사람의 대기 시간 합을 최소화하세요.

**풀이**  
시간이 적게 걸리는 사람부터 앞에 세웁니다.  
누적합의 합을 구하면 됩니다.

```python
n = int(input())
times = sorted(map(int, input().split()))

acc = 0
total = 0
for t in times:
    acc += t
    total += acc
print(total)
```

### 회의실 배정 (BOJ 1931)

**문제**  
회의 시작 시간과 끝 시간이 주어집니다. 회의가 겹치지 않게 최대한 많은 회의를 배정하세요.

**풀이**  
종료 시간이 빠른 회의부터 선택합니다.  
종료 시간이 같다면 시작 시간이 빠른 순서로 정렬합니다.

```python
n = int(input())
meetings = [tuple(map(int, input().split())) for _ in range(n)]
meetings.sort(key=lambda x: (x[1], x[0]))

cnt = 0
last_end = 0
for start, end in meetings:
    if start >= last_end:
        cnt += 1
        last_end = end
print(cnt)
```

### 잃어버린 괄호 (BOJ 1541)

**문제**  
식에 괄호를 적절히 쳐서 결과를 최소로 만드세요.

**풀이**  
`-` 뒤에 오는 숫자들을 모두 더한 후 빼면 최소가 됩니다.  
즉, 첫 번째 `-` 이후의 모든 숫자는 괄호로 묶어 뺍니다.

```python
expr = input().strip()
parts = expr.split('-')
# 첫 번째 부분은 모두 더함
total = sum(map(int, parts[0].split('+')))
# 이후 부분은 각각 합해서 빼줌
for part in parts[1:]:
    total -= sum(map(int, part.split('+')))
print(total)
```

### 주유소 (BOJ 13305)

**문제**  
도시마다 기름 가격이 다릅니다. 왼쪽에서 오른쪽으로 이동할 때 최소 비용으로 기름을 채우는 방법을 구하세요.

**풀이**  
지나온 도시 중 가장 싼 가격으로 다음 도시까지의 거리를 채웁니다.

```python
n = int(input())
dist = list(map(int, input().split()))
price = list(map(int, input().split()))

min_price = price[0]
cost = 0
for i in range(n - 1):
    if price[i] < min_price:
        min_price = price[i]
    cost += min_price * dist[i]
print(cost)
```

## 그리디 구현 패턴

### 정렬 + 순회

가장 기본적인 패턴입니다.  
데이터를 정렬한 뒤, 조건을 만족하는지 확인하며 선택합니다.

```python
data.sort(key=...)
for x in data:
    if condition(x):
        take(x)
    else:
        skip(x)
```

### 힙(우선순위 큐) 활용

“가장 작은(또는 큰) 것을 계속 선택”해야 할 때 사용합니다.  
파이썬에서는 `heapq`를 사용합니다.

```python
import heapq
heap = []
for item in items:
    heapq.heappush(heap, priority(item))
    if len(heap) > limit:
        heapq.heappop(heap)   # 필요 없는 것 제거
```

### 스위핑 (Sweeping)

구간이나 이벤트를 정렬한 뒤, 한쪽 방향으로 이동하며 상태를 관리합니다.

## 그리디 vs DP

그리디는 **빠르지만 항상 맞지는 않습니다**.  
반면 DP는 **항상 최적해를 보장하지만 느릴 수 있습니다**.

| 기준 | 그리디 | DP |
|------|--------|-----|
| 속도 | 빠름 (보통 O(n log n)) | 상대적으로 느림 |
| 최적 보장 | 조건에 따라 다름 | 항상 보장 |
| 사용 시기 | 최적 부분 구조 + 탐욕 선택 속성 만족 | 위 조건이 불확실할 때 |

그리디가 통하는 대표적인 조건은 “현재 선택이 미래 선택에 영향을 주지 않음” 또는 “작은 문제로 분할 가능”입니다.

## 마무리

그리디는 문제를 푸는 가장 직관적인 방법 중 하나입니다.  
- “정렬 후 순서대로 선택”이 80% 이상을 차지합니다.  
- 반례를 생각해보는 것이 중요합니다.  
- 만약 반례가 떠오르면 DP나 다른 방법을 고려하세요.

실전에서는 다음 순서로 접근해 보세요.

1. 문제를 읽고 “현재 상태에서 최선의 선택”이 무엇인지 생각합니다.
2. 그 선택이 전체 최적해로 이어질 수 있는지 직관적으로 확인합니다.
3. 정렬 기준을 정하고 한 번 순회하며 선택합니다.
4. 예제를 넣어 테스트하고, 반례가 있다면 다른 방법을 찾습니다.

대표 문제들을 직접 풀어보면 그리디에 대한 감각이 빠르게 익숙해집니다.
