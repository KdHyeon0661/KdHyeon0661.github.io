# 웹 서버 기초와 데이터베이스 운영

## 웹 서버 기초 (Nginx / Apache)

웹 서버는 클라이언트 요청을 받아 HTML, 이미지, PHP 등 동적 콘텐츠를 반환하는 핵심 인프라다.  
초중급 수준에서는 **가상호스트(VirtualHost)** 설정, **SSL 인증서 적용**, **PHP-FPM 연동** 및 **리버스 프록시** 기본 개념을 익히는 것이 목표다.

---

## Nginx 가상호스트 설정

### 설치

```bash
sudo apt update
sudo apt install nginx
```

### 사이트 설정 구조

- `/etc/nginx/sites-available/` : 설정 파일 저장 위치
- `/etc/nginx/sites-enabled/` : 활성화된 설정 링크
- `sites-available`에 설정을 만들고 `sites-enabled`에 심볼릭 링크를 걸어 관리한다.

### 기본 가상호스트 예시

`/etc/nginx/sites-available/example.com`:

```nginx
server {
    listen 80;
    server_name example.com www.example.com;
    root /var/www/example.com;
    index index.html index.php;

    location / {
        try_files $uri $uri/ =404;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
    }
}
```

### 사이트 활성화

```bash
sudo ln -s /etc/nginx/sites-available/example.com /etc/nginx/sites-enabled/
sudo nginx -t              # 설정 검증
sudo systemctl reload nginx
```

## Apache 가상호스트 설정

### 설치

```bash
sudo apt install apache2
```

### 사이트 설정 구조

- `/etc/apache2/sites-available/` : 설정 파일
- `/etc/apache2/sites-enabled/` : 활성화 링크
- `a2ensite`, `a2dissite` 명령으로 활성화/비활성화 관리

### 기본 가상호스트 예시

`/etc/apache2/sites-available/example.com.conf`:

```apache
<VirtualHost *:80>
    ServerName example.com
    ServerAlias www.example.com
    DocumentRoot /var/www/example.com

    <Directory /var/www/example.com>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/example.com_error.log
    CustomLog ${APACHE_LOG_DIR}/example.com_access.log combined
</VirtualHost>
```

### 사이트 활성화 및 PHP 연동

```bash
sudo a2ensite example.com.conf
sudo a2enmod rewrite         # 필요시
sudo systemctl reload apache2
```

PHP 연동은 별도로 `libapache2-mod-php` 패키지를 설치하면 자동 처리된다.

## Let’s Encrypt로 SSL 인증서 적용

Let’s Encrypt는 무료 SSL 인증서를 제공하는 서비스다.  
Certbot 도구를 사용하면 인증서 발급과 웹 서버 설정을 자동화할 수 있다.

### Certbot 설치

```bash
sudo apt install certbot python3-certbot-nginx   # Nginx
# 또는
sudo apt install certbot python3-certbot-apache  # Apache
```

### 인증서 발급 (Nginx)

```bash
sudo certbot --nginx -d example.com -d www.example.com
```

인증서 발급 후 `/etc/letsencrypt/live/example.com/`에 인증서 파일이 생성되고, Nginx 설정에 SSL 관련 지시어가 자동 추가된다.

### 자동 갱신

Certbot은 systemd 타이머로 주기적 갱신을 처리한다.

```bash
sudo certbot renew --dry-run   # 갱신 테스트
```

## 리버스 프록시 기본 개념

리버스 프록시는 클라이언트 요청을 받아 내부 서버(예: Node.js, Python 애플리케이션)로 전달하는 중계 서버다.  
보안, 로드 밸런싱, SSL 종단 등의 이점이 있다.

### Nginx 리버스 프록시 예시

```nginx
server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

- `proxy_pass` : 요청을 전달할 내부 주소
- `proxy_set_header` : 백엔드에 전달할 헤더 (원본 IP 보존 등)

## LEMP / LAMP 스택 기초

| 스택 | 구성 요소 |
|------|----------|
| LEMP | Linux + Nginx + MySQL(MariaDB) + PHP |
| LAMP | Linux + Apache + MySQL(MariaDB) + PHP |

### PHP-FPM 연동 (Nginx)

PHP-FPM은 PHP 요청을 처리하는 FastCGI 데몬이다.

```bash
sudo apt install php-fpm php-mysql
```

Nginx 설정에서 위 예시와 같이 `fastcgi_pass`로 PHP-FPM 소켓을 지정한다.

### Apache에서 PHP

Apache에서는 `libapache2-mod-php` 패키지로 PHP를 모듈로 연동하거나, `mod_proxy_fcgi`로 PHP-FPM을 사용할 수 있다.

## 데이터베이스 기본 운영 (MariaDB/MySQL)

데이터베이스 서버는 애플리케이션의 데이터를 저장하고 관리한다.  
초중급 수준에서는 **설치, 보안 설정, 사용자 관리, 간단한 백업/복원**을 중점적으로 다룬다.

---

## MariaDB 설치 및 기본 보안

### 설치

```bash
sudo apt install mariadb-server
```

### 보안 설정

설치 후 기본 보안 스크립트를 실행한다.

```bash
sudo mysql_secure_installation
```

질문에 따라:
- root 비밀번호 설정
- 익명 사용자 제거
- 원격 root 로그인 제한
- test 데이터베이스 제거
- 권한 테이블 리로드

### 서비스 관리

```bash
sudo systemctl status mariadb
sudo systemctl enable mariadb
```

---

## 사용자 관리

### root 접속

```bash
sudo mysql -u root -p
```

### 데이터베이스 생성

```sql
CREATE DATABASE myapp;
```

### 사용자 생성 및 권한 부여

```sql
CREATE USER 'myuser'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON myapp.* TO 'myuser'@'localhost';
FLUSH PRIVILEGES;
```

### 권한 확인

```sql
SHOW GRANTS FOR 'myuser'@'localhost';
```

## 간단한 백업과 복원

### 백업 (mysqldump)

```bash
# 전체 데이터베이스 백업
sudo mysqldump -u root -p --all-databases > /backup/all_databases.sql

# 특정 데이터베이스만
sudo mysqldump -u root -p myapp > /backup/myapp.sql
```

### 복원

```bash
sudo mysql -u root -p myapp < /backup/myapp.sql
```

### 백업 자동화 (cron 예시)

```crontab
0 2 * * * root mysqldump -u root -p'password' myapp > /backup/myapp_$(date +\%F).sql
```

## 문제 해결 기본

| 증상 | 확인 방법 |
|------|----------|
| 웹 서버 접속 안 됨 | `systemctl status nginx`, `nginx -t`, 방화벽 확인 |
| PHP 페이지 깨짐 | `php -v`, PHP-FPM 상태 확인, `tail -f /var/log/nginx/error.log` |
| 데이터베이스 접속 실패 | `systemctl status mariadb`, `mysql -u user -p -h localhost` 테스트 |
| 백업 파일 크기 이상 | `ls -lh /backup` 확인, `mysqlcheck`로 데이터베이스 점검 |

## 결론

웹 서버와 데이터베이스는 대부분의 애플리케이션에서 함께 사용되는 핵심 구성 요소다.

- **웹 서버**는 Nginx 또는 Apache를 선택하여 가상호스트 설정, SSL 인증서 적용, 리버스 프록시 구성, PHP-FPM 연동을 통해 다양한 애플리케이션을 서비스할 수 있다.
- **데이터베이스**는 MariaDB/MySQL을 기본으로 설치 후 보안 설정, 사용자 관리, 정기적인 백업을 통해 데이터를 안전하게 유지한다.

초중급 수준에서는 **설정 파일의 위치와 구조, 서비스 제어 명령, 간단한 백업/복원 절차**를 익히는 것이 중요하다. 이러한 기초를 바탕으로 점진적으로 성능 튜닝, 복제, 클러스터링 등 고급 주제로 확장할 수 있다.
