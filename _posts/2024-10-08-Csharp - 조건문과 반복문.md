# C# 조건문과 반복문

프로그래밍에서 조건문과 반복문은 프로그램이 스스로 결정을 내리고 동일한 작업을 반복적으로 수행하도록 만드는 핵심 제어 구조입니다. 단순히 코드를 순차적으로 실행하는 것을 넘어, 데이터의 상태와 사용자 입력에 따라 복잡한 비즈니스 로직을 표현하는 기본 도구입니다.

---

## 조건문

조건문은 주어진 논리식의 참과 거짓을 평가하여 프로그램의 실행 경로를 분기합니다. 조건문이 얼마나 명확하게 작성되었는지에 따라 코드의 가독성과 유지보수성이 크게 달라집니다.

### if 문과 가드 클로즈

`if` 문은 가장 기본적인 조건 분기 구조입니다. 하지만 실제 비즈니스 로직에서는 예외 처리와 검증 로직이 중첩되면서 코드의 들여쓰기 깊이가 깊어지는 문제가 발생합니다.

이를 해결하는 방법이 **가드 클로즈(Guard Clauses)** 패턴입니다. 유효하지 않은 조건을 메서드 상단에서 미리 검사하여 일찍 반환함으로써 본문 코드의 들여쓰기 깊이를 줄입니다.

```csharp
public string GetUserStatus(User user)
{
    if (user is null) return "사용자 정보 없음";
    if (!user.IsActive) return "비활성 사용자";
    if (user.Subscription?.IsValid != true) return "구독 만료";
    
    return "정상 사용자";
}
```

가드 클로즈를 적용하면 메서드의 핵심 로직이 평탄하게 유지되어 읽기 쉬워집니다.

### switch 문과 패턴 매칭

전통적인 `switch` 문은 각 `case` 블록 끝에 `break`, `return`, `goto` 등이 필요했습니다. 최신 C#에서는 이를 확장하여 객체의 속성과 형태를 검사하는 **패턴 매칭(Pattern Matching)** 을 제공합니다.

**switch 식**은 값을 반환하는 간결한 형태입니다.

```csharp
public string GetWeatherDescription(WeatherData data) => data switch
{
    { Temperature: > 30, Humidity: > 80 } => "무더운 날씨",
    { Temperature: > 25 } => "따뜻한 날씨",
    { Temperature: <= 0 } => "추운 날씨",
    _ => "보통 날씨"
};
```

**튜플 패턴 매칭**을 사용하면 여러 값을 동시에 평가할 수 있습니다.

```csharp
public string GetQuadrant(int x, int y) => (x, y) switch
{
    (> 0, > 0) => "제1사분면",
    (< 0, > 0) => "제2사분면",
    (< 0, < 0) => "제3사분면",
    (> 0, < 0) => "제4사분면",
    (0, 0) => "원점",
    _ => "축 위"
};
```

패턴 매칭은 복잡한 조건 분기를 명확하게 표현할 수 있게 해줍니다.

## 반복문

반복문은 동일한 연산을 컬렉션의 모든 요소에 적용하거나 특정 조건을 만족할 때까지 작업을 반복합니다. 반복문의 선택과 사용 방식은 알고리즘의 시간 복잡도와 메모리 효율성에 직접적인 영향을 미칩니다.

### for 문과 알고리즘 복잡도

`for` 문은 반복 횟수가 명확하거나 인덱스가 필요할 때 사용합니다. 초기화, 조건 검사, 증감식을 한 곳에서 관리할 수 있어 루프의 흐름을 파악하기 쉽습니다.

```csharp
for (int i = 0; i < 10; i++)
{
    Console.WriteLine($"Index: {i}");
}
```

크기가 $$N$$인 배열을 중첩 루프로 순회할 경우 시간 복잡도는 $$O(N^2)$$이 됩니다. 반복문의 중첩 깊이가 성능에 미치는 영향을 고려해야 합니다.

### while 문과 do-while 문

`while` 문은 조건이 참인 동안 반복합니다. 파일 읽기, 네트워크 대기 등 종료 시점을 예측하기 어려운 경우에 적합합니다.

```csharp
string line;
while ((line = reader.ReadLine()) != null)
{
    Process(line);
}
```

`do-while` 문은 조건 검사를 루프 끝에서 수행하므로, 본문이 최소 한 번은 반드시 실행됨을 보장합니다. 사용자 입력 검증 등에 유용합니다.

```csharp
int choice;
do
{
    Console.Write("선택 (1.시작 / 2.종료): ");
} while (!int.TryParse(Console.ReadLine(), out choice) || (choice != 1 && choice != 2));
```

### foreach 문과 이터레이터

`foreach` 문은 컬렉션의 모든 요소를 안전하게 순회합니다. 인덱스 범위를 벗어날 위험이 없으며, 컴파일러가 내부적으로 이터레이터 패턴을 사용하여 코드를 변환합니다.

```text
[foreach의 내부 동작 구조]

IEnumerable 객체 ── GetEnumerator() 호출 ──> IEnumerator (열거자 반환)
                                              │
    ┌──────────────────────────────────────────┘
    │
    ├── 1. MoveNext() 호출 (다음 요소 존재 여부 확인)
    ├── 2. Current 속성 접근 (현재 요소 반환)
    └── 3. MoveNext()가 false일 때까지 반복
```

```csharp
var numbers = new List<int> { 1, 2, 3, 4, 5 };
foreach (var num in numbers)
{
    Console.WriteLine(num);
}
```

### yield return을 활용한 지연 실행

`yield return`은 대용량 데이터를 처리할 때 메모리 효율을 높입니다. 모든 데이터를 한 번에 메모리에 올리지 않고, 호출자가 값을 요청할 때마다 하나씩 계산하여 반환합니다.

```csharp
public IEnumerable<int> GetEvenNumbers(int max)
{
    for (int i = 0; i <= max; i++)
    {
        if (i % 2 == 0) yield return i;
    }
}
```

이 방식은 지연 실행(Lazy Evaluation)이라고 하며, 컬렉션이 매우 클 때 불필요한 메모리 할당을 방지합니다.

## 실무 제어 흐름 설계

### 역순 순회로 안전한 요소 삭제

`foreach` 문으로 리스트를 순회하면서 요소를 삭제하면 예외가 발생합니다. 조건에 따라 요소를 제거해야 할 때는 끝 인덱스부터 역순으로 `for` 문을 사용합니다.

```csharp
for (int i = numbers.Count - 1; i >= 0; i--)
{
    if (numbers[i] % 2 == 0)
    {
        numbers.RemoveAt(i);
    }
}
```

역순으로 순회하면 삭제로 인한 인덱스 밀림 현상을 피할 수 있습니다.

### 배열과 리스트의 성능 특성

배열과 리스트는 모두 인덱스를 통한 빠른 접근이 가능하지만, 크기 변경에 따른 비용이 다릅니다.

- **배열**: 고정 크기. 크기를 초과할 수 없습니다. 요소 접근은 $$O(1)$$입니다.
- **List<T>**: 동적 크기. 내부적으로 배열을 관리합니다. 요소를 추가할 때 내부 배열의 용량이 부족하면 더 큰 배열을 새로 할당하고 기존 요소를 복사합니다. 이 재할당 작업은 용량을 $$N$$에서 $$2N$$으로 늘릴 때 $$O(N)$$ 비용이 발생합니다.

```csharp
// List<T>의 용량 관리 예시
var list = new List<int>();
for (int i = 0; i < 1000; i++)
{
    list.Add(i); // 필요 시 내부 배열 재할당
}
```

반복적으로 요소를 추가하는 경우, 초기 용량을 미리 지정하면 재할당 횟수를 줄일 수 있습니다.

```csharp
var list = new List<int>(1000); // 초기 용량을 1000으로 설정
```

## 마무리

C#의 조건문과 반복문은 단순한 문법 요소를 넘어, 개발자의 논리를 코드로 표현하는 핵심 도구입니다.

- `if` 문에서 가드 클로즈를 활용해 중첩을 줄이고 가독성을 높입니다.
- 패턴 매칭을 통해 복잡한 조건 분기를 간결하게 표현합니다.
- 반복문 선택 시 `for`, `foreach`, `while` 각각의 적합한 사용처를 구분합니다.
- `yield return`을 활용해 대용량 데이터를 메모리 효율적으로 처리합니다.
- 컬렉션 수정 시 역순 순회를 사용해 안전성을 확보합니다.
- 배열과 리스트의 성능 특성을 이해하고, 리스트 사용 시 초기 용량을 고려합니다.

제어 흐름을 명확하게 설계하는 능력은 유지보수성이 높고 성능이 좋은 애플리케이션을 만드는 기초가 됩니다.
