# 재귀

재귀는 함수가 자기 자신을 호출하여 문제를 해결하는 기법이다. 문제를 같은 형태의 더 작은 하위 문제로 나누고, 더 이상 나눌 수 없는 가장 작은 문제(기저 조건)에서 답을 구한 뒤 결과를 결합한다.

## 기본 구조

재귀 함수는 반드시 두 가지 요소를 갖춰야 한다.

- **기저 조건(Base case)**: 더 이상 재귀 호출 없이 바로 답을 반환하는 조건
- **재귀 호출(Recursive case)**: 문제를 더 작은 크기로 축소하여 자기 자신을 다시 호출

```python
def recursive(state):
    # 기저 조건
    if is_base(state):
        return base_value(state)
    
    # 하위 문제로 분할
    sub_states = split(state)
    
    # 하위 문제 해결 (재귀 호출)
    sub_results = [recursive(s) for s in sub_states]
    
    # 결과 결합
    return combine(sub_results)
```

재귀 함수가 실행될 때마다 호출 스택에 프레임이 쌓이고, 기저 조건에 도달하면 역순으로 결과를 반환하며 스택이 해제된다.

## 재귀의 대표 패턴

### 1. 분할 정복

문제를 반으로 나누어 해결한 후 결과를 합친다. 병합 정렬, 빠른 거듭제곱 등이 대표적이다.

**빠른 거듭제곱**

$$a^b$$를 구할 때 $$b$$가 짝수이면 $$(a^{b/2})^2$$, 홀수이면 $$a \times a^{b-1}$$로 계산한다.

```python
def power(a, b):
    if b == 0:
        return 1
    half = power(a, b // 2)
    result = half * half
    if b % 2 == 1:
        result *= a
    return result
```

시간 복잡도는 $$O(\log b)$$로, 단순 반복문보다 효율적이다.

**병합 정렬**

배열을 반으로 나누고 각각 정렬한 후 병합한다.

```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)

def merge(left, right):
    result = []
    i = j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

시간 복잡도는 $$O(n \log n)$$, 공간 복잡도는 $$O(n)$$이다.

### 2. 백트래킹

가능한 모든 경우를 탐색하되, 조건에 맞지 않으면 되돌아간다. 조합, 순열 생성이 대표적이다.

**조합 생성**

```python
def combinations(arr, k):
    result = []
    
    def backtrack(start, path):
        if len(path) == k:
            result.append(path[:])
            return
        for i in range(start, len(arr)):
            path.append(arr[i])
            backtrack(i + 1, path)
            path.pop()
    
    backtrack(0, [])
    return result
```

**순열 생성**

```python
def permutations(arr):
    result = []
    used = [False] * len(arr)
    
    def backtrack(path):
        if len(path) == len(arr):
            result.append(path[:])
            return
        for i in range(len(arr)):
            if used[i]:
                continue
            used[i] = True
            path.append(arr[i])
            backtrack(path)
            path.pop()
            used[i] = False
    
    backtrack([])
    return result
```

두 방식 모두 상태를 변경한 후 재귀 호출, 호출이 끝나면 원래 상태로 되돌리는 패턴을 사용한다.

### 3. 트리 순회

이진 트리를 전위, 중위, 후위 순서로 탐색하는 것은 재귀로 자연스럽게 표현된다.

```python
class Node:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def preorder(node):
    if not node:
        return
    print(node.val, end=' ')
    preorder(node.left)
    preorder(node.right)

def inorder(node):
    if not node:
        return
    inorder(node.left)
    print(node.val, end=' ')
    inorder(node.right)

def postorder(node):
    if not node:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.val, end=' ')
```

각 순회의 차이는 재귀 호출과 출력 순서에 있다.

## 재귀의 성능과 한계

### 시간 복잡도 분석

재귀의 시간 복잡도는 점화식으로 표현할 수 있다.

- **병합 정렬**: $$T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n \log n)$$
- **이진 탐색**: $$T(n) = T(n/2) + O(1) \Rightarrow T(n) = O(\log n)$$
- **피보나치(순수 재귀)**: $$T(n) = T(n-1) + T(n-2) + O(1) \Rightarrow T(n) = O(2^n)$$

### 공간 복잡도

재귀는 호출 스택을 사용하므로, 최대 재귀 깊이에 비례한 공간을 차지한다. 깊이가 $$n$$인 경우 공간 복잡도는 $$O(n)$$이다.

### 파이썬에서의 주의점

파이썬은 기본 재귀 깊이 제한이 약 1000이다. 깊은 재귀가 필요한 경우 다음 방법을 고려한다.

```python
import sys
sys.setrecursionlimit(10**6)  # 깊이 제한 증가
```

깊이 10만 이상이 예상되면 재귀 대신 반복문이나 명시적 스택을 사용하는 것이 안전하다.

### 메모이제이션

중복 계산이 많은 재귀(피보나치 등)는 메모이제이션으로 최적화할 수 있다.

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n):
    if n < 2:
        return n
    return fib(n-1) + fib(n-2)
```

`lru_cache`는 함수의 결과를 캐시하여 이미 계산한 값은 다시 계산하지 않는다. 시간 복잡도는 $$O(n)$$으로 줄어든다.

## 대표 문제와 풀이

### 하노이 탑 (BOJ 11729)

원판을 옮기는 순서를 재귀로 표현한다. n개의 원판을 A에서 C로 옮기려면 n-1개를 A에서 B로, 가장 큰 원판을 A에서 C로, n-1개를 B에서 C로 옮기면 된다.

```python
def hanoi(n, start, mid, end):
    if n == 1:
        print(start, end)
        return
    hanoi(n-1, start, end, mid)
    print(start, end)
    hanoi(n-1, mid, start, end)

n = int(input())
print(2**n - 1)  # 총 이동 횟수
hanoi(n, 1, 2, 3)
```

### 별 찍기 - 10 (BOJ 2447)

프랙탈 패턴을 재귀로 생성한다. n×n 패턴은 n/3×n/3 패턴을 조합해 만든다.

```python
def star(n):
    if n == 1:
        return ['*']
    prev = star(n // 3)
    result = []
    for s in prev:
        result.append(s * 3)
    for s in prev:
        result.append(s + ' ' * (n // 3) + s)
    for s in prev:
        result.append(s * 3)
    return result

n = int(input())
print('\n'.join(star(n)))
```

### Z (BOJ 1074)

2^n × 2^n 배열을 Z 모양으로 방문할 때 (r, c)가 몇 번째 방문인지 구한다. 4등분하여 각 사분면의 크기를 계산하고 재귀적으로 접근한다.

```python
def z(n, r, c):
    if n == 0:
        return 0
    half = 2 ** (n - 1)
    if r < half and c < half:
        return z(n - 1, r, c)
    if r < half and c >= half:
        return half * half + z(n - 1, r, c - half)
    if r >= half and c < half:
        return 2 * half * half + z(n - 1, r - half, c)
    return 3 * half * half + z(n - 1, r - half, c - half)
```

## 재귀 vs 반복

| 비교 항목 | 재귀 | 반복 |
|---------|------|------|
| 가독성 | 분할 정복, 트리 탐색에 직관적 | 단순 반복 작업에 직관적 |
| 성능 | 함수 호출 오버헤드 존재 | 오버헤드가 작음 |
| 메모리 | 호출 스택 사용 | 추가 메모리 거의 없음 |
| 깊이 제한 | 언어별 제한 존재 | 없음 |

재귀가 자연스러운 문제(트리 탐색, 분할 정복, 백트래킹)는 재귀로 작성하고, 깊이가 깊거나 성능이 중요한 경우 반복문으로 변환하는 것이 좋다.

## 마무리

재귀는 문제를 같은 형태의 작은 문제로 나누어 해결하는 강력한 도구다. 기저 조건의 정확성과 상태 복원이 가장 중요하며, 필요에 따라 메모이제이션이나 반복 변환을 적절히 활용해야 한다. 다음 기준으로 재귀 사용을 결정하면 된다.

- 문제가 자연스럽게 하위 문제로 분할되는가?
- 재귀 깊이가 예상되는 입력 크기에서 안전한가?
- 중복 계산이 발생한다면 메모이제이션으로 해결 가능한가?

이 기준을 염두에 두고, 재귀를 적재적소에 활용할 수 있도록 연습하는 것이 중요하다.
