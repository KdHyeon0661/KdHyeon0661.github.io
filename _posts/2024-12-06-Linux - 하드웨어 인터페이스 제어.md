# 하드웨어 인터페이스 제어 (USB, 블루투스, 전원관리)

## 전체 구성 개요

리눅스에서 하드웨어 장치(USB, 블루투스, 전원)는 여러 계층의 소프트웨어가 협력하여 관리됩니다.

* **커널** : 장치를 감지하고 `uevent`(추가/제거/변경)을 발생시킵니다.
* **systemd-udevd** : uevent를 받아 `/dev` 노드를 생성하고 권한·심볼릭 링크를 설정하며, 규칙에 따라 프로그램을 실행합니다.
* **BlueZ** : 블루투스 스택으로, `bluetoothctl` 같은 도구로 제어합니다.
* **upower** : 배터리, 어댑터 상태를 D-Bus로 제공합니다.
* **acpid** : 전원 버튼, 노트북 뚜껑 등 ACPI 이벤트를 스크립트로 처리합니다.
* **systemd-logind** : 기본적으로 전원 키/뚜껑 정책을 관리하므로, acpid와 함께 사용할 때 충돌에 주의해야 합니다.
* **전력 최적화 도구** : TLP, powertop, cpupower 등으로 CPU, USB, PCIe, SATA 절전 설정을 조정합니다.

## udev — 장치 이벤트 자동화

udev는 장치가 연결/해제될 때 커널 이벤트를 받아 /dev 디렉터리에 장치 파일을 만들고, 특정 규칙에 따라 프로그램을 실행하거나 심볼릭 링크를 생성합니다.

### 규칙 파일 위치

* 배포판 기본 제공: `/usr/lib/udev/rules.d/*.rules`
* 사용자/관리자 추가: `/etc/udev/rules.d/*.rules` (우선순위가 더 높음, 번호가 큰 파일이 나중 적용)

### 규칙 문법 간단 예시

```udev
# /etc/udev/rules.d/70-myusb.rules
ACTION=="add", SUBSYSTEM=="block", KERNEL=="sd?1", ENV{ID_FS_UUID}=="1234-5678", SYMLINK+="backup_disk", MODE="0660", GROUP="backup"
```

* `ACTION=="add"` : 장치가 추가될 때
* `KERNEL=="sd?1"` : 파티션 1번만 (전체 디스크가 아닌)
* `ENV{ID_FS_UUID}` : 파일시스템 UUID (udev가 이미 읽어 놓은 값)
* `SYMLINK+="backup_disk"` : `/dev/backup_disk` 심볼릭 링크 생성
* `MODE`, `GROUP` : 권한과 그룹 설정

### 장치 정보 확인 및 디버깅

```bash
# 특정 장치의 속성 확인
udevadm info -a -n /dev/sdb1

# 실시간 이벤트 모니터링
udevadm monitor --udev --kernel --property

# 규칙 테스트 (실제 실행은 안 함)
sudo udevadm test /sys/block/sdb
```

### udev → systemd 연계 (장시간 작업 위임)

무거운 작업(백업, 마운트 등)은 udev의 `RUN`에서 직접 실행하기보다는 systemd 서비스로 떠넘기는 것이 안전합니다.

**udev 규칙**:
```udev
ACTION=="add", SUBSYSTEM=="block", ENV{ID_FS_UUID}=="1234-5678", \
  ENV{SYSTEMD_WANTS}="usb-backup@%E{ID_FS_UUID}.service"
```

**systemd 템플릿 서비스** (`/etc/systemd/system/usb-backup@.service`):
```ini
[Unit]
Description=USB backup for %i
After=dev-disk-by\x2duuid-%i.device

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/usb-backup.sh %i
```
이렇게 하면 장치가 의존성으로 보장되며, 중복 실행을 피할 수 있습니다.

## 블루투스 (BlueZ)

### 기본 명령어

```bash
# 블루투스 서비스 시작
sudo systemctl enable --now bluetooth

# rfkill로 무선 차단 상태 확인/해제
rfkill list
sudo rfkill unblock bluetooth
```

### 블루투스ctl 대화형 사용

```text
bluetoothctl
[bluetooth]# power on
[bluetooth]# agent on
[bluetooth]# scan on                # 주변 기기 검색
[bluetooth]# pair XX:XX:XX:XX:XX:XX
[bluetooth]# trust XX:XX:XX:XX:XX:XX
[bluetooth]# connect XX:XX:XX:XX:XX:XX
```

### 오디오 프로파일

* **A2DP** : 고음질 음악 재생 (마이크 없음)
* **HSP/HFP** : 통화용 (마이크 포함, 음질 낮음)

사운드 설정 GUI 또는 `pactl`(PulseAudio), `wpctl`(PipeWire)로 프로파일을 전환할 수 있습니다.

### 문제 확인

```bash
dmesg | grep -i bt   # 커널 메시지
journalctl -u bluetooth -f
```

## upower — 배터리 및 전원 상태

`upower`는 배터리, AC 어댑터, UPS 등의 정보를 제공합니다.

```bash
upower -e                         # 장치 경로 목록
upower -i /org/freedesktop/UPower/devices/battery_BAT0
upower -d                         # 전체 정보 출력
upower --monitor                  # 실시간 이벤트
```

출력 주요 항목:
* `state` : charging / discharging
* `percentage` : 잔량 (%)
* `time to empty` / `time to full` : 예상 시간
* `energy`, `energy-full-design` : 에너지(Wh)

배터리 잔량 알림 스크립트 예시:

```bash
#!/bin/bash
bat=$(upower -e | grep battery | head -1)
pct=$(upower -i "$bat" | awk '/percentage/ {gsub("%","",$2); print $2}')
state=$(upower -i "$bat" | awk -F: '/state/ {gsub(/ /,"",$2); print $2}')
if [[ "$state" == "discharging" && "$pct" -le 20 ]]; then
    notify-send "배터리 부족" "잔량 ${pct}%"
fi
```

## acpid — 전원 이벤트 처리

acpid는 ACPI 이벤트(전원 버튼, 노트북 뚜껑 닫힘 등)를 감지하고 설정된 스크립트를 실행합니다.

### 설치 및 서비스

```bash
sudo apt install acpid
sudo systemctl enable --now acpid
tail -f /var/log/acpid   # 이벤트 로그 확인
```

### 이벤트 처리 예시

**이벤트 파일** `/etc/acpi/events/powerbtn`:
```ini
event=button/power
action=/etc/acpi/powerbtn.sh
```

**실행 스크립트** `/etc/acpi/powerbtn.sh`:
```bash
#!/bin/bash
logger "Power button pressed, shutdown"
systemctl poweroff
```

**뚜껑 닫힘** `/etc/acpi/events/lid`:
```ini
event=button/lid.*
action=/etc/acpi/lid.sh
```

**스크립트** `/etc/acpi/lid.sh`:
```bash
#!/bin/bash
state=$(awk '{print $2}' /proc/acpi/button/lid/*/state 2>/dev/null | head -1)
if [[ "$state" == "closed" ]]; then
    systemctl suspend
fi
```

### systemd-logind와 충돌 방지

systemd-logind도 기본적으로 전원 버튼, 뚜껑 닫힘을 처리하므로 acpid와 중복 실행될 수 있습니다.  
원하는 이벤트만 acpid에서 처리하려면 logind 설정에서 해당 이벤트를 `ignore`로 변경합니다.

```ini
# /etc/systemd/logind.conf
HandlePowerKey=ignore
HandleLidSwitch=ignore
```
```bash
sudo systemctl restart systemd-logind
```

## 전력 최적화

### CPU 주파수 거버너

```bash
# 패키지 설치 (Debian/Ubuntu)
sudo apt install linux-tools-common linux-tools-$(uname -r)

# 현재 거버너 확인
cpupower frequency-info

# 배터리 모드에서는 powersave로 설정
sudo cpupower frequency-set -g powersave

# AC 전원에서는 performance 또는 schedutil
sudo cpupower frequency-set -g schedutil
```

### USB AutoSuspend

```bash
# 특정 USB 장치 절전 활성화
echo auto | sudo tee /sys/bus/usb/devices/1-2/power/control

# 현재 상태 확인
cat /sys/bus/usb/devices/*/power/control
```
마우스, 키보드 등은 auto로 설정 시 절전 후 깨어나지 않을 수 있으므로 `on`으로 유지하거나 화이트리스트로 관리해야 합니다.

### PCIe ASPM, SATA ALPM

* **ASPM** : PCIe 링크 절전 (커널 파라미터 `pcie_aspm=force`로 강제 활성화 가능, 하드웨어 지원 확인 필요)
* **ALPM** : SATA 링크 절전 (`/sys/class/scsi_host/host*/link_power_management_policy`)
  ```bash
  echo med_power_with_dipm | sudo tee /sys/class/scsi_host/host0/link_power_management_policy
  ```

### TLP (자동 전력 관리 도구)

TLP는 노트북에서 AC/배터리 전환에 따라 다양한 전력 설정을 자동으로 적용합니다.

```bash
sudo apt install tlp
sudo systemctl enable --now tlp
sudo tlp-stat -s               # 상태 확인
```
설정 파일 `/etc/tlp.conf`에서 CPU 거버너, USB 자동 서스펜드, Wi-Fi 전력 관리 등을 조정할 수 있습니다.

### powertop

```bash
sudo powertop --auto-tune      # 즉시 추천 절전 설정 적용 (일시적)
```
재부팅 시 초기화되므로, 영구 적용하려면 TLP 등에 설정을 옮기는 것이 좋습니다.

## 슬립/하이버네이트

### 용어
* **suspend (to RAM)** : 메모리 유지, 빠른 복귀 (S3 / s2idle)
* **hibernate (to disk)** : 메모리 내용을 스왑에 저장 후 전원 차단 (S4)
* **hybrid-sleep** : RAM 유지 + 디스크에 저장 → 정전에도 복구 가능

### 사용

```bash
systemctl suspend
systemctl hibernate
systemctl hybrid-sleep
```

### 하이버네이트 설정

1. 스왑 파티션이나 스왑 파일이 RAM 크기 이상인지 확인.
2. 커널 명령줄에 `resume=` 파라미터 추가 (스왑 장치의 UUID 또는 파티션)
   ```bash
   # /etc/default/grub
   GRUB_CMDLINE_LINUX="resume=UUID=xxxx-xxxx"
   ```
   `sudo update-grub`
3. initramfs 업데이트: `sudo update-initramfs -u`

### s2idle vs deep (최신 노트북)

```bash
cat /sys/power/mem_sleep
# 출력: [s2idle] deep
```
* `s2idle` : 더 빠르지만 전력 소모가 상대적으로 큼
* `deep` : 더 저전력 (S3)이나 하드웨어 호환성에 따라 깨어남 문제가 있을 수 있음

## 통합 예제: USB 삽입 → 자동 백업

### udev 규칙
```udev
# /etc/udev/rules.d/80-backup-stick.rules
ACTION=="add", SUBSYSTEM=="block", ENV{ID_FS_UUID}=="ABCD-1234", \
  ENV{SYSTEMD_WANTS}="backup-stick@%E{ID_FS_UUID}.service"
```

### systemd 템플릿 서비스
```ini
# /etc/systemd/system/backup-stick@.service
[Unit]
Description=Backup for %i
After=dev-disk-by\x2duuid-%i.device

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/backup-stick.sh %i
```

### 백업 스크립트
```bash
#!/bin/bash
uuid="$1"
dev="/dev/disk/by-uuid/$uuid"
mnt="/mnt/backup"

mount -o nosuid,nodev,noexec "$dev" "$mnt"
rsync -a /home/user/Documents/ "$mnt/backup/"
umount "$mnt"
```

이 구조는 udev가 장치를 감지하면 systemd 서비스를 실행하며, 장치 의존성이 보장되고 백업이 완료될 때까지 서비스가 실행됩니다.

## 결론

리눅스에서 USB, 블루투스, 전원 관리는 여러 도구와 서비스가 계층적으로 협력하는 구조입니다.

* **udev** : 장치 연결 시 자동으로 규칙을 실행하여 심볼릭 링크 생성, 권한 설정, 서비스 트리거 등을 할 수 있습니다. 장시간 작업은 systemd 서비스로 위임하는 것이 안정적입니다.
* **블루투스** : `bluetoothctl`로 페어링과 연결을 관리하며, 오디오 프로파일에 따라 사운드 설정이 필요할 수 있습니다.
* **upower** : 배터리 잔량, 충전 상태를 제공하며, 스크립트에서 경고나 자동 조치에 활용할 수 있습니다.
* **acpid** : 전원 버튼, 뚜껑 닫힘 등 ACPI 이벤트를 처리하며, systemd-logind와 중복을 피하기 위해 적절히 `ignore` 설정이 필요할 수 있습니다.
* **전력 최적화** : CPU 거버너, USB 자동 절전, TLP 등을 활용하여 배터리 사용 시간을 늘릴 수 있습니다.
* **슬립/하이버네이트** : `systemctl` 명령으로 제어하며, 하이버네이트는 스왑 공간과 커널 파라미터 설정이 필요합니다.

이러한 기능들을 조합하면 USB 삽입 시 자동 백업, 배터리 부족 알림, 전원 버튼으로 절전 등 사용자 환경에 맞는 자동화를 구성할 수 있습니다. 각 구성 요소의 역할을 이해하고, 필요에 따라 설정을 조정하면 하드웨어 제어를 효율적으로 할 수 있습니다.
