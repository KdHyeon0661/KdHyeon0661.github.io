# 메일 서버 기초 (Postfix, Dovecot)

## 왜 메일 서버를 알아야 하는가

리눅스 서버에서 시스템 알림, 로그 전송, 사용자 간 메시지 등을 처리하려면 메일 전송 기능이 필요하다. 초중급 수준에서는 **로컬 메일 전송**이나 **외부 메일 릴레이** 설정 정도를 익히는 것이 목표다. 이 글에서는 가장 널리 사용되는 **Postfix**(MTA)와 **Dovecot**(MDA/IMAP)을 중심으로 메일 서버의 기본 개념과 구성을 다룬다.

---

## 메일 관련 핵심 개념

### SMTP (Simple Mail Transfer Protocol)
- 메일을 **전송**하는 프로토콜 (서버 간, 클라이언트→서버)
- 포트: 25 (서버 간), 587 (클라이언트 제출), 465 (SSL)
- Postfix는 SMTP 서버 역할

### IMAP (Internet Message Access Protocol)
- 메일을 **읽고 관리**하는 프로토콜
- 메일은 서버에 보관되며, 여러 클라이언트에서 동기화 가능
- 포트: 143 (일반), 993 (SSL)
- Dovecot이 IMAP 서버 역할

### MTA (Mail Transfer Agent) / MDA (Mail Delivery Agent)
- MTA: 메일 전송 담당 (Postfix, Sendmail)
- MDA: 메일을 사용자 메일박스에 전달 (Dovecot, procmail)

## Postfix 설치와 기본 설정

### 설치

```bash
sudo apt update
sudo apt install postfix
```

설치 중 물음에 따라 **인터넷 사이트**를 선택하고, 시스템 메일 이름(예: `mail.example.com`)을 입력한다.

### 기본 구성 파일 (`/etc/postfix/main.cf`)

```conf
# myhostname = 서버의 완전한 도메인 이름
myhostname = mail.example.com

# mydomain = 도메인 이름
mydomain = example.com

# myorigin = 보내는 메일의 @ 뒤에 붙을 도메인
myorigin = $mydomain

# inet_interfaces = 수신할 인터페이스 (all 또는 특정 IP)
inet_interfaces = all

# mydestination = 로컬로 취급할 도메인 (이 도메인으로 오는 메일은 로컬로 배달)
mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain

# home_mailbox = 사용자 메일박스 형식 (Maildir 권장)
home_mailbox = Maildir/
```

### 로컬 메일 전송 테스트

```bash
echo "테스트 메일" | mail -s "제목" root
tail -f /var/log/mail.log
```

`mail` 명령이 없다면 `mailutils` 패키지를 설치한다.

### 외부 메일 릴레이 (예: Gmail)

메일을 외부 SMTP 서버로 전달하려면 `/etc/postfix/main.cf`에 다음을 추가한다.

```conf
relayhost = [smtp.gmail.com]:587
smtp_use_tls = yes
smtp_sasl_auth_enable = yes
smtp_sasl_password_maps = hash:/etc/postfix/sasl_passwd
smtp_sasl_security_options = noanonymous
```

`sasl_passwd` 파일:
```
[smtp.gmail.com]:587  username@gmail.com:app-password
```
```bash
sudo chmod 600 /etc/postfix/sasl_passwd
sudo postmap /etc/postfix/sasl_passwd
sudo systemctl reload postfix
```

## Dovecot: IMAP 서버

Dovecot은 사용자가 IMAP으로 메일에 접근할 수 있게 해준다.

### 설치 및 기본 설정

```bash
sudo apt install dovecot-core dovecot-imapd
```

기본 설정 파일은 `/etc/dovecot/dovecot.conf`와 `/etc/dovecot/conf.d/` 아래에 있다.

### 간단한 설정 (`/etc/dovecot/conf.d/10-mail.conf`)

```conf
mail_location = maildir:~/Maildir
```

### SSL 설정 (옵션, 기본 포트 143만 열 경우 불필요)

`/etc/dovecot/conf.d/10-ssl.conf`에서 `ssl = required`를 `ssl = yes`로 변경하고 인증서 경로 지정.

### Dovecot 실행

```bash
sudo systemctl enable --now dovecot
```

### 접속 테스트 (telnet)

```bash
telnet localhost 143
* OK [CAPABILITY ...] Dovecot ready.
a login 사용자 비밀번호
a OK [CAPABILITY ...] Logged in
a select INBOX
* FLAGS ...
```

## 메일 큐 관리

Postfix는 보내지 못한 메일을 큐에 보관한다.

### 큐 확인

```bash
postqueue -p          # 대기 중인 메일 목록
mailq                 # 동일
```

### 큐 처리 강제 실행

```bash
postfix flush         # 모든 큐 즉시 전송 시도
postqueue -f          # 동일
```

### 큐에서 메일 삭제

```bash
sudo postsuper -d ALL   # 전체 큐 삭제 (주의)
sudo postsuper -d <QUEUE_ID>   # 특정 메일만 삭제
```

## 스팸 필터: SpamAssassin 기초

SpamAssassin은 메일 헤더와 본문을 분석해 스팸 점수를 매기고, 태그를 추가하거나 차단할 수 있다.

### 설치 및 기본 설정

```bash
sudo apt install spamassassin spamc
sudo systemctl enable --now spamassassin
```

### Postfix와 연동 (milter 방식)

```bash
sudo apt install spamass-milter
```

Postfix 설정 (`/etc/postfix/main.cf`):

```conf
smtpd_milters = unix:/var/run/spamass-milter/spamass-milter.sock
non_smtpd_milters = $smtpd_milters
milter_default_action = accept
```

SpamAssassin은 기본 점수 5점 이상을 스팸으로 판단하며, 메일 헤더에 `X-Spam-Flag: YES`를 추가한다.

### 수동 스캔 테스트

```bash
cat email.eml | spamc | less
```

## 문제 해결 기본

| 증상 | 확인 방법 |
|------|----------|
| 메일 전송 안 됨 | `tail -f /var/log/mail.log`, `postqueue -p` |
| IMAP 접속 안 됨 | `systemctl status dovecot`, `telnet localhost 143` |
| 스팸 필터 적용 안 됨 | `spamassassin --lint` 설정 점검, milter 소켓 권한 확인 |

## 실전 시나리오: 로컬 메일 릴레이

서버에서 발생하는 로그를 관리자 메일로 전송하고 싶다면 간단한 릴레이 설정으로 충분하다.

1. Postfix 설치 후 `myorigin`과 `mydestination`을 적절히 설정
2. `relayhost`를 외부 SMTP로 지정 (예: Gmail)
3. 알림을 받을 관리자 주소를 `/etc/aliases`에 등록
   ```
   root: admin@example.com
   ```
   `newaliases` 실행
4. 시스템 로그가 `root`로 전송되도록 설정 (대부분 기본)

## 결론

메일 서버의 기본 구성은 생각보다 간단하다. Postfix로 MTA를, Dovecot으로 IMAP을 구성하면 내부 사용자 간 메일 교환과 외부 메일 릴레이가 가능하다.  

초중급 수준에서는 다음 사항을 익히는 것으로 충분하다.
- Postfix 기본 설정 (로컬 메일, 릴레이)
- 메일 큐 확인 및 관리
- Dovecot으로 IMAP 서비스 제공
- SpamAssassin을 통한 간단한 스팸 필터 적용

이러한 기초를 바탕으로 필요에 따라 추가 기능(웹메일, DKIM, DMARC 등)을 점진적으로 확장할 수 있다.
