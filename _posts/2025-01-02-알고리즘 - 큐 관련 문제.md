# 큐

큐는 선입선출(FIFO) 구조로, 먼저 들어온 데이터가 먼저 나간다. 대기열 처리, BFS, 시뮬레이션 등 다양한 문제에서 핵심 자료구조로 사용된다. 여기서는 초중급 수준에서 꼭 알아야 할 패턴을 간추렸다.

## 기본 연산

- `enqueue`: 뒤에 추가
- `dequeue`: 앞에서 제거
- `peek`: 앞의 값 조회
- 시간복잡도: 각 연산 $$O(1)$$

파이썬에서는 `collections.deque`를 사용하는 것이 가장 효율적이다. 리스트로 구현할 경우 `pop(0)`은 $$O(n)$$이므로 피해야 한다.

```python
from collections import deque

q = deque()
q.append(1)      # enqueue
q.append(2)
front = q[0]     # peek (1)
x = q.popleft()  # dequeue (1)
```

## 핵심 유형 3가지

### 1. 프린터 큐 (BOJ 1966)

문제: 문서마다 중요도가 있고, 큐의 맨 앞 문서보다 높은 중요도가 뒤에 있으면 맨 앞 문서를 뒤로 보낸다. 특정 문서가 몇 번째로 인쇄되는지 구하는 문제.

해결: (인덱스, 중요도)를 큐에 저장하고, 매번 맨 앞을 꺼내 현재 큐에 더 높은 중요도가 있는지 확인한다.

```python
from collections import deque

def printer_queue(n, m, priorities):
    q = deque((i, p) for i, p in enumerate(priorities))
    count = 0
    while q:
        i, p = q.popleft()
        if any(p < other for _, other in q):
            q.append((i, p))
        else:
            count += 1
            if i == m:
                return count
```

`any()`는 매번 큐 전체를 검사하지만, 입력 크기가 작을 때는 충분하다. 더 효율적으로 하려면 우선순위 빈도수를 관리할 수도 있지만, 초중급 수준에서는 이 정도로도 충분하다.

### 2. 카드2 (BOJ 2164)

문제: 1부터 N까지의 카드를 큐에 넣고, 맨 위 카드를 버리고 그 다음 카드를 맨 아래로 옮기는 작업을 반복한다. 마지막에 남는 카드 번호를 출력한다.

해결: 큐에 1..N을 넣고 시뮬레이션한다.

```python
from collections import deque

n = int(input())
q = deque(range(1, n+1))

while len(q) > 1:
    q.popleft()          # 버리기
    q.append(q.popleft()) # 다음 카드를 뒤로

print(q[0])
```

시간복잡도는 각 카드가 상수 번 이동하므로 $$O(n)$$이다.

### 3. 요세푸스 문제 (BOJ 1158)

문제: N명이 원형으로 앉아 있고, K번째 사람을 제거한다. 제거되는 순서를 출력한다.

해결: 큐를 원형처럼 사용하며, K-1번 앞의 사람을 뒤로 보낸 후 맨 앞을 제거한다.

```python
from collections import deque

n, k = map(int, input().split())
q = deque(range(1, n+1))
result = []

while q:
    # K-1번 앞의 사람을 뒤로
    for _ in range(k-1):
        q.append(q.popleft())
    result.append(q.popleft())

print("<" + ", ".join(map(str, result)) + ">")
```

`deque.rotate(-(k-1))`를 사용해 더 간결하게 작성할 수도 있다.

## BFS (너비 우선 탐색)

BFS는 큐를 사용해 가까운 정점부터 탐색하는 알고리즘이다. 무가중치 그래프에서 최단 거리를 구할 때 사용한다.

```python
from collections import deque

def bfs(graph, start):
    visited = set([start])
    q = deque([start])
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            if v not in visited:
                visited.add(v)
                q.append(v)
    return order
```

**2차원 격자에서의 BFS 예시** (상하좌우 이동)

```python
def grid_bfs(grid, start):
    R, C = len(grid), len(grid[0])
    sr, sc = start
    dist = [[-1]*C for _ in range(R)]
    q = deque([(sr, sc)])
    dist[sr][sc] = 0
    dirs = [(1,0), (-1,0), (0,1), (0,-1)]

    while q:
        r, c = q.popleft()
        for dr, dc in dirs:
            nr, nc = r+dr, c+dc
            if 0 <= nr < R and 0 <= nc < C and grid[nr][nc] != '#' and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                q.append((nr, nc))
    return dist
```

- 시간복잡도: $$O(V+E)$$ (정점 수 + 간선 수)
- 격자에서는 정점이 $$R \times C$$, 간선이 각 정점당 4개이므로 $$O(RC)$$.

## 슬라이딩 윈도우 최대

길이가 k인 윈도우를 배열 위에서 한 칸씩 이동하며 각 윈도우의 최댓값을 구하는 문제는 **모노토닉 덱**으로 해결할 수 있다. 덱에는 인덱스를 저장하며, 값이 감소하도록 유지한다.

```python
from collections import deque

def sliding_window_max(arr, k):
    dq = deque()
    result = []
    for i, x in enumerate(arr):
        # 뒤에서부터 현재 x보다 작거나 같은 값 제거
        while dq and arr[dq[-1]] <= x:
            dq.pop()
        dq.append(i)
        # 윈도우 범위를 벗어난 인덱스 제거
        if dq[0] <= i - k:
            dq.popleft()
        # 윈도우가 완성된 시점부터 결과 저장
        if i >= k - 1:
            result.append(arr[dq[0]])
    return result
```

각 인덱스는 덱에 한 번 들어가고 한 번 나오므로 시간복잡도는 $$O(n)$$이다.

## 큐의 변형: 두 스택으로 큐 구현

스택 두 개를 이용해 큐를 구현할 수 있다. `in_stack`에 push하고, `out_stack`이 비어 있을 때만 `in_stack`의 원소를 모두 옮겨서 pop한다.

```python
class MyQueue:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def pop(self):
        self._transfer()
        return self.out_stack.pop()

    def peek(self):
        self._transfer()
        return self.out_stack[-1]

    def _transfer(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
```

각 원소는 두 번만 이동하므로 분할 상환 $$O(1)$$이다.

## 큐 선택 가이드

| 상황 | 사용 자료구조 | 이유 |
|------|------------|------|
| 단순 대기열 처리 | `collections.deque` | 양쪽 끝 연산 $$O(1)$$ |
| BFS (그래프/격자) | `deque` | 순차적 확장에 적합 |
| 원형 시뮬레이션 | `deque` + `rotate` 또는 직접 pop/append | 원형 순환 구현 용이 |
| 최대/최소 슬라이딩 윈도우 | 모노토닉 덱 (deque) | $$O(n)$$ 시간, 각 원소 한 번씩 처리 |
| 자료구조 변형 (큐를 스택으로 등) | 필요에 따라 | 특수 요구 사항 대응 |

---

## 마무리

큐는 단순하지만 BFS, 시뮬레이션, 대기열 처리 등에서 필수적인 도구다. 여기서 소개한 프린터 큐, 카드2, 요세푸스, BFS 기본, 슬라이딩 윈도우 최대 패턴을 직접 구현해보면 큐를 활용한 문제에 대한 직관이 생긴다. 복잡한 응용은 이 기본 패턴의 확장이므로, 핵심 동작 원리를 확실히 이해하는 것이 중요하다.
