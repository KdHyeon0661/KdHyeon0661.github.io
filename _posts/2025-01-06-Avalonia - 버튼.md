# Avalonia MVVM에서 버튼 기능 추가하기

Avalonia에서 버튼 클릭 이벤트를 MVVM 패턴으로 처리하려면 명령(command)을 사용해야 합니다. 이 글에서는 ReactiveUI의 `ReactiveCommand`를 중심으로 동기/비동기 명령, 조건부 활성화(`CanExecute`), 실행 상태 표시, 예외 처리, 그리고 확장 기법까지 단계별로 설명합니다.

---

## 목표와 사용 기술

| 항목 | 설명 |
|------|------|
| `ReactiveCommand` | MVVM 방식의 명령 구현체. 동기/비동기 모두 지원 |
| `WhenAnyValue`, `CombineLatest` | `CanExecute` 조건을 Observable로 선언 |
| `IsExecuting` | 명령 실행 중 상태를 나타내는 Observable |
| `ThrownExceptions` | 명령 실행 중 발생한 예외 스트림 |
| `CommandParameter` | 명령에 인자 전달 |
| `Unit` | 매개변수/결과가 없음을 의미하는 ReactiveUI 타입 |

---

## ReactiveCommand 기본

ReactiveUI의 `ReactiveCommand`는 일반적인 `ICommand` 구현체로, WPF의 `RelayCommand`보다 더 풍부한 기능을 제공합니다. 가장 큰 차이는 `CanExecute`를 Observable로 선언하여 상태 변화에 따라 자동으로 활성/비활성화가 갱신된다는 점입니다.

```csharp
using ReactiveUI;
using System.Reactive;
using System.Reactive.Linq;

public class BasicViewModel : ReactiveObject
{
    public ReactiveCommand<Unit, Unit> MyCommand { get; }

    public BasicViewModel()
    {
        // 동기 명령
        MyCommand = ReactiveCommand.Create(() => { /* 실행 로직 */ });
    }
}
```

`ReactiveCommand.Create`는 인자가 없는 동기 명령을 만들고, `ReactiveCommand.CreateFromTask`는 비동기 명령을 만듭니다. 반환 타입이 `Unit`인 것은 결과가 없음을 의미합니다.

## 예제: 동기/비동기 + CanExecute

다음은 입력값과 체크박스 상태에 따라 버튼의 활성화 여부가 결정되는 완전한 예제입니다.

```csharp
// ViewModels/ButtonViewModel.cs
using ReactiveUI;
using System;
using System.Reactive;
using System.Reactive.Linq;
using System.Threading;
using System.Threading.Tasks;

public class ButtonViewModel : ReactiveObject
{
    private string _status = "대기 중...";
    public string Status
    {
        get => _status;
        set => this.RaiseAndSetIfChanged(ref _status, value);
    }

    private bool _canClick = true;
    public bool CanClick
    {
        get => _canClick;
        set => this.RaiseAndSetIfChanged(ref _canClick, value);
    }

    private string _input = "";
    public string Input
    {
        get => _input;
        set => this.RaiseAndSetIfChanged(ref _input, value);
    }

    private CancellationTokenSource? _cts;

    public ReactiveCommand<Unit, Unit> ClickCommand { get; }
    public ReactiveCommand<Unit, Unit> AsyncCommand { get; }
    public ReactiveCommand<Unit, Unit> CancelCommand { get; }

    private readonly ObservableAsPropertyHelper<bool> _isBusy;
    public bool IsBusy => _isBusy.Value;

    public ButtonViewModel()
    {
        // CanExecute 조건: CanClick == true && Input이 비어 있지 않음
        var canExecute = this.WhenAnyValue(
                vm => vm.CanClick,
                vm => vm.Input,
                (can, text) => can && !string.IsNullOrWhiteSpace(text));

        ClickCommand = ReactiveCommand.Create(OnClick, canExecute);
        AsyncCommand = ReactiveCommand.CreateFromTask(OnAsyncClick, canExecute);
        CancelCommand = ReactiveCommand.Create(OnCancel, AsyncCommand.IsExecuting);

        _isBusy = AsyncCommand.IsExecuting
            .StartWith(false)
            .ToProperty(this, vm => vm.IsBusy);

        AsyncCommand.ThrownExceptions.Subscribe(ex =>
        {
            Status = $"오류: {ex.Message}";
        });
    }

    private void OnClick()
    {
        Status = $"[{DateTime.Now:T}] 동기 클릭: 입력 = '{Input}'";
    }

    private async Task OnAsyncClick()
    {
        _cts?.Cancel();
        _cts = new CancellationTokenSource();
        Status = "처리 중...";
        await Task.Delay(2000, _cts.Token);
        Status = $"[{DateTime.Now:T}] 비동기 완료: 입력 길이 = {Input.Length}";
    }

    private void OnCancel()
    {
        _cts?.Cancel();
        Status = "취소 요청됨";
    }
}
```

XAML에서는 이 ViewModel과 바인딩합니다.

```xml
<!-- Views/ButtonView.axaml -->
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             x:Class="MyApp.Views.ButtonView">
    <Grid RowDefinitions="Auto,Auto,Auto,Auto" Margin="16" RowSpacing="8">
        <TextBlock Text="{Binding Status}" />
        <StackPanel Grid.Row="1" Orientation="Horizontal" Spacing="8">
            <TextBox Width="200" Text="{Binding Input, Mode=TwoWay, UpdateSourceTrigger=PropertyChanged}" />
            <CheckBox Content="버튼 활성화" IsChecked="{Binding CanClick}" />
        </StackPanel>
        <StackPanel Grid.Row="2" Orientation="Horizontal" Spacing="8">
            <Button Content="동기" Command="{Binding ClickCommand}" />
            <Button Content="비동기 (2초)" Command="{Binding AsyncCommand}" />
            <Button Content="취소" Command="{Binding CancelCommand}" />
        </StackPanel>
        <StackPanel Grid.Row="3" Orientation="Horizontal" Spacing="8">
            <ProgressBar IsIndeterminate="True" Width="160" Height="6" IsVisible="{Binding IsBusy}" />
            <TextBlock Text="실행 중" IsVisible="{Binding IsBusy}" />
        </StackPanel>
    </Grid>
</UserControl>
```

**핵심**  
- `WhenAnyValue`로 여러 속성을 감시하고, 그 결과를 `CanExecute`의 소스로 사용합니다.  
- `IsExecuting`은 명령 실행 중일 때 `true`가 되는 Observable이며, 이를 활용해 취소 버튼의 활성화 조건을 설정했습니다.  
- `ObservableAsPropertyHelper`를 이용해 `IsBusy` 속성을 만들어 스피너에 바인딩했습니다.

## CommandParameter로 항목 전달

리스트에서 각 항목에 삭제 버튼을 두는 경우, 어떤 항목을 삭제할지 명령에 전달해야 합니다. `CommandParameter`를 사용합니다.

```csharp
public class ItemsViewModel : ReactiveObject
{
    public ObservableCollection<string> Items { get; } = new();
    public ReactiveCommand<string, Unit> RemoveCommand { get; }

    public ItemsViewModel()
    {
        Items.Add("Alpha");
        Items.Add("Beta");
        RemoveCommand = ReactiveCommand.Create<string>(item => Items.Remove(item));
    }
}
```

XAML에서는 `CommandParameter`에 현재 항목을 바인딩합니다.

```xml
<ListBox Items="{Binding Items}">
    <ListBox.ItemTemplate>
        <DataTemplate>
            <Grid ColumnDefinitions="*,Auto">
                <TextBlock Text="{Binding .}" />
                <Button Grid.Column="1" Content="삭제"
                        Command="{Binding DataContext.RemoveCommand, RelativeSource={RelativeSource AncestorType=UserControl}}"
                        CommandParameter="{Binding .}" />
            </Grid>
        </DataTemplate>
    </ListBox.ItemTemplate>
</ListBox>
```

## 결과를 반환하는 비동기 커맨드

명령이 작업 결과를 반환해야 할 때는 제네릭 버전의 `ReactiveCommand`를 사용합니다.

```csharp
public class ResultViewModel : ReactiveObject
{
    public ReactiveCommand<Unit, string> GenerateCommand { get; }
    private string _last = "";
    public string Last
    {
        get => _last;
        private set => this.RaiseAndSetIfChanged(ref _last, value);
    }

    public ResultViewModel()
    {
        GenerateCommand = ReactiveCommand.CreateFromTask(async () =>
        {
            await Task.Delay(500);
            return $"[{DateTime.Now:T}] 토큰";
        });
        GenerateCommand.Subscribe(token => Last = token);
    }
}
```

XAML:

```xml
<StackPanel>
    <Button Content="토큰 생성" Command="{Binding GenerateCommand}" />
    <TextBlock Text="{Binding Last}" />
</StackPanel>
```

## 여러 조건 결합한 CanExecute

`CombineLatest`를 사용하면 여러 속성이나 상태를 조합할 수 있습니다.

```csharp
var canExecute = Observable.CombineLatest(
    this.WhenAnyValue(vm => vm.CanClick),
    this.WhenAnyValue(vm => vm.Input).Select(s => !string.IsNullOrWhiteSpace(s)),
    this.WhenAnyValue(vm => vm.IsNetworkConnected),
    (can, hasInput, net) => can && hasInput && net
);
SaveCommand = ReactiveCommand.CreateFromTask(SaveAsync, canExecute);
```

## 스타일과 트리거로 버튼 UI 개선

`DataTrigger`를 이용해 명령 실행 중에 버튼의 내용이나 상태를 변경할 수 있습니다.

```xml
<Button Command="{Binding SendCommand}">
    <Button.Styles>
        <Style Selector="Button">
            <Style.Triggers>
                <DataTrigger Binding="{Binding SendCommand.IsExecuting}" Value="True">
                    <Setter Property="Content" Value="전송 중..." />
                    <Setter Property="IsEnabled" Value="False" />
                </DataTrigger>
            </Style.Triggers>
        </Style>
    </Button.Styles>
</Button>
```

## 예외 처리 패턴

`ThrownExceptions`를 구독하여 예외를 중앙에서 처리할 수 있습니다.

```csharp
SaveCommand.ThrownExceptions
    .ObserveOn(RxApp.MainThreadScheduler)
    .Subscribe(ex =>
    {
        // 로그 기록, 사용자 알림 등
        Status = $"저장 실패: {ex.Message}";
    });
```

## 키 바인딩

키보드 단축키로 명령을 실행하려면 `KeyBinding`을 사용합니다.

```xml
<UserControl>
    <UserControl.KeyBindings>
        <KeyBinding Gesture="Enter" Command="{Binding AsyncCommand}" />
        <KeyBinding Gesture="Ctrl+S" Command="{Binding SaveCommand}" />
    </UserControl.KeyBindings>
    <!-- 나머지 UI -->
</UserControl>
```

## 단위 테스트

ViewModel은 UI 없이 테스트할 수 있습니다.

```csharp
[Fact]
public async Task AsyncCommand_Disabled_When_InputEmpty()
{
    var vm = new ButtonViewModel { CanClick = true, Input = "" };
    Assert.False(await vm.AsyncCommand.CanExecute.FirstAsync());
}

[Fact]
public async Task AsyncCommand_UpdatesStatus()
{
    var vm = new ButtonViewModel { CanClick = true, Input = "test" };
    await vm.AsyncCommand.Execute();
    Assert.Contains("비동기 완료", vm.Status);
}
```

## 확장 가이드

- **진행률 표시**: `IProgress<T>`를 명령에 주입하거나, 명령 결과를 `double` 타입으로 반환하는 스트림을 만들 수 있습니다.
- **중복 실행 방지**: `IsExecuting`을 다른 명령의 `CanExecute`에 결합하여 실행 중에는 다른 명령을 비활성화할 수 있습니다.
- **다이얼로그 연동**: `Interaction<TInput, TOutput>`(ReactiveUI) 또는 `IDialogService`를 사용해 사용자 확인을 받은 후 명령을 이어나갑니다.
- **서비스 추상화**: 파일 I/O, 네트워크 등은 인터페이스로 분리하여 ViewModel 테스트 시 목(mock)으로 대체할 수 있습니다.

## 결론

Avalonia에서 MVVM 패턴으로 버튼을 구현할 때는 ReactiveUI의 `ReactiveCommand`가 가장 효율적입니다. `CanExecute`를 Observable로 선언하는 방식은 상태 관리가 깔끔해지고, `IsExecuting`과 `ThrownExceptions`를 활용하면 실행 상태와 오류 처리를 일관되게 처리할 수 있습니다. 이 글에서 소개한 기법들을 조합하면 버튼 하나에 들어가는 로직도 견고하게 설계할 수 있습니다.
