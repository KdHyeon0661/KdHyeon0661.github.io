# 백트래킹(Backtracking)

## 백트래킹이란?

백트래킹은 **모든 가능한 경우를 탐색**하되, 조건에 맞지 않는 경우는 **더 이상 진행하지 않고 되돌아가서(backtrack)** 다른 길을 시도하는 방법이다.  
쉽게 말해, 가능성이 없는 길은 미리 포기하는 **가지치기(pruning)** 를 통해 탐색 시간을 크게 줄인다.

### 완전 탐색과의 차이

완전 탐색(Brute Force)은 가능한 모든 경우를 끝까지 검사한다.  
백트래킹은 중간에 **해가 될 가능성이 없는 조합**을 발견하면 그 이후 단계는 아예 건너뛴다.  
예를 들어, 체스판에 퀸을 놓을 때 이미 같은 열에 퀸이 있으면 더 이상 그 열을 고려하지 않는 식이다.

---

## 핵심 구성 요소

백트래킹 알고리즘은 보통 다음 네 가지 요소를 가진다.

1. **상태 표현**: 현재까지 결정한 내용을 저장하는 구조 (예: 퀸의 위치, 사용한 숫자 목록)
2. **후보 생성**: 다음 단계에서 선택할 수 있는 후보들을 만드는 방법
3. **유망성 판정**: 현재 상태에서 더 진행해도 해가 될 가능성이 있는지 검사
4. **복원**: 선택을 취소하고 이전 상태로 되돌리는 동작

### 재귀 템플릿

```python
def backtrack(state):
    # 1. 기저 조건: 완성된 해인지 확인
    if is_complete(state):
        process_solution(state)   # 해 출력, 저장 등
        return

    # 2. 후보 생성 (보통 반복문)
    for choice in generate_candidates(state):
        if is_promising(state, choice):   # 유망성 검사
            apply(state, choice)          # 선택 적용
            backtrack(state)              # 재귀 호출
            undo(state, choice)           # 선택 취소 (복원)
```

## 기본 예제 1: 순열 만들기

서로 다른 숫자로 구성된 순열을 출력하는 문제로 백트래킹 구조를 이해해보자.

```python
def permute(arr):
    n = len(arr)
    used = [False] * n          # 각 숫자를 사용했는지 체크
    path = []                   # 현재까지 만든 순열

    def backtrack():
        if len(path) == n:      # 모든 숫자를 다 사용함
            print(path)
            return
        for i in range(n):
            if used[i]:
                continue        # 이미 사용한 숫자는 건너뛰기
            # 선택
            used[i] = True
            path.append(arr[i])
            backtrack()
            # 복원
            path.pop()
            used[i] = False

    backtrack()
```

**설명**
- `used` 배열로 중복 선택을 막는다.
- `path`가 꽉 차면 출력하고 되돌아간다.
- 가지치기는 여기서 간단히 `used` 체크만으로 이루어지지만, 문제에 따라 더 복잡한 조건이 들어갈 수 있다.

## 기본 예제 2: 조합 만들기

조합은 순서를 고려하지 않기 때문에 시작 인덱스를 전달하여 중복을 방지한다.

```python
def combine(arr, r):
    n = len(arr)
    path = []

    def backtrack(start):
        if len(path) == r:
            print(path)
            return
        # 필요한 개수만큼 남은 원소가 있는지 확인하는 가지치기
        for i in range(start, n - (r - len(path)) + 1):
            path.append(arr[i])
            backtrack(i + 1)   # 다음 선택은 i+1부터
            path.pop()

    backtrack(0)
```

**핵심**  
- `start` 인덱스를 통해 이전에 선택한 원소보다 뒤쪽만 선택하도록 강제한다.
- 가지치기: 남아야 하는 원소 수(`r - len(path)`)보다 남은 원소 수가 적으면 반복문이 자동으로 중단된다.

## N-Queen: 대표적인 백트래킹 문제

N×N 체스판에 N개의 퀸을 서로 공격할 수 없도록 배치하는 문제다.  
퀸은 같은 행, 열, 대각선에 있으면 공격 가능하다.

### 간단한 구현

```python
n = int(input())
col = [False] * n            # 열 점유 여부
diag1 = [False] * (2*n)      # r - c + n (왼쪽 아래↔오른쪽 위 대각선)
diag2 = [False] * (2*n)      # r + c (오른쪽 아래↔왼쪽 위 대각선)
ans = 0

def backtrack(r):
    global ans
    if r == n:                # 모든 행에 퀸을 놓음
        ans += 1
        return
    for c in range(n):
        d1 = r - c + n
        d2 = r + c
        if col[c] or diag1[d1] or diag2[d2]:
            continue          # 공격 가능한 위치면 건너뛰기
        # 퀸 배치
        col[c] = diag1[d1] = diag2[d2] = True
        backtrack(r + 1)
        # 배치 취소
        col[c] = diag1[d1] = diag2[d2] = False

backtrack(0)
print(ans)
```

**가지치기 포인트**  
- 같은 열에 이미 퀸이 있으면 그 열은 배제.
- 대각선 충돌 여부를 $$O(1)$$에 검사하기 위해 `r-c`와 `r+c` 값을 인덱스로 사용한다.

## 스도쿠: 제약 전파와 변수 순서 휴리스틱

스도쿠는 9×9 격자에 1~9를 넣되, 각 행/열/3×3 블록에 중복이 없어야 한다.  
백트래킹에 **제약 전파**와 **최소 잔여 후보(MRV)** 를 적용하면 속도가 크게 향상된다.

```python
board = [list(map(int, input().split())) for _ in range(9)]
rows = [0]*9
cols = [0]*9
boxes = [0]*9
blanks = []

# 초기 상태 설정 (비트마스크로 사용 중인 숫자 기록)
for r in range(9):
    for c in range(9):
        num = board[r][c]
        if num == 0:
            blanks.append((r, c))
        else:
            bit = 1 << (num - 1)
            rows[r] |= bit
            cols[c] |= bit
            boxes[(r//3)*3 + (c//3)] |= bit

def get_candidates(r, c):
    used = rows[r] | cols[c] | boxes[(r//3)*3 + (c//3)]
    # 사용되지 않은 숫자의 비트만 남김 (1~9: 비트 0~8)
    return (~used) & 0x1FF

def solve(idx):
    if idx == len(blanks):
        return True

    # MRV: 후보 수가 가장 적은 칸을 찾음
    best = idx
    best_cnt = 10
    for k in range(idx, len(blanks)):
        r, c = blanks[k]
        cnt = get_candidates(r, c).bit_count()
        if cnt < best_cnt:
            best_cnt, best = cnt, k
            if cnt == 1:
                break
    blanks[idx], blanks[best] = blanks[best], blanks[idx]
    r, c = blanks[idx]

    cand = get_candidates(r, c)
    while cand:
        bit = cand & -cand                     # 가장 낮은 1비트 추출
        num = bit.bit_length()                 # 1~9
        # 숫자 배치
        board[r][c] = num
        rows[r] |= bit
        cols[c] |= bit
        boxes[(r//3)*3 + (c//3)] |= bit

        if solve(idx + 1):
            return True

        # 배치 취소
        board[r][c] = 0
        rows[r] ^= bit
        cols[c] ^= bit
        boxes[(r//3)*3 + (c//3)] ^= bit

        cand -= bit

    blanks[idx], blanks[best] = blanks[best], blanks[idx]
    return False

solve(0)

for row in board:
    print(' '.join(map(str, row)))
```

**사용한 기법**  
- **비트마스크**: 각 행/열/블록에 사용된 숫자를 9비트 정수로 관리 → 후보 계산과 복원이 빠르다.
- **MRV (Minimum Remaining Values)**: 빈 칸 중에서 선택할 수 있는 숫자가 가장 적은 칸부터 결정 → 탐색 분기를 최소화.
- **제약 전파**: 후보 계산 시 이미 사용된 숫자를 미리 제외한다.

## 최적화 문제: 부분 집합 합

특정 합을 만드는 부분 집합을 찾는 문제에서 **가지치기**와 **경계(bound)** 를 활용할 수 있다.

```python
def subset_sum(arr, target):
    n = len(arr)
    arr.sort(reverse=True)              # 큰 수부터 시도
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + arr[i]

    best = None                         # (원소 수, 부분 집합)

    def dfs(i, cur_sum, cnt, chosen):
        nonlocal best
        if cur_sum > target:
            return
        # 남은 원소를 모두 더해도 target에 못 미치면 포기
        if cur_sum + (prefix[n] - prefix[i]) < target:
            return
        # 현재 cnt가 이미 찾은 최선보다 크면 더 볼 필요 없음
        if best and cnt >= best[0]:
            return

        if cur_sum == target:
            if not best or cnt < best[0]:
                best = (cnt, chosen[:])
            return

        if i == n:
            return

        # 현재 원소를 선택하는 경우
        chosen.append(arr[i])
        dfs(i+1, cur_sum + arr[i], cnt+1, chosen)
        chosen.pop()

        # 선택하지 않는 경우
        dfs(i+1, cur_sum, cnt, chosen)

    dfs(0, 0, 0, [])
    return best
```

**가지치기 전략**  
- **불가능성 컷**: 이미 합이 목표를 초과했거나, 남은 원소를 모두 더해도 목표에 도달할 수 없으면 중단.
- **최적화 컷**: 현재 원소 수가 이미 찾은 최적해보다 많으면 더 탐색할 필요 없음.

## 복잡도와 실전 팁

### 이론적 복잡도

탐색 트리의 깊이를 $$d$$, 평균 분기수를 $$b$$라고 하면 완전 탐색 시 노드 수는 약 $$O(b^d)$$이다.  
백트래킹은 가지치기를 통해 실제 탐색 노드 수를 이보다 훨씬 줄일 수 있다.

### 구현 팁

- **재귀 깊이**: 파이썬은 기본 재귀 한도가 1000이므로 필요한 경우 `sys.setrecursionlimit(10**6)` 설정.
- **비트 연산**: 집합 연산이 필요할 때는 리스트 대신 비트마스크를 사용하면 속도가 크게 향상된다.
- **전역 변수**: `global` 대신 함수 내에서 `nonlocal`을 쓰거나, 결과를 반환하는 방식으로 설계.
- **휴리스틱**: 변수 순서(가장 제약이 큰 것부터), 값 순서(가능성 높은 값부터)를 조정하면 성능이 달라진다.

## 디버깅 체크리스트

1. **복원 누락**: `apply`만 하고 `undo`를 빼먹으면 상태가 오염된다.
2. **기저 조건 오류**: `is_complete` 조건이 잘못되어 무한 재귀가 발생할 수 있다.
3. **가지치기 조건이 너무 엄격**: 올바른 해를 잘라버리지 않는지 확인.
4. **출력 형식**: 문제에서 요구하는 대로 출력하는지 확인.

## 표로 보는 전략 요약

| 문제 유형 | 추천 기법 |
|-----------|-----------|
| 순열/조합 생성 | 사용 여부 배열(`used`) 또는 시작 인덱스 |
| N-Queen / 스도쿠 | 제약 조건을 빠르게 검사하는 자료구조 (비트마스크, 집합) |
| 최적화 문제 | 가지치기에 경계(bound) 활용 |
| 큰 입력 | 변수 순서 휴리스틱(MRV) 적용 |
| 해 하나만 필요 | 해를 찾으면 즉시 상위로 반환 |

## 마무리

백트래킹은 **가능성을 탐색하면서 조건에 맞지 않는 경로를 조기에 포기**하는 방법이다.  
재귀를 기본으로 하며, 상태를 잘 정의하고, 유망성 검사와 복원을 정확히 구현하는 것이 핵심이다.  
처음에는 순열/조합 같은 기본 예제로 구조를 익히고, 점차 N-Queen, 스도쿠처럼 제약 조건이 많은 문제로 확장해 가는 것이 좋다.

효율적인 백트래킹은 휴리스틱과 제약 전파의 적절한 사용에서 나온다.  
모든 문제에 최적의 가지치기를 처음부터 완벽하게 설계하기는 어렵지만, 위의 템플릿과 예제들을 바탕으로 하나씩 적용해 나가다 보면 복잡한 탐색 문제도 체계적으로 해결할 수 있다.
