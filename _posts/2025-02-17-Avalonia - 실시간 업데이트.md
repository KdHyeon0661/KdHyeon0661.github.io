# Avalonia MVVM에서 실시간 업데이트 (WebSocket)

실시간 데이터가 필요한 애플리케이션(주식, 채팅, 알림)에서는 WebSocket을 활용해 서버와 지속적인 연결을 유지한다. 이 글에서는 MVVM 패턴을 유지하면서 WebSocket을 안정적으로 연동하는 방법을 다룬다.

## 왜 WebSocket인가

HTTP 요청-응답 방식과 달리 WebSocket은 **양방향 실시간 통신**을 제공한다. 한 번 연결을 맺으면 서버가 먼저 데이터를 전송할 수 있어, 폴링(polling)보다 훨씬 효율적이다.

## 전체 구조

```
[Server] ←WebSocket→ IWebSocketService ←→ ViewModel ←→ View
```

- **IWebSocketService**: 연결, 재연결, 메시지 송수신을 담당
- **ViewModel**: 서비스에서 받은 메시지를 UI에 반영, 사용자 입력을 서비스로 전달
- **View**: 바인딩을 통해 데이터와 명령을 ViewModel에 연결

## WebSocketService 구현 (핵심)

### 연결과 수신 루프

실제 WebSocket 연결과 메시지 수신을 관리한다. 재연결을 위한 지수 백오프, 부분 메시지 조립, Heartbeat 등이 포함된다.

```csharp
using System.Net.WebSockets;
using System.Text;
using System.Text.Json;

public sealed class WebSocketService : IWebSocketService
{
    private ClientWebSocket? _client;
    private CancellationTokenSource? _cts;
    private WebSocketOptions? _options;
    private readonly SemaphoreSlim _sendLock = new(1, 1);

    public event EventHandler<NotificationMessage>? OnNotification;
    public bool IsConnected => _client?.State == WebSocketState.Open;

    public async Task ConnectAsync(WebSocketOptions options, CancellationToken ct = default)
    {
        _options = options;
        _cts = CancellationTokenSource.CreateLinkedTokenSource(ct);
        await TryConnectWithReconnectAsync(_cts.Token);
        _ = Task.Run(() => HeartbeatLoop(_cts.Token));
    }

    private async Task TryConnectWithReconnectAsync(CancellationToken ct)
    {
        var delay = _options!.ReconnectMinDelay;
        while (!ct.IsCancellationRequested)
        {
            try
            {
                _client?.Dispose();
                _client = new ClientWebSocket();

                if (!string.IsNullOrWhiteSpace(_options.BearerToken))
                    _client.Options.SetRequestHeader("Authorization", $"Bearer {_options.BearerToken}");

                await _client.ConnectAsync(_options.ServerUri, ct);
                _ = Task.Run(() => ReceiveLoop(ct), ct);
                return;
            }
            catch when (!ct.IsCancellationRequested)
            {
                await Task.Delay(delay, ct);
                delay = TimeSpan.FromMilliseconds(Math.Min(delay.TotalMilliseconds * 2,
                                       _options.ReconnectMaxDelay.TotalMilliseconds));
            }
        }
    }

    private async Task ReceiveLoop(CancellationToken ct)
    {
        var buffer = new byte[8192];
        using var ms = new MemoryStream();

        while (!ct.IsCancellationRequested && IsConnected)
        {
            WebSocketReceiveResult result;
            try
            {
                result = await _client!.ReceiveAsync(new ArraySegment<byte>(buffer), ct);
            }
            catch
            {
                await ReconnectAsync(ct);
                continue;
            }

            ms.Write(buffer, 0, result.Count);
            if (!result.EndOfMessage) continue;

            ms.Position = 0;
            if (result.MessageType == WebSocketMessageType.Text)
            {
                using var reader = new StreamReader(ms, Encoding.UTF8);
                var text = await reader.ReadToEndAsync();
                HandleMessage(text);
            }
            ms.SetLength(0);
        }
    }

    private void HandleMessage(string json)
    {
        try
        {
            var msg = JsonSerializer.Deserialize<NotificationMessage>(json);
            if (msg != null) OnNotification?.Invoke(this, msg);
        }
        catch { /* 파싱 오류 무시 */ }
    }

    private async Task HeartbeatLoop(CancellationToken ct)
    {
        var ping = "{\"type\":\"ping\"}";
        var bytes = Encoding.UTF8.GetBytes(ping);
        while (!ct.IsCancellationRequested)
        {
            await Task.Delay(_options!.HeartbeatInterval, ct);
            if (IsConnected)
            {
                await SendAsync(ping, ct);
            }
        }
    }

    private async Task ReconnectAsync(CancellationToken ct)
    {
        try { await _client!.CloseAsync(WebSocketCloseStatus.NormalClosure, "", ct); } catch { }
        _client?.Dispose();
        await TryConnectWithReconnectAsync(ct);
    }

    public async Task SendAsync(string text, CancellationToken ct = default)
    {
        if (!IsConnected) return;
        var bytes = Encoding.UTF8.GetBytes(text);
        await _sendLock.WaitAsync(ct);
        try
        {
            await _client!.SendAsync(new ArraySegment<byte>(bytes), WebSocketMessageType.Text, true, ct);
        }
        finally { _sendLock.Release(); }
    }

    public async Task DisconnectAsync(CancellationToken ct = default)
    {
        _cts?.Cancel();
        if (_client?.State == WebSocketState.Open)
            await _client.CloseAsync(WebSocketCloseStatus.NormalClosure, "", ct);
        _client?.Dispose();
    }

    public async ValueTask DisposeAsync()
    {
        await DisconnectAsync();
        _sendLock.Dispose();
        _cts?.Dispose();
    }
}
```

## ViewModel에서 서비스 사용

ViewModel은 서비스를 주입받아 메시지를 구독하고, UI 갱신은 Dispatcher를 통해 처리한다.

```csharp
public class DashboardViewModel : ReactiveObject
{
    private readonly IWebSocketService _ws;
    public ObservableCollection<NotificationMessage> Messages { get; } = new();
    private string _status = "연결 안됨";
    public string Status
    {
        get => _status;
        private set => this.RaiseAndSetIfChanged(ref _status, value);
    }

    public ReactiveCommand<Unit, Unit> ConnectCommand { get; }
    public ReactiveCommand<Unit, Unit> DisconnectCommand { get; }
    public ReactiveCommand<string, Unit> SendCommand { get; }

    public DashboardViewModel(IWebSocketService ws)
    {
        _ws = ws;
        _ws.OnNotification += OnMessageReceived;

        ConnectCommand = ReactiveCommand.CreateFromTask(async () =>
        {
            var opt = new WebSocketOptions
            {
                ServerUri = new Uri("wss://example.com/ws"),
                BearerToken = "your-token"
            };
            try
            {
                await _ws.ConnectAsync(opt);
                Status = "연결됨";
            }
            catch (Exception ex) { Status = $"오류: {ex.Message}"; }
        });

        DisconnectCommand = ReactiveCommand.CreateFromTask(async () =>
        {
            await _ws.DisconnectAsync();
            Status = "연결 안됨";
        });

        SendCommand = ReactiveCommand.CreateFromTask<string>(async text =>
        {
            if (!string.IsNullOrWhiteSpace(text))
                await _ws.SendAsync(text);
        });
    }

    private void OnMessageReceived(object? sender, NotificationMessage msg)
    {
        Avalonia.Threading.Dispatcher.UIThread.Post(() =>
        {
            Messages.Insert(0, msg);
            if (Messages.Count > 200) Messages.RemoveAt(Messages.Count - 1);
        });
    }
}
```

## DI 등록 (App.axaml.cs)

```csharp
public override void OnFrameworkInitializationCompleted()
{
    var services = new ServiceCollection();
    services.AddSingleton<IWebSocketService, WebSocketService>();
    services.AddTransient<DashboardViewModel>();

    var sp = services.BuildServiceProvider();

    if (ApplicationLifetime is IClassicDesktopStyleApplicationLifetime desktop)
    {
        desktop.MainWindow = new Window
        {
            Content = new DashboardView(),
            DataContext = sp.GetRequiredService<DashboardViewModel>()
        };
        desktop.MainWindow.Show();
    }
    base.OnFrameworkInitializationCompleted();
}
```

## 신뢰성 향상 포인트

| 요소 | 설명 |
|------|------|
| 재연결 | 연결 끊김 시 지수 백오프로 재시도 |
| Heartbeat | 일정 주기로 ping 메시지 전송, 서버가 응답 없으면 연결 종료로 간주 |
| 부분 메시지 조립 | `EndOfMessage`가 false일 때 데이터를 누적 후 완성 시 처리 |
| UI 스레드 | 수신 스레드에서 UI 업데이트 시 Dispatcher 사용 |
| 메모리 | 컬렉션에 무한정 쌓지 않도록 최대 개수 제한 |

## 단위 테스트 전략

WebSocket 서비스는 인터페이스로 분리했으므로 Mock 객체로 대체해 ViewModel 테스트가 가능하다.

```csharp
[Fact]
public async Task ConnectCommand_UpdatesStatus()
{
    var mock = new Mock<IWebSocketService>();
    mock.Setup(x => x.ConnectAsync(It.IsAny<WebSocketOptions>(), default))
        .Returns(Task.CompletedTask);

    var vm = new DashboardViewModel(mock.Object);
    await vm.ConnectCommand.Execute();

    Assert.Equal("연결됨", vm.Status);
}
```

## 결론

WebSocket을 MVVM과 결합할 때는 **네트워크 로직을 서비스로 격리**하고, ViewModel은 순수하게 상태와 바인딩만 담당하도록 한다. 재연결, Heartbeat, 부분 메시지 처리 같은 실무 요소를 초기부터 고려하면 안정적인 실시간 애플리케이션을 구축할 수 있다. 이 패턴은 주식 시세, 채팅, 알림 센터 등 다양한 실시간 기능에 응용할 수 있다.
