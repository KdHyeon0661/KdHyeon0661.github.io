# 리눅스와 윈도우 연동

## Samba: 리눅스에서 Windows 파일 공유 서버 만들기

Samba는 리눅스 시스템이 Windows와 파일을 공유할 수 있게 해주는 소프트웨어다. 윈도우 클라이언트가 네트워크를 통해 리눅스 서버의 파일에 접근할 수 있다.

### 설치

**Debian/Ubuntu 계열**:
```bash
sudo apt update
sudo apt install samba samba-common-bin
```

**RHEL/CentOS/Fedora 계열**:
```bash
sudo dnf install samba samba-common samba-client
```

### 기본 구성

Samba의 주요 설정 파일은 `/etc/samba/smb.conf`다. 크게 두 부분으로 나뉜다:
- `[global]`: 서버 전체 설정
- `[공유이름]`: 각 공유 디렉터리 설정

**간단한 공유 예시**:
```ini
[global]
   workgroup = WORKGROUP
   server string = %h Samba Server
   security = user
   map to guest = Bad User

[share]
   path = /srv/samba/share
   browsable = yes
   read only = no
   guest ok = yes
```

### 공유 디렉터리 준비

```bash
sudo mkdir -p /srv/samba/share
sudo chown -R nobody:nogroup /srv/samba/share   # 게스트 접근용
sudo chmod -R 0755 /srv/samba/share
```

### Samba 사용자 등록 (게스트 접근 제한 시)

```bash
# 시스템 계정 생성
sudo useradd -m filesvc
sudo passwd filesvc

# Samba 전용 계정 등록
sudo smbpasswd -a filesvc

# 등록된 사용자 확인
sudo pdbedit -L
```

공유 설정에서 게스트 접근을 제한하려면:
```ini
[share]
   guest ok = no
   valid users = filesvc
```

### 서비스 시작 및 확인

```bash
# 설정 파일 문법 검사
sudo testparm

# 서비스 시작 및 활성화
sudo systemctl enable --now smbd

# 공유 목록 확인
smbclient -L localhost -U filesvc
```

### 윈도우 클라이언트에서 접속

- 파일 탐색기 주소창에 `\\리눅스서버IP\share` 입력
- 필요 시 사용자 이름과 비밀번호 입력

## 리눅스에서 Windows 공유 마운트 (CIFS)

리눅스에서 Windows의 공유 폴더를 사용하려면 CIFS(Common Internet File System)를 이용한다.

### 수동 마운트

```bash
# 마운트 포인트 생성
sudo mkdir -p /mnt/wshare

# Windows 공유 마운트
sudo mount -t cifs //192.168.0.10/projects /mnt/wshare \
  -o username=winuser,password=winpass,uid=1000,gid=1000,vers=3.0
```

**주요 옵션**:
- `vers=3.0`: SMB 3.0 프로토콜 사용 (보안과 성능 향상)
- `uid/gid`: 마운트된 파일의 소유자/그룹 설정
- `credentials`: 인증 정보 파일 경로 (보안)

### 인증 정보 파일 사용 (보안)

```bash
# 인증 정보 파일 생성
sudo tee /etc/samba/creds-wshare > /dev/null <<EOF
username=winuser
password=winpass
domain=EXAMPLE
EOF
sudo chmod 600 /etc/samba/creds-wshare
```

마운트 명령:
```bash
sudo mount -t cifs //192.168.0.10/projects /mnt/wshare \
  -o credentials=/etc/samba/creds-wshare,uid=1000,gid=1000,vers=3.0
```

### 자동 마운트 (`/etc/fstab`)

```fstab
//192.168.0.10/projects  /mnt/wshare  cifs  credentials=/etc/samba/creds-wshare,uid=1000,gid=1000,vers=3.0,_netdev  0  0
```

`_netdev` 옵션은 네트워크가 준비된 후 마운트를 시도하도록 한다.

## WSL (Windows Subsystem for Linux) 환경

WSL은 Windows에서 리눅스를 실행할 수 있는 환경이다.

### Windows 드라이브 접근

WSL은 Windows 드라이브를 `/mnt/c`, `/mnt/d` 등에 자동으로 마운트한다. 성능과 권한을 위해 `/etc/wsl.conf`를 구성할 수 있다.

```ini
# /etc/wsl.conf
[automount]
enabled = true
options = "metadata,uid=1000,gid=1000,umask=022,fmask=0111,case=off"

[interop]
appendWindowsPath = false
```

- `metadata`: POSIX 권한/소유권을 NTFS 확장 속성에 저장 (chmod/chown 사용 가능)
- `case=off`: 대소문자 구분 비활성화 (Windows 앱과 호환성)
- `appendWindowsPath=false`: WSL PATH에 Windows 경로 자동 추가 방지

변경사항 적용 후 WSL 재시작:
```powershell
wsl --shutdown
wsl
```

### Windows에서 WSL 파일 접근

Windows 파일 탐색기에서 `\\wsl.localhost\Ubuntu\home\사용자명`으로 WSL 내 파일에 접근할 수 있다.

## 권한 문제 해결 핵심

| 문제 | 원인 | 해결 |
|------|------|------|
| 접근 거부 | Samba 사용자 미등록, 유효 사용자 미설정 | `smbpasswd -a`로 계정 등록, `valid users` 확인 |
| 파일 권한 불일치 | POSIX ACL과 Windows ACL 매핑 문제 | `vfs objects = acl_xattr`, `map acl inherit = yes` 추가 |
| CIFS 마운트 실패 | 프로토콜 버전 불일치, 인증 실패 | `vers=3.0`, `sec=ntlmssp` 옵션 시도, `dmesg | grep CIFS`로 오류 확인 |

## 주요 명령어 요약

| 작업 | 명령어 |
|------|--------|
| Samba 구성 검증 | `testparm` |
| Samba 사용자 등록 | `sudo smbpasswd -a 사용자` |
| Samba 서비스 제어 | `systemctl start\|stop\|restart smbd` |
| 공유 목록 확인 | `smbclient -L localhost -U 사용자` |
| CIFS 마운트 | `mount -t cifs //서버/공유 /마운트점 -o 옵션` |
| 현재 연결 확인 | `smbstatus` |
| WSL 구성 | `/etc/wsl.conf`, `wsl --shutdown` |

## 결론

리눅스와 윈도우 간 파일 공유는 Samba와 CIFS를 통해 가능하다.

- **Samba 서버**: 리눅스를 파일 서버로 만들어 윈도우 클라이언트가 접근할 수 있게 한다.
- **CIFS 클라이언트**: 리눅스에서 윈도우 공유를 마운트해 사용한다.
- **WSL**: Windows 위에서 리눅스를 실행하며, 두 운영체제 간 파일 시스템을 자연스럽게 공유할 수 있다.

초기에는 간단한 게스트 공유부터 시작해, 점차 사용자 인증, 권한 매핑, 자동 마운트 등으로 확장하면 된다. 문제 발생 시 `testparm`과 `smbstatus`로 구성과 세션을 확인하고, 로그(`journalctl -u smbd`)를 참고하면 원인을 빠르게 파악할 수 있다.
