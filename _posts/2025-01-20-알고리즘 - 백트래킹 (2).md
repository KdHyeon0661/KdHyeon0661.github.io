# 백트래킹으로 부분집합 탐색하기

백트래킹은 가능한 모든 조합을 탐색하면서 조건에 맞지 않으면 더 이상 진행하지 않고 되돌아오는 기법이다. 부분집합 문제는 백트래킹의 가장 기본적인 형태로, 원소를 포함하거나 포함하지 않는 두 가지 선택을 반복하며 모든 경우를 탐색한다.

## 기본 개념

원소가 \(n\)개인 집합의 부분집합 개수는 \(2^n\)이다. 각 원소에 대해 “포함한다” 또는 “포함하지 않는다” 두 가지 결정을 내리기 때문이다. 예를 들어 \([1,2,3]\)의 부분집합은 8개이다.

```
[] [1] [2] [3] [1,2] [1,3] [2,3] [1,2,3]
```

백트래킹은 이 결정 트리를 깊이 우선으로 탐색하며, 중간에 조건을 위반하면 더 깊이 들어가지 않는다.

---

## 기본 구현 2가지

### 1. 포함/미포함 재귀

가장 직관적인 방식이다. 각 원소를 선택하거나 건너뛰는 두 가지 분기로 탐색한다.

```python
def subsets(arr):
    result = []
    path = []
    n = len(arr)

    def dfs(i):
        if i == n:
            result.append(path[:])
            return
        # 미포함
        dfs(i + 1)
        # 포함
        path.append(arr[i])
        dfs(i + 1)
        path.pop()

    dfs(0)
    return result
```

- 시간 복잡도: \(O(2^n)\) (모든 부분집합 방문)
- 공간 복잡도: \(O(n)\) (재귀 스택 깊이)

### 2. 비트마스크

재귀 없이 반복문만으로 모든 부분집합을 생성할 수 있다. 정수 0부터 \(2^n - 1\)까지의 비트 패턴을 이용한다.

```python
def subsets_bitmask(arr):
    n = len(arr)
    result = []
    for mask in range(1 << n):
        sub = [arr[i] for i in range(n) if mask & (1 << i)]
        result.append(sub)
    return result
```

- 장점: 구현이 간단하고, 특정 조건을 만족하는 부분집합을 빠르게 셀 수 있다.

---

## 프루닝(가지치기)

백트래킹의 핵심은 탐색 중에 더 이상 해가 될 수 없는 경로를 미리 차단하는 것이다. 대표적인 프루닝 조건은 다음과 같다.

| 상황 | 프루닝 조건 |
|------|-----------|
| 합이 목표를 초과 | 현재 합 > 목표값 → 중단 |
| 남은 원소를 다 더해도 목표 미달 | 현재 합 + 남은 최대합 < 목표 → 중단 |
| 선택 개수 제한 | 이미 선택한 개수 + 남은 원소 수 < 필요 개수 → 중단 |
| 중복 원소 | 같은 레벨에서 같은 값을 두 번 선택하지 않음 |

### 합 제약이 있는 부분집합 (예: 합이 S인 부분집합)

```python
def count_sum_subsets(arr, target):
    arr.sort(reverse=True)           # 상한 컷을 위해 내림차순
    n = len(arr)
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i+1] = prefix[i] + arr[i]

    ans = 0
    def dfs(i, current_sum):
        nonlocal ans
        if current_sum == target:
            ans += 1
            return
        if i == n or current_sum > target:
            return
        # 남은 최대합으로도 목표에 도달할 수 없으면 중단
        if current_sum + (prefix[n] - prefix[i]) < target:
            return
        # 포함
        dfs(i + 1, current_sum + arr[i])
        # 미포함
        dfs(i + 1, current_sum)

    dfs(0, 0)
    return ans
```

이때 내림차순 정렬은 빨리 합이 커지게 해서 조기 컷을 유도한다. `prefix` 배열은 남은 원소의 최대합을 빠르게 계산하기 위한 전처리다.

## 중복 원소 처리

입력 배열에 중복된 값이 있을 때, 단순히 포함/미포함을 적용하면 같은 부분집합이 여러 번 생성된다. 이를 방지하려면 배열을 정렬한 후, 같은 깊이에서 같은 값이 연속으로 나올 때 첫 번째만 선택하도록 한다.

```python
def subsets_unique(arr):
    arr.sort()
    result = []
    path = []

    def dfs(start):
        result.append(path[:])          # 현재 부분집합 저장
        for i in range(start, len(arr)):
            # 이전과 같은 값이면 스킵
            if i > start and arr[i] == arr[i-1]:
                continue
            path.append(arr[i])
            dfs(i + 1)
            path.pop()

    dfs(0)
    return result
```

이 방식은 **조합(combination)** 을 생성하는 것과 같으며, 결과는 자연스럽게 사전순으로 정렬된다.

---

## 길이 제한: k-조합

길이가 정확히 k인 부분집합만 필요할 때는 `start` 인덱스를 이용해 조합을 생성한다.

```python
def combinations(arr, k):
    result = []
    path = []
    n = len(arr)

    def dfs(start):
        if len(path) == k:
            result.append(path[:])
            return
        # 남은 원소 수가 필요 개수보다 적으면 더 이상 진행 불가
        need = k - len(path)
        for i in range(start, n - need + 1):
            path.append(arr[i])
            dfs(i + 1)
            path.pop()

    dfs(0)
    return result
```

루프의 상한 `n - need + 1`은 필요한 개수를 채울 수 없는 구간을 미리 잘라내는 프루닝 역할을 한다.

## 실전 예제: 암호 만들기 (BOJ 1759)

문제: 서로 다른 알파벳이 주어졌을 때, 최소 한 개의 모음과 두 개의 자음으로 이루어진 길이 L의 암호를 모두 사전순으로 출력한다.

해결 전략: 전체 알파벳을 정렬한 뒤 길이 L의 조합을 만들고, 모음/자음 조건을 만족하는 것만 출력한다. 백트래킹 단계에서 조건을 미리 확인할 수도 있지만, 조합 생성 후 필터링해도 충분히 효율적이다.

```python
def generate_passwords(chars, L):
    chars.sort()
    vowels = set('aeiou')
    result = []

    def dfs(start, path):
        if len(path) == L:
            v_cnt = sum(1 for ch in path if ch in vowels)
            if v_cnt >= 1 and (L - v_cnt) >= 2:
                result.append(''.join(path))
            return
        for i in range(start, len(chars)):
            path.append(chars[i])
            dfs(i + 1, path)
            path.pop()

    dfs(0, [])
    return result
```

## 언제 백트래킹을 사용할까?

| 문제 유형 | 백트래킹 적용 이유 |
|----------|-----------------|
| 모든 조합/순열 탐색 | 완전 탐색이 필요하지만 가지치기로 효율화 가능 |
| 제약 조건이 있는 선택 | 조건을 위반하면 즉시 중단하여 탐색 공간 축소 |
| n이 20~30 정도 | \(2^n\)이 약 100만~10억으로 가지치기에 따라 해결 가능 |
| 최적해 탐색 | 브랜치 앤 바운드와 함께 사용 (최대합, 최소비용 등) |

---

## 마무리

부분집합 탐색은 백트래킹의 첫걸음이다. 포함/미포함 재귀와 비트마스크 두 가지 기본 방식을 익히고, 가지치기와 중복 처리 방법을 함께 이해하면 대부분의 조합 탐색 문제를 해결할 수 있다. 실전에서는 입력 크기와 제약 조건을 먼저 확인한 후, 단순 열거가 가능한지 아니면 가지치기가 필수인지를 판단하는 것이 중요하다.
