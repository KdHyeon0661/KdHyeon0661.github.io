# 스택의 기본과 활용

## 스택이란?

스택(Stack)은 **한쪽 끝에서만 데이터를 넣고(push) 빼는(pop)** 자료구조다.  
마지막에 넣은 데이터가 가장 먼저 나오는 **LIFO(Last-In-First-Out)** 원칙을 따른다.

- **push**: 스택의 맨 위에 원소 추가  
- **pop**: 스택의 맨 위 원소 제거 및 반환  
- **top/peek**: 맨 위 원소 확인 (제거하지 않음)  
- **empty**: 스택이 비어있는지 확인

파이썬에서는 리스트(list)를 스택처럼 사용할 수 있다.  
`append()`가 push, `pop()`이 pop 역할을 하며, 둘 다 $$O(1)$$ 시간에 동작한다.

---

## 스택을 사용하는 이유

스택은 **가장 최근에 들어온 정보를 먼저 처리해야 하는 상황**에서 자연스럽게 쓰인다.

- 함수 호출과 복귀 (재귀 호출 스택)  
- 실행 취소(Undo) 기능  
- 브라우저 뒤로 가기  
- 괄호 짝 맞추기  
- 수식 계산 (후위 표기법)  
- 깊이 우선 탐색(DFS)의 반복적 구현

---

## 괄호 검사: 스택의 가장 기본적인 예

문자열에 포함된 괄호 `(`, `)`, `{`, `}`, `[`, `]`가 올바르게 짝을 이루고 있는지 검사하는 문제다.  
여는 괄호가 나오면 스택에 넣고, 닫는 괄호가 나오면 스택에서 가장 최근의 여는 괄호와 짝이 맞는지 확인한다.

```python
def valid_brackets(s):
    pair = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in ')]}':
            if not stack or stack[-1] != pair[ch]:
                return False
            stack.pop()
    return not stack
```

**동작 원리**  
- 여는 괄호는 모두 스택에 쌓는다.  
- 닫는 괄호를 만나면 스택의 top에 있는 여는 괄호와 비교한다.  
  - 짝이 맞으면 pop  
  - 짝이 맞지 않거나 스택이 비어 있으면 잘못된 문자열  
- 모든 문자를 처리한 뒤 스택이 비어 있어야 올바르다.

## DFS(깊이 우선 탐색)를 스택으로 구현하기

그래프를 탐색하는 방법 중 하나인 DFS는 재귀 호출로 쉽게 구현할 수 있지만, 재귀 깊이가 너무 깊어지면 파이썬의 재귀 한도를 초과할 수 있다.  
이런 경우 **명시적인 스택**을 사용하여 반복문으로 구현할 수 있다.

```python
def dfs_stack(graph, start):
    visited = set()
    stack = [start]
    while stack:
        u = stack.pop()
        if u in visited:
            continue
        visited.add(u)
        print(u, end=' ')
        # 인접 정점을 역순으로 넣어야 방문 순서를 제어할 수 있다
        for v in sorted(graph[u], reverse=True):
            if v not in visited:
                stack.append(v)
```

**설명**  
- 스택에 시작 정점을 넣고, 스택이 빌 때까지 반복한다.  
- 스택에서 꺼낸 정점을 방문 처리하고, 아직 방문하지 않은 인접 정점을 스택에 넣는다.  
- 인접 정점을 넣을 때 순서를 조정하면 방문 순서를 원하는 대로 바꿀 수 있다.

## 중위 표기식을 후위 표기식으로 변환 (Shunting Yard 알고리즘)

사람이 보기 편한 `3 + 4 * 2` 같은 중위 표기식을 컴퓨터가 쉽게 계산할 수 있는 후위 표기식 `3 4 2 * +`으로 바꾸는 데 스택을 사용한다.

### 기본 아이디어
- 피연산자는 바로 출력한다.  
- 연산자는 스택에 임시 저장하다가, 우선순위가 더 높은 연산자가 나오면 먼저 출력한다.  
- 괄호는 별도로 처리한다.

```python
def infix_to_postfix(expr):
    prec = {'+': 1, '-': 1, '*': 2, '/': 2}
    stack = []
    output = []
    for ch in expr:
        if ch.isdigit():
            output.append(ch)
        elif ch == '(':
            stack.append(ch)
        elif ch == ')':
            while stack and stack[-1] != '(':
                output.append(stack.pop())
            stack.pop()  # '(' 제거
        else:  # 연산자
            while stack and stack[-1] != '(' and prec[ch] <= prec.get(stack[-1], 0):
                output.append(stack.pop())
            stack.append(ch)
    while stack:
        output.append(stack.pop())
    return ''.join(output)
```

### 후위 표기식 계산

후위 표기식은 스택으로 쉽게 계산할 수 있다.  
피연산자는 스택에 넣고, 연산자를 만나면 피연산자 두 개를 꺼내 계산한 뒤 결과를 다시 스택에 넣는다.

```python
def eval_postfix(expr):
    stack = []
    for ch in expr:
        if ch.isdigit():
            stack.append(int(ch))
        else:
            b = stack.pop()
            a = stack.pop()
            if ch == '+':
                stack.append(a + b)
            elif ch == '-':
                stack.append(a - b)
            elif ch == '*':
                stack.append(a * b)
            elif ch == '/':
                stack.append(a // b)   # 정수 나눗셈
    return stack.pop()
```

## 오큰수 (Next Greater Element)

배열의 각 원소에 대해 **오른쪽에 있으면서 더 큰 수 중 가장 왼쪽에 있는 수**를 찾는 문제다.  
스택을 이용하면 $$O(n)$$에 해결할 수 있다.

```python
def next_greater(arr):
    n = len(arr)
    result = [-1] * n
    stack = []   # 인덱스를 저장
    for i in range(n):
        while stack and arr[stack[-1]] < arr[i]:
            idx = stack.pop()
            result[idx] = arr[i]
        stack.append(i)
    return result
```

**작동 원리**  
- 스택에는 아직 오큰수를 찾지 못한 인덱스들이 내림차순으로 쌓인다.  
- 현재 원소가 스택 top의 원소보다 크면, 그 top의 오큰수를 현재 원소로 결정하고 pop한다.  
- 이 과정을 반복한 뒤 현재 인덱스를 스택에 넣는다.

## 히스토그램에서 가장 큰 직사각형

높이가 담긴 배열이 주어졌을 때, 연속된 막대들로 만들 수 있는 가장 넓은 직사각형의 넓이를 구하는 문제다.  
스택을 사용하면 $$O(n)$$에 풀 수 있다.

```python
def largest_rectangle(heights):
    stack = []
    max_area = 0
    heights.append(0)   # 끝을 처리하기 위한 센티넬
    for i, h in enumerate(heights):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            max_area = max(max_area, height * width)
        stack.append(i)
    heights.pop()
    return max_area
```

**아이디어**  
- 스택에는 높이가 증가하는 순서로 인덱스를 유지한다.  
- 현재 높이보다 큰 높이가 스택에 있으면, 그 높이를 기준으로 확장 가능한 너비를 계산한다.  
- 모든 막대를 처리한 뒤에도 스택에 남은 것들을 마저 계산한다.

## 스택 변형: 최솟값을 $$O(1)$$에 알 수 있는 MinStack

스택의 기본 연산(push, pop, top)에 추가로 **현재 스택에 있는 최솟값**을 $$O(1)$$에 반환하는 자료구조를 만들 수 있다.

```python
class MinStack:
    def __init__(self):
        self.stack = []          # (값, 현재까지의 최솟값)

    def push(self, x):
        if not self.stack:
            self.stack.append((x, x))
        else:
            cur_min = min(x, self.stack[-1][1])
            self.stack.append((x, cur_min))

    def pop(self):
        self.stack.pop()

    def top(self):
        return self.stack[-1][0]

    def getMin(self):
        return self.stack[-1][1]
```

**동작**  
- 각 원소를 저장할 때, 해당 원소가 들어간 시점의 최솟값을 함께 저장한다.  
- `getMin`은 스택 top의 최솟값을 바로 반환한다.

## 두 개의 스택으로 큐 구현하기

스택 두 개를 사용하여 큐(FIFO)의 동작을 구현할 수 있다.

```python
class QueueWithTwoStacks:
    def __init__(self):
        self.in_stack = []
        self.out_stack = []

    def push(self, x):
        self.in_stack.append(x)

    def _transfer(self):
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())

    def pop(self):
        self._transfer()
        return self.out_stack.pop()

    def peek(self):
        self._transfer()
        return self.out_stack[-1]

    def empty(self):
        return not self.in_stack and not self.out_stack
```

**아이디어**  
- `in_stack`에 새 원소를 계속 넣는다.  
- `pop`이나 `peek`이 호출되면, `out_stack`이 비어있을 때 `in_stack`의 모든 원소를 옮겨 담는다.  
- 이렇게 하면 `out_stack`의 top이 가장 먼저 들어온 원소가 된다.

## 스택을 선택하는 기준

| 문제 상황 | 스택이 적합한 이유 |
|-----------|-------------------|
| 괄호 검사, 태그 매칭 | 가장 최근에 열린 요소를 먼저 닫아야 함 |
| DFS (깊이 우선 탐색) | 경로를 따라 깊게 들어간 후 되돌아오는 구조 |
| 후위 표기식 계산 | 연산자와 피연산자의 순서가 LIFO에 맞음 |
| 오큰수, 히스토그램 | 아직 처리되지 않은 원소들의 후보를 유지하며 순서대로 처리 |

---

## 실전 팁

- **파이썬 리스트를 스택으로 사용할 때** `list.pop()`은 빈 리스트에서 호출하면 오류가 발생하므로 반드시 `if stack:`으로 비어 있는지 확인한다.
- **입력이 큰 경우** `sys.stdin.readline`을 사용하고, 출력이 많다면 `sys.stdout.write`나 리스트에 모아 한 번에 출력한다.
- **재귀 깊이 문제**가 발생할 수 있는 DFS는 스택을 이용한 반복문으로 구현하는 것이 안전하다.

## 테스트를 위한 간단한 예제

```python
# 괄호 검사
print(valid_brackets("()[]{}"))   # True
print(valid_brackets("([)]"))     # False

# 오큰수
arr = [3, 5, 2, 7]
print(next_greater(arr))          # [5, 7, 7, -1]

# 히스토그램
heights = [2, 1, 4, 5, 1, 3, 3]
print(largest_rectangle(heights)) # 8
```

## 마무리

스택은 매우 단순하지만 다양한 알고리즘에서 핵심적인 역할을 한다.  
괄호 검사, DFS, 수식 계산, 모노토닉 스택 등을 익히면 복잡한 문제도 체계적으로 접근할 수 있다.  
처음에는 괄호 검사 같은 기본 예제로 스택의 동작에 익숙해지고, 점차 오큰수나 히스토그램처럼 응용 문제로 확장해 나가기를 권한다.
