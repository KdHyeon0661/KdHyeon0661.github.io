# Avalonia에서 다크/라이트 모드 전환 기능 구현

Avalonia 애플리케이션에서 사용자에게 테마(라이트/다크) 전환 기능을 제공하려면, 색상과 브러시를 런타임에 교체할 수 있는 구조가 필요합니다. 이 글에서는 리소스 사전(ResourceDictionary)을 활용한 테마 관리, 사용자 설정 저장, MVVM 패턴을 통한 UI 제어까지 단계별로 설명합니다.

---

## 전체 구조

```
MyAvaloniaApp/
├── Themes/
│   ├── LightTheme.axaml          # 라이트 모드 색상/브러시
│   └── DarkTheme.axaml           # 다크 모드 색상/브러시
├── Services/
│   ├── ISettingsService.cs
│   ├── SettingsService.cs
│   └── ThemeService.cs           # 테마 로딩/교체 로직
├── ViewModels/
│   └── ThemeViewModel.cs
├── Views/
│   └── ThemeToggleView.axaml
├── Models/
│   └── AppSettings.cs
├── App.axaml
└── Program.cs
```

이 구조에서 핵심은 `Themes` 폴더에 각 테마별 리소스 사전을 두고, `ThemeService`가 런타임에 이 사전들을 교체하는 방식입니다. 사용자 선택은 `SettingsService`로 파일에 저장하고, 앱 재시작 시 복원합니다.

---

## 테마 리소스 사전 만들기

### 색상과 브러시의 역할 분리

Avalonia에서 테마를 구성할 때는 색상(Color)과 브러시(Brush)를 분리하는 것이 좋습니다. 색상은 원색(hex) 값을 저장하고, 브러시는 해당 색상을 참조합니다. 이렇게 하면 나중에 색상만 바꿔도 모든 브러시가 자동으로 갱신됩니다.

#### 라이트 테마 (Themes/LightTheme.axaml)

```xml
<ResourceDictionary xmlns="https://github.com/avaloniaui">
  <!-- 테마 식별 마커: 런타임 교체 시 이 키로 현재 테마를 찾음 -->
  <x:String xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" x:Key="__ThemeMarker">Light</x:String>

  <!-- 색상 팔레트 -->
  <Color x:Key="Color.Background">#FFFFFFFF</Color>
  <Color x:Key="Color.Foreground">#FF101010</Color>
  <Color x:Key="Color.Accent">#FF0067C0</Color>
  <Color x:Key="Color.Border">#FFE0E0E0</Color>

  <!-- 브러시: DynamicResource로 색상을 참조 -->
  <SolidColorBrush x:Key="Brush.Background" Color="{DynamicResource Color.Background}" />
  <SolidColorBrush x:Key="Brush.Foreground" Color="{DynamicResource Color.Foreground}" />
  <SolidColorBrush x:Key="Brush.Accent"     Color="{DynamicResource Color.Accent}" />
  <SolidColorBrush x:Key="Brush.Border"     Color="{DynamicResource Color.Border}" />
</ResourceDictionary>
```

#### 다크 테마 (Themes/DarkTheme.axaml)

```xml
<ResourceDictionary xmlns="https://github.com/avaloniaui">
  <x:String xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml" x:Key="__ThemeMarker">Dark</x:String>

  <Color x:Key="Color.Background">#FF1E1E1E</Color>
  <Color x:Key="Color.Foreground">#FFF1F1F1</Color>
  <Color x:Key="Color.Accent">#FF3399FF</Color>
  <Color x:Key="Color.Border">#FF2A2A2A</Color>

  <SolidColorBrush x:Key="Brush.Background" Color="{DynamicResource Color.Background}" />
  <SolidColorBrush x:Key="Brush.Foreground" Color="{DynamicResource Color.Foreground}" />
  <SolidColorBrush x:Key="Brush.Accent"     Color="{DynamicResource Color.Accent}" />
  <SolidColorBrush x:Key="Brush.Border"     Color="{DynamicResource Color.Border}" />
</ResourceDictionary>
```

**설명**  
- `__ThemeMarker` 키는 현재 적용된 테마가 무엇인지 식별하기 위한 용도입니다. 테마 교체 시 이 키를 가진 리소스 사전을 찾아 제거합니다.  
- `DynamicResource`를 사용하면 런타임에 참조하는 색상이 바뀌면 브러시도 자동으로 갱신됩니다.  
- 키 이름에 접두어(`Color.`, `Brush.`)를 붙여 충돌을 방지하고, 대규모 프로젝트에서 일관성을 유지할 수 있습니다.

## 앱 초기 설정 (App.axaml)

`App.axaml`에서는 기본 테마(라이트)를 `Application.Resources.MergedDictionaries`에 포함시킵니다. 또한 `FluentTheme`를 통해 컨트롤의 기본 룩앤필을 지정합니다.

```xml
<Application xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             x:Class="MyAvaloniaApp.App">
  <Application.Styles>
    <FluentTheme Mode="Light"/>
  </Application.Styles>

  <Application.Resources>
    <ResourceDictionary>
      <ResourceDictionary.MergedDictionaries>
        <ResourceInclude Source="avares://MyAvaloniaApp/Themes/LightTheme.axaml" />
      </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
  </Application.Resources>
</Application>
```

**주의**  
- 테마 리소스는 `Application.Resources.MergedDictionaries`에 추가해야 합니다. `Application.Styles`에 넣으면 스타일로 취급되어 리소스 교체가 제대로 이루어지지 않을 수 있습니다.  
- `FluentTheme`는 컨트롤의 기본 모양(버튼, 텍스트박스 등)을 제공하며, 별도의 테마와 함께 사용할 수 있습니다.

## 테마 교체 서비스 (ThemeService)

`ThemeService`는 현재 테마 리소스 사전을 찾아 제거하고, 새 테마 사전을 추가하는 역할을 합니다. 마커 키(`__ThemeMarker`)를 이용해 기존 테마 사전을 정확히 식별합니다.

```csharp
using Avalonia;
using Avalonia.Markup.Xaml;
using System;
using System.Linq;

namespace MyAvaloniaApp.Services;

public static class ThemeService
{
    private const string ThemeMarkerKey = "__ThemeMarker";

    public static string? CurrentThemeName
        => FindThemeDictionary()?.ContainsKey(ThemeMarkerKey) == true
           ? FindThemeDictionary()?[ThemeMarkerKey]?.ToString()
           : null;

    public static void ApplyTheme(string themeName) // "Light" 또는 "Dark"
    {
        var app = Application.Current ?? throw new InvalidOperationException("Application not ready.");
        var resources = app.Resources;

        // 1) 기존 테마 사전 제거
        var existing = FindThemeDictionary();
        if (existing != null)
            resources.MergedDictionaries.Remove(existing);

        // 2) 새 테마 로드
        var uri = themeName.Equals("Dark", StringComparison.OrdinalIgnoreCase)
            ? new Uri("avares://MyAvaloniaApp/Themes/DarkTheme.axaml")
            : new Uri("avares://MyAvaloniaApp/Themes/LightTheme.axaml");

        var include = new ResourceInclude(uri) { Source = uri };
        resources.MergedDictionaries.Add(include);
    }

    private static ResourceDictionary? FindThemeDictionary()
    {
        var app = Application.Current;
        if (app == null) return null;

        return app.Resources.MergedDictionaries
            .OfType<ResourceDictionary>()
            .FirstOrDefault(d => d.ContainsKey(ThemeMarkerKey));
    }
}
```

**동작 설명**  
- `FindThemeDictionary()`는 `MergedDictionaries` 중에서 `__ThemeMarker` 키를 가진 사전을 찾습니다.  
- `ApplyTheme()`는 찾은 사전을 제거한 후, 새 테마 파일을 `ResourceInclude`로 로드하여 추가합니다.  
- `ResourceInclude`의 `Source`에 `avares://` URI를 사용하면 어셈블리 내 리소스를 정확히 참조할 수 있습니다.

## 사용자 설정 저장 (SettingsService)

사용자가 선택한 테마를 저장하고 복원하기 위해 `ISettingsService` 인터페이스와 JSON 파일 기반 구현을 만듭니다.

### 모델 (Models/AppSettings.cs)

```csharp
namespace MyAvaloniaApp.Models;

public sealed class AppSettings
{
    public bool IsDarkMode { get; set; }
}
```

### 인터페이스 (Services/ISettingsService.cs)

```csharp
using System.Threading.Tasks;
using MyAvaloniaApp.Models;

namespace MyAvaloniaApp.Services;

public interface ISettingsService
{
    Task SaveAsync(AppSettings settings);
    Task<AppSettings> LoadAsync();
}
```

### 구현 (Services/SettingsService.cs)

```csharp
using System.IO;
using System.Text.Json;
using System.Threading.Tasks;
using MyAvaloniaApp.Models;

namespace MyAvaloniaApp.Services;

public sealed class SettingsService : ISettingsService
{
    private const string FileName = "appsettings.json";

    public async Task SaveAsync(AppSettings settings)
    {
        var json = JsonSerializer.Serialize(settings, new JsonSerializerOptions { WriteIndented = true });
        await File.WriteAllTextAsync(FileName, json);
    }

    public async Task<AppSettings> LoadAsync()
    {
        if (!File.Exists(FileName))
            return new AppSettings { IsDarkMode = false };

        var json = await File.ReadAllTextAsync(FileName);
        return JsonSerializer.Deserialize<AppSettings>(json) ?? new AppSettings();
    }
}
```

## ViewModel: 테마 전환 로직 (ThemeViewModel)

`ThemeViewModel`은 사용자 인터페이스(토글 스위치)와 비즈니스 로직(테마 교체, 저장, 복원)을 연결합니다. ReactiveUI를 사용하여 명령과 속성 변경을 처리합니다.

```csharp
using ReactiveUI;
using System.Reactive;
using System.Threading.Tasks;
using MyAvaloniaApp.Models;
using MyAvaloniaApp.Services;

namespace MyAvaloniaApp.ViewModels;

public sealed class ThemeViewModel : ReactiveObject
{
    private readonly ISettingsService _settings;
    private bool _isDark;

    public bool IsDark
    {
        get => _isDark;
        set => this.RaiseAndSetIfChanged(ref _isDark, value);
    }

    public ReactiveCommand<Unit, Unit> ApplyCommand { get; }
    public ReactiveCommand<Unit, Unit> SaveCommand  { get; }
    public ReactiveCommand<Unit, Unit> LoadCommand  { get; }

    public ThemeViewModel()
        : this(new SettingsService()) {}

    public ThemeViewModel(ISettingsService settings)
    {
        _settings = settings;

        ApplyCommand = ReactiveCommand.Create(ApplyTheme);
        SaveCommand  = ReactiveCommand.CreateFromTask(SaveAsync);
        LoadCommand  = ReactiveCommand.CreateFromTask(LoadAsync);
    }

    private void ApplyTheme()
    {
        ThemeService.ApplyTheme(IsDark ? "Dark" : "Light");
        // (선택) FluentTheme의 테마 변형도 함께 변경
        // var app = Avalonia.Application.Current;
        // app!.RequestedThemeVariant = IsDark ? ThemeVariant.Dark : ThemeVariant.Light;
    }

    private async Task SaveAsync()
    {
        await _settings.SaveAsync(new AppSettings { IsDarkMode = IsDark });
    }

    private async Task LoadAsync()
    {
        var s = await _settings.LoadAsync();
        IsDark = s.IsDarkMode;
        ApplyTheme();   // 로드 후 즉시 테마 적용
    }
}
```

**핵심**  
- `ApplyTheme()`는 `ThemeService`를 호출해 현재 `IsDark` 값에 따라 테마를 교체합니다.  
- `LoadAsync()`는 저장된 설정을 읽어 `IsDark`를 설정한 후 테마를 적용합니다.  
- `SaveAsync()`는 현재 상태를 파일에 저장합니다.

## 뷰: 테마 토글 UI (ThemeToggleView)

뷰는 `ToggleSwitch`로 다크 모드 여부를 선택하고, 버튼으로 테마 적용, 저장, 불러오기를 수행합니다. 배경, 텍스트, 테두리 등이 현재 테마 리소스(`DynamicResource`)를 사용하도록 설정합니다.

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:vm="using:MyAvaloniaApp.ViewModels"
             x:Class="MyAvaloniaApp.Views.ThemeToggleView"
             Width="360" Height="160">

  <UserControl.DataContext>
    <vm:ThemeViewModel/>
  </UserControl.DataContext>

  <StackPanel Margin="20" Spacing="8"
              Background="{DynamicResource Brush.Background}">
    <TextBlock Text="테마 전환"
               Foreground="{DynamicResource Brush.Foreground}"
               FontSize="18" />

    <ToggleSwitch IsChecked="{Binding IsDark}"
                  Content="다크 모드"
                  Foreground="{DynamicResource Brush.Foreground}"/>

    <StackPanel Orientation="Horizontal" Spacing="8">
      <Button Content="테마 적용" Command="{Binding ApplyCommand}"/>
      <Button Content="저장" Command="{Binding SaveCommand}"/>
      <Button Content="불러오기" Command="{Binding LoadCommand}"/>
    </StackPanel>

    <Border BorderBrush="{DynamicResource Brush.Border}" BorderThickness="1" Padding="8">
      <TextBlock Text="프리뷰: 이 영역의 배경/전경/테두리는 현재 테마 리소스로 그려집니다."
                 Foreground="{DynamicResource Brush.Foreground}"
                 TextWrapping="Wrap"/>
    </Border>
  </StackPanel>
</UserControl>
```

**설명**  
- `Background`, `Foreground`, `BorderBrush` 등에 `{DynamicResource Brush.xxx}`를 사용하면 런타임에 리소스가 교체될 때 UI가 자동으로 업데이트됩니다.  
- `ToggleSwitch`의 `IsChecked`는 `IsDark` 속성과 양방향 바인딩되어 사용자 선택을 즉시 ViewModel에 반영합니다.

## 다른 뷰에서 테마 리소스 사용하기

테마가 적용된 리소스를 사용하려면, 다른 뷰에서도 동일한 `DynamicResource` 키를 사용하면 됩니다. 예를 들어 `MainView.axaml`에서:

```xml
<StackPanel Background="{DynamicResource Brush.Background}" Padding="20" Spacing="8">
  <TextBlock Text="테마 테스트" Foreground="{DynamicResource Brush.Foreground}" FontSize="22"/>
  <Button Content="확인" Background="{DynamicResource Brush.Accent}" />
  <Border BorderBrush="{DynamicResource Brush.Border}" BorderThickness="1" Height="1"/>
</StackPanel>
```

이렇게 작성하면 `ThemeService`가 리소스 사전을 교체할 때 모든 화면이 동시에 갱신됩니다.

## 추가 고려 사항

### FluentTheme의 ThemeVariant 병행

Avalonia의 내장 `FluentTheme`는 자체적으로 `ThemeVariant.Light` / `ThemeVariant.Dark`를 지원합니다. 이 변형을 함께 변경하면 버튼, 텍스트박스 등 기본 컨트롤의 스타일까지 일관되게 바뀝니다.

```csharp
// ThemeViewModel.ApplyTheme() 내부에 추가
var app = Avalonia.Application.Current;
if (app is not null)
    app.RequestedThemeVariant = IsDark ? ThemeVariant.Dark : ThemeVariant.Light;
```

### 시스템 테마 감지

앱 시작 시 운영체제의 테마를 감지하여 기본값으로 설정할 수 있습니다.

```csharp
// App.axaml.cs의 OnFrameworkInitializationCompleted()에서
var isSystemDark = Application.Current?.PlatformSettings?.GetColorValues()?.ThemeVariant == ThemeVariant.Dark;
ThemeService.ApplyTheme(isSystemDark == true ? "Dark" : "Light");
```

단, 사용자가 저장한 설정이 있다면 이를 최우선으로 적용해야 합니다. 보통은 설정을 로드한 후에 `LoadAsync()`를 호출하여 저장된 값을 반영하면 됩니다.

### 지역 테마 (Local Theme)

특정 창이나 컨트롤에만 다른 테마를 적용하려면 해당 요소의 `Resources.MergedDictionaries`에 테마 사전을 추가하면 됩니다. 이는 전역 테마와 독립적으로 작동합니다.

```xml
<Window ...>
  <Window.Resources>
    <ResourceDictionary>
      <ResourceDictionary.MergedDictionaries>
        <ResourceInclude Source="avares://MyAvaloniaApp/Themes/DarkTheme.axaml"/>
      </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
  </Window.Resources>
  <!-- 이 Window만 다크 테마 적용 -->
</Window>
```

## 문제 해결 체크리스트

| 문제 | 원인 | 해결책 |
|------|------|--------|
| 테마 교체 후 색상이 안 바뀜 | `StaticResource`를 사용함 | `DynamicResource`로 변경 |
| 테마 파일을 `Application.Styles`에 넣음 | 스타일과 리소스 역할 구분 오류 | `Application.Resources.MergedDictionaries`로 이동 |
| 기존 테마 사전이 제거되지 않음 | 마커 키가 없거나, `FindThemeDictionary` 로직 오류 | 각 테마 파일에 `__ThemeMarker` 키 포함 확인 |
| 저장/복원 순서 문제 | 앱 시작 시 저장된 설정을 적용하기 전에 다른 테마가 적용됨 | `LoadAsync()`를 가장 나중에 호출하거나, 로드 후 테마 적용 |

## 성능 및 설계 팁

- **`DynamicResource` 체인**: 색상 → 브러시 → 컨트롤 속성 순으로 연결하면 교체 시점에 모든 브러시가 한 번에 갱신됩니다.
- **키 네이밍 규칙**: `Color.`, `Brush.` 접두어를 붙여 충돌을 피하고, 대규모 프로젝트에서 일관성을 유지하세요.
- **스타일 분리**: 컨트롤의 템플릿(모양)은 별도 `Styles` 폴더에 두고, 색상/브러시만 테마 리소스에서 관리합니다.
- **테스트**: `ThemeService`는 단위 테스트에서 App 인스턴스가 필요하므로 통합 테스트 성격으로 작성하거나, App 초기화가 완료된 환경에서만 검증하세요.

## 결론

Avalonia에서 라이트/다크 모드 전환을 구현하는 핵심은 `Application.Resources.MergedDictionaries`를 런타임에 교체하는 것입니다. 리소스 사전을 테마별로 분리하고, `DynamicResource`를 사용하면 변경 사항이 즉시 UI에 반영됩니다. 사용자 설정은 `SettingsService`로 파일에 저장하고, `ThemeViewModel`에서 MVVM 패턴으로 UI와 로직을 연결하면 깔끔하게 구현할 수 있습니다. 이 구조를 바탕으로 추가적인 색상 테마(블루, 그린 등)나 하이 콘트라스트 모드로 확장하는 것도 쉽습니다.
