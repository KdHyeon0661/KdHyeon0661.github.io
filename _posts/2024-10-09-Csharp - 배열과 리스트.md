# C# 배열과 리스트

C#에서 여러 데이터를 하나의 집합으로 다룰 때 가장 기본적으로 사용하는 자료구조는 배열(Array)과 리스트(List<T>)입니다. 배열은 고정 크기의 연속 메모리 구조로, 인덱스를 통한 빠른 접근이 특징입니다. 리스트는 동적 크기를 지원하는 컬렉션으로, 내부적으로 배열을 관리하면서 요소 추가와 제거를 편리하게 처리합니다. 이 두 가지는 서로 다른 상황에 맞게 선택해야 하며, 각각의 내부 동작 방식을 이해하면 더 효율적인 코드를 작성할 수 있습니다.

---

## 배열

배열은 동일한 타입의 요소들이 연속된 메모리 공간에 저장되는 자료구조입니다. 생성 시 크기를 지정하며, 이후 크기를 변경할 수 없습니다. 마치 정해진 칸 수의 사물함과 같습니다.

### 배열 선언과 초기화

```csharp
// 크기만 지정
int[] numbers = new int[5];

// 선언과 동시에 값 할당
string[] names = new string[] { "Alice", "Bob", "Charlie" };

// 축약형 (컴파일러가 타입 추론)
char[] grades = { 'A', 'B', 'C' };
```

### 배열 요소 접근

인덱스를 통해 $$O(1)$$ 시간에 요소에 접근할 수 있습니다. 인덱스는 0부터 시작합니다.

```csharp
int first = numbers[0];
numbers[2] = 100;
```

### 배열의 메모리 구조

배열은 관리되는 힙(Managed Heap)에 연속된 블록으로 할당됩니다. 각 요소는 고정된 크기(값 타입은 그 크기, 참조 타입은 참조 주소 크기)만큼 떨어진 위치에 저장됩니다.

```text
[배열 메모리 구조]
배열 참조 변수 (스택)  →   힙 메모리
   numbers    ────────→  [0] [1] [2] [3] [4] (연속된 공간)
                              ↑
                         각 요소는 타입 크기만큼의 간격
```

### 배열의 장점과 단점

- **장점**: 인덱스 접근 속도가 빠르며, 추가 메모리 오버헤드가 거의 없습니다.
- **단점**: 크기를 변경할 수 없습니다. 요소를 중간에 삽입하거나 삭제하려면 새로운 배열을 생성하고 복사해야 합니다.

### 배열 크기 변경의 비용

배열은 크기를 늘릴 수 없으므로, 요소를 추가해야 할 경우 더 큰 배열을 새로 만들고 기존 요소를 복사합니다. 이 작업은 기존 요소 수를 $$N$$이라고 할 때 $$O(N)$$의 시간과 추가 메모리가 필요합니다.

```csharp
int[] oldArray = { 1, 2, 3 };
int[] newArray = new int[4];
Array.Copy(oldArray, newArray, oldArray.Length);
newArray[3] = 4;
oldArray = newArray;
```

## 리스트 (List<T>)

`List<T>`는 `System.Collections.Generic` 네임스페이스에 있는 동적 배열입니다. 내부적으로 배열을 사용하지만, 용량(Capacity)을 자동으로 관리하여 크기 변경을 추상화합니다. 마치 자동으로 크기가 늘어나는 사물함이라고 생각할 수 있습니다.

### 리스트 선언과 초기화

```csharp
using System.Collections.Generic;

// 빈 리스트 생성
List<int> numbers = new List<int>();

// 초기 용량 지정 (성능 최적화)
List<string> names = new List<string>(100);

// 컬렉션 초기화
List<char> grades = new List<char> { 'A', 'B', 'C' };
```

### 요소 추가와 제거

```csharp
numbers.Add(10);           // 끝에 추가
numbers.Insert(0, 5);      // 특정 위치에 삽입
numbers.Remove(10);        // 값으로 제거 (첫 번째 일치 항목)
numbers.RemoveAt(0);       // 인덱스로 제거
```

### 리스트의 내부 동작

리스트는 내부에 배열(`T[] _items`)을 보유합니다. 요소를 추가할 때 내부 배열의 크기가 부족하면, 현재 용량의 2배(일반적으로)로 증가시킨 새 배열을 할당하고 기존 요소를 복사합니다.

```text
[List<T> 내부 구조]

List<T> 객체 (스택)         힙 메모리
   ┌─────────────┐
   │ _items  ────┼───────→ [0] [1] [2] [3] [ ] [ ] ...
   │ _size = 3   │
   │ _version    │
   └─────────────┘
```

- **용량(Capacity)**: 내부 배열의 총 크기
- **크기(Count)**: 실제 저장된 요소의 개수 (≤ Capacity)

### 용량 관리와 성능

리스트에 요소를 추가할 때, 내부 배열이 가득 차면 새로운 배열을 할당하고 기존 요소를 복사합니다. 이 재할당 작업은 $$O(N)$$ 시간이 소요됩니다. 따라서 많은 요소를 추가할 것으로 예상되면 생성자에서 초기 용량을 지정하여 재할당 횟수를 줄일 수 있습니다.

```csharp
// 초기 용량을 지정하면 재할당 최소화
var manyNumbers = new List<int>(10000);
for (int i = 0; i < 10000; i++)
{
    manyNumbers.Add(i); // 10,000번 동안 재할당이 거의 없음
}
```

### 리스트의 주요 메서드 시간 복잡도

| 작업 | 시간 복잡도 |
|------|------------|
| 인덱스로 접근 (`list[i]`) | $$O(1)$$ |
| 끝에 추가 (`Add`) | 분할 상환 $$O(1)$$ (재할당 시 $$O(N)$$) |
| 중간 삽입/삭제 (`Insert`, `RemoveAt`) | $$O(N)$$ (요소 이동 필요) |
| 값 검색 (`Contains`, `IndexOf`) | $$O(N)$$ (정렬되지 않은 경우) |
| 정렬 (`Sort`) | $$O(N \log N)$$ |

## 배열과 리스트의 선택 기준

어떤 자료구조를 선택할지는 데이터의 특성과 수행할 작업에 따라 달라집니다.

### 배열을 사용하는 것이 좋은 경우

- 요소 개수가 고정되어 있고 변경되지 않는 경우
- 메모리 오버헤드를 최소화해야 하는 경우 (리스트는 추가 필드가 있음)
- 다차원 데이터(2D, 3D 배열)를 다룰 때 (가독성 면에서 `int[,]`가 유리할 수 있음)

```csharp
int[,] matrix = new int[3, 4];
matrix[0, 1] = 5;
```

### 리스트를 사용하는 것이 좋은 경우

- 요소의 개수가 동적으로 변하는 경우
- 끝에 요소를 자주 추가해야 하는 경우
- LINQ 쿼리나 `foreach` 등 컬렉션 인터페이스가 필요한 경우

### 성능 비교 예시

요소를 중간에 삽입하거나 제거하는 작업은 배열과 리스트 모두 $$O(N)$$이지만, 리스트는 이러한 작업을 편리한 메서드로 제공합니다. 하지만 많은 삽입/삭제가 발생한다면 `LinkedList<T>`와 같은 다른 자료구조를 고려해야 합니다.

```csharp
// 리스트 중간 삽입: 요소 이동 발생
List<int> list = new List<int> { 1, 2, 3, 4, 5 };
list.Insert(2, 99); // 3,4,5가 한 칸씩 뒤로 이동
```

## 배열과 리스트의 변환

두 자료구조 사이의 변환은 간단합니다.

```csharp
// 배열 → 리스트
int[] arr = { 1, 2, 3 };
List<int> list = arr.ToList();

// 리스트 → 배열
int[] newArr = list.ToArray();
```

---

## 실무 팁

- **초기 용량 설정**: 리스트에 추가할 요소 수를 미리 알고 있다면 생성자에 용량을 지정해 성능을 높입니다.
- **읽기 전용 컬렉션**: 메서드 내부에서 배열이나 리스트를 수정하지 않도록 하려면 `IReadOnlyList<T>` 인터페이스를 사용합니다.
- **배열의 복사**: 배열을 다른 배열로 복사할 때는 `Array.Copy` 또는 `Clone`을 사용합니다.

```csharp
int[] source = { 1, 2, 3 };
int[] target = new int[3];
Array.Copy(source, target, source.Length);
```

## 마무리

배열과 리스트는 C#에서 가장 자주 사용되는 컬렉션 타입입니다. 배열은 단순하고 빠르지만 크기가 고정되어 있고, 리스트는 동적이지만 약간의 오버헤드가 있습니다. 두 자료구조의 성능 특성과 내부 동작을 이해하고, 상황에 맞게 적절히 선택하는 능력을 기르는 것이 중요합니다.

- 데이터의 크기가 고정되어 있다면 배열을 사용합니다.
- 크기가 변하고 끝에 요소를 주로 추가한다면 리스트를 사용합니다.
- 많은 양의 데이터를 다룰 때는 초기 용량을 지정하여 재할당 비용을 줄입니다.
- 중간 삽입/삭제가 잦다면 `LinkedList<T>`도 고려합니다.

올바른 자료구조 선택은 코드의 성능과 가독성을 크게 향상시킵니다.
