# 메뉴 + 라우팅 구조

Avalonia 애플리케이션에서 메뉴와 라우팅을 체계적으로 구성하면 사용자 경험과 유지보수성을 크게 향상시킬 수 있습니다. 이 글에서는 **메뉴 기반 탐색**, **DI와 히스토리 스택을 갖춘 라우팅 서비스**, **권한/더티 가드**, **모듈 확장**, **파라미터 전달**, **애니메이션**, **딥링크 복원**까지 실전에서 활용 가능한 구조를 초중급 개발자 기준으로 설명합니다.

---

## 1. 기본 UI 레이아웃

좌측 메뉴(ListBox)와 우측 콘텐츠 영역(ContentControl)을 갖춘 전형적인 레이아웃입니다. 뒤로/앞으로 버튼과 애니메이션 전환을 함께 포함합니다.

```xml
<!-- MainWindow.axaml -->
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        x:Class="MyApp.MainWindow"
        Width="1200" Height="800">

  <DockPanel>

    <!-- 상단 바 (뒤로/앞으로) -->
    <Border DockPanel.Dock="Top" Height="48" Background="#1e1e1e">
      <StackPanel Orientation="Horizontal" Spacing="8" Margin="12,0">
        <Button Content="뒤로" Command="{Binding BackCommand}"/>
        <Button Content="앞으로" Command="{Binding ForwardCommand}"/>
      </StackPanel>
    </Border>

    <!-- 좌측 메뉴 -->
    <ListBox DockPanel.Dock="Left"
             Width="220"
             Items="{Binding MenuItems}"
             SelectedItem="{Binding SelectedMenuItem}">
      <ListBox.ItemTemplate>
        <DataTemplate>
          <TextBlock Text="{Binding Title}" Margin="12,6"/>
        </DataTemplate>
      </ListBox.ItemTemplate>
    </ListBox>

    <!-- 콘텐츠 영역 (애니메이션 포함) -->
    <ContentControl Content="{Binding CurrentView}">
      <ContentControl.Transitions>
        <Transitions>
          <PageSlide Duration="0:0:0.25" SlideDirection="Left"/>
        </Transitions>
      </ContentControl.Transitions>
    </ContentControl>

  </DockPanel>
</Window>
```

**핵심**: `ContentControl.Content`에 현재 뷰를 바인딩하고, `Transitions`로 자연스러운 페이지 전환 효과를 줍니다.

## 2. 메뉴 아이템과 라우트 모델

메뉴 아이템은 표시할 텍스트와 연결할 ViewModel 타입, 그리고 선택적 초기 파라미터를 갖습니다.

```csharp
public sealed class MenuItem
{
    public string Title { get; init; } = "";
    public Type ViewModelType { get; init; } = typeof(object);
    public object? DefaultParameter { get; init; }
}
```

히스토리 스택에 저장할 라우트 정보는 ViewModel 타입과 파라미터로 구성합니다.

```csharp
public sealed class Route
{
    public Type ViewModelType { get; }
    public object? Parameter { get; }

    public Route(Type vmType, object? parameter = null)
    {
        ViewModelType = vmType;
        Parameter = parameter;
    }
}
```

히스토리 엔트리는 라우트와 함께 생성된 ViewModel과 View를 함께 보관하여 캐싱합니다.

```csharp
public sealed class RouteEntry
{
    public Route Route { get; }
    public object? ViewModel { get; }
    public IControl? View { get; }

    public RouteEntry(Route route, object? vm, IControl? view)
    {
        Route = route;
        ViewModel = vm;
        View = view;
    }
}
```

## 3. ViewLocator – ViewModel에서 View 찾기

ViewModel 타입 이름에서 "ViewModel"을 "View"로 바꾸어 View 타입을 찾습니다. 실제 프로젝트에서는 어셈블리 규칙을 활용해 더 정교하게 구성할 수 있습니다.

```csharp
public static class ViewLocator
{
    public static IControl ResolveView(object viewModel)
    {
        var vmType = viewModel.GetType();
        var viewTypeName = vmType.FullName!.Replace("ViewModel", "View");
        var viewType = Type.GetType(viewTypeName) ?? throw new InvalidOperationException($"View not found for {vmType.Name}");
        return (IControl)Activator.CreateInstance(viewType)!;
    }
}
```

> **참고**: Avalonia의 `DataTemplate`을 이용해 VM-View 매핑을 자동화할 수도 있지만, 여기서는 라우팅 서비스가 직접 View를 생성하는 방식으로 진행합니다.

## 4. 네비게이션 가드 (INavigationGuard)

화면 전환 전에 권한, 더티 상태 등을 검사합니다.

```csharp
public interface INavigationGuard
{
    Task<bool> CanNavigateAsync(Route from, Route to, CancellationToken ct = default);
}
```

### 더티 상태 가드 예시

```csharp
public interface IDirtyAware
{
    bool IsDirty { get; }
}

public sealed class DirtyGuard : INavigationGuard
{
    private readonly Func<Task<bool>> _confirm; // 저장 확인 다이얼로그

    public DirtyGuard(Func<Task<bool>> confirm) => _confirm = confirm;

    public async Task<bool> CanNavigateAsync(Route from, Route to, CancellationToken ct = default)
    {
        // 현재 ViewModel이 IDirtyAware이고 더티 상태라면 확인
        var currentVm = NavigationService.CurrentEntry?.ViewModel;
        if (currentVm is IDirtyAware d && d.IsDirty)
            return await _confirm();
        return true;
    }
}
```

> `NavigationService.CurrentEntry`는 라우팅 서비스가 현재 상태를 노출한다고 가정합니다.

### 권한 기반 가드

```csharp
public interface IAuthState
{
    bool IsAdmin { get; }
}

public sealed class RoleGuard : INavigationGuard
{
    private readonly IAuthState _auth;

    public RoleGuard(IAuthState auth) => _auth = auth;

    public Task<bool> CanNavigateAsync(Route from, Route to, CancellationToken ct = default)
    {
        if (to.ViewModelType == typeof(SettingsViewModel) && !_auth.IsAdmin)
            return Task.FromResult(false);
        return Task.FromResult(true);
    }
}
```

## 5. 네비게이션 서비스 (INavigationService)

핵심 라우팅 엔진입니다. DI를 통해 ViewModel을 생성하고, 히스토리 스택을 관리하며, 가드를 적용합니다.

```csharp
public interface INavigationService
{
    RouteEntry? CurrentEntry { get; }
    bool CanGoBack { get; }
    bool CanGoForward { get; }

    Task NavigateAsync<TViewModel>(object? parameter = null, bool clearForward = true, CancellationToken ct = default);
    Task NavigateAsync(Type viewModelType, object? parameter = null, bool clearForward = true, CancellationToken ct = default);
    Task<bool> BackAsync(CancellationToken ct = default);
    Task<bool> ForwardAsync(CancellationToken ct = default);
    Task<bool> NavigateRouteAsync(Route route, bool clearForward = true, CancellationToken ct = default);
}
```

### 구현

```csharp
public sealed class NavigationService : INavigationService
{
    private readonly IServiceProvider _sp;
    private readonly IEnumerable<INavigationGuard> _guards;
    private readonly SynchronizationContext _ui;
    private readonly Func<IControl?, Task> _present; // UI에 View를 표시하는 델리게이트
    private readonly Stack<RouteEntry> _back = new();
    private readonly Stack<RouteEntry> _forward = new();

    public RouteEntry? CurrentEntry { get; private set; }
    public bool CanGoBack => _back.Count > 0;
    public bool CanGoForward => _forward.Count > 0;

    public NavigationService(
        IServiceProvider sp,
        IEnumerable<INavigationGuard> guards,
        Func<IControl?, Task> present,
        SynchronizationContext ui)
    {
        _sp = sp;
        _guards = guards;
        _present = present;
        _ui = ui;
    }

    public Task NavigateAsync<TViewModel>(object? parameter = null, bool clearForward = true, CancellationToken ct = default)
        => NavigateAsync(typeof(TViewModel), parameter, clearForward, ct);

    public async Task NavigateAsync(Type viewModelType, object? parameter = null, bool clearForward = true, CancellationToken ct = default)
        => await NavigateRouteAsync(new Route(viewModelType, parameter), clearForward, ct);

    public async Task<bool> NavigateRouteAsync(Route route, bool clearForward = true, CancellationToken ct = default)
    {
        var from = CurrentEntry?.Route ?? new Route(typeof(object));
        foreach (var g in _guards)
            if (!await g.CanNavigateAsync(from, route, ct))
                return false;

        // DI 스코프 생성 (페이지별 수명 관리)
        using var scope = _sp.CreateScope();
        var vm = scope.ServiceProvider.GetRequiredService(route.ViewModelType);

        // 파라미터 전달 (IAcceptParameter 인터페이스)
        if (vm is IAcceptParameter ap)
            ap.ApplyParameter(route.Parameter);

        var view = ViewLocator.ResolveView(vm);
        await PresentOnUiAsync(view, ct);

        if (CurrentEntry is not null)
            _back.Push(CurrentEntry);
        if (clearForward)
            ClearForward();

        CurrentEntry = new RouteEntry(route, vm, view);
        return true;
    }

    public async Task<bool> BackAsync(CancellationToken ct = default)
    {
        if (!CanGoBack) return false;
        var target = _back.Pop();

        var from = CurrentEntry?.Route ?? new Route(typeof(object));
        foreach (var g in _guards)
            if (!await g.CanNavigateAsync(from, target.Route, ct))
                return false;

        if (CurrentEntry is not null)
            _forward.Push(CurrentEntry);

        await PresentOnUiAsync(target.View, ct);
        CurrentEntry = target;
        return true;
    }

    public async Task<bool> ForwardAsync(CancellationToken ct = default)
    {
        if (!CanGoForward) return false;
        var target = _forward.Pop();

        var from = CurrentEntry?.Route ?? new Route(typeof(object));
        foreach (var g in _guards)
            if (!await g.CanNavigateAsync(from, target.Route, ct))
                return false;

        if (CurrentEntry is not null)
            _back.Push(CurrentEntry);

        await PresentOnUiAsync(target.View, ct);
        CurrentEntry = target;
        return true;
    }

    private void ClearForward()
    {
        while (_forward.Count > 0)
        {
            var e = _forward.Pop();
            TryDispose(e.ViewModel);
            TryDispose(e.View);
        }
    }

    private static void TryDispose(object? o)
    {
        switch (o)
        {
            case IAsyncDisposable a: a.DisposeAsync().AsTask().GetAwaiter().GetResult(); break;
            case IDisposable d: d.Dispose(); break;
        }
    }

    private Task PresentOnUiAsync(IControl? view, CancellationToken ct)
    {
        var tcs = new TaskCompletionSource();
        _ui.Post(_ =>
        {
            _present(view);
            tcs.SetResult();
        }, null);
        return tcs.Task;
    }
}
```

**설명**  
- `_present` 델리게이트는 실제로 `ContentControl.Content = view`를 UI 스레드에서 수행하는 함수입니다.  
- `SynchronizationContext`를 통해 UI 스레드로 전환합니다.  
- `CreateScope()`를 사용해 페이지별로 DI 스코프를 분리하여 수명을 관리합니다.  
- `TryDispose`로 히스토리에서 제거될 때 ViewModel과 View를 정리합니다.

## 6. 파라미터 전달 (IAcceptParameter)

파라미터를 받을 ViewModel은 이 인터페이스를 구현합니다.

```csharp
public interface IAcceptParameter
{
    void ApplyParameter(object? parameter);
}

public class UserDetailViewModel : ReactiveObject, IAcceptParameter
{
    private readonly IUserRepository _repo;
    public string? UserName { get; private set; }

    public UserDetailViewModel(IUserRepository repo) => _repo = repo;

    public void ApplyParameter(object? parameter)
    {
        if (parameter is int userId)
        {
            var user = _repo.GetById(userId);
            UserName = user.Name;
            this.RaisePropertyChanged(nameof(UserName));
        }
    }
}
```

사용 예:

```csharp
await _nav.NavigateAsync<UserDetailViewModel>(123);
```

## 7. MainViewModel과 메뉴 연동

MainViewModel은 메뉴 항목을 제공하고, 선택 시 네비게이션 서비스를 호출합니다. 현재 View를 바인딩할 수 있도록 `CurrentView` 속성을 노출합니다.

```csharp
using ReactiveUI;
using System.Collections.ObjectModel;

public sealed class MainViewModel : ReactiveObject
{
    private readonly INavigationService _nav;

    public ObservableCollection<MenuItem> MenuItems { get; } = new();

    private MenuItem? _selectedMenuItem;
    public MenuItem? SelectedMenuItem
    {
        get => _selectedMenuItem;
        set
        {
            this.RaiseAndSetIfChanged(ref _selectedMenuItem, value);
            if (value is not null)
                _ = NavigateFromMenuAsync(value);
        }
    }

    private IControl? _currentView;
    public IControl? CurrentView
    {
        get => _currentView;
        set => this.RaiseAndSetIfChanged(ref _currentView, value);
    }

    public ReactiveCommand<Unit, Unit> BackCommand { get; }
    public ReactiveCommand<Unit, Unit> ForwardCommand { get; }

    public MainViewModel(INavigationService nav, IEnumerable<IModule> modules)
    {
        _nav = nav;

        foreach (var m in modules)
            foreach (var mi in m.GetMenuItems())
                MenuItems.Add(mi);

        BackCommand = ReactiveCommand.CreateFromTask(async () => await _nav.BackAsync());
        ForwardCommand = ReactiveCommand.CreateFromTask(async () => await _nav.ForwardAsync());

        // 네비게이션 서비스의 현재 뷰 변화를 관찰
        _ = Task.Run(async () =>
        {
            while (true)
            {
                await Task.Delay(100);
                CurrentView = _nav.CurrentEntry?.View;
            }
        });

        // 초기 화면
        SelectedMenuItem = MenuItems.FirstOrDefault();
    }

    private async Task NavigateFromMenuAsync(MenuItem item)
        => await _nav.NavigateAsync(item.ViewModelType, item.DefaultParameter);
}
```

> **참고**: 실제로는 `INavigationService`가 이벤트를 통해 `CurrentView` 변경을 알리도록 개선하는 것이 좋습니다. 위 예시는 폴링 방식으로 단순화했습니다.

## 8. DI 등록 (App.axaml.cs / Program.cs)

```csharp
var services = new ServiceCollection();

// 전역 상태 (권한, 설정 등)
services.AddSingleton<IAuthState, AuthState>();

// 네비게이션 가드 등록
services.AddSingleton<INavigationGuard, DirtyGuard>(sp =>
{
    var confirm = async () => { /* 다이얼로그 표시, 사용자 응답 반환 */ return true; };
    return new DirtyGuard(confirm);
});
services.AddSingleton<INavigationGuard, RoleGuard>();

// 네비게이션 서비스 등록 (델리게이트는 MainWindow에서 제공)
services.AddSingleton<INavigationService>(sp =>
{
    // ContentControl을 담을 호스트 객체
    var host = new ShellViewHost(); // 단순히 IControl? Content { get; set; }
    Func<IControl?, Task> present = async v => host.Content = v;

    var ui = SynchronizationContext.Current ?? new SynchronizationContext();
    return new NavigationService(sp, sp.GetServices<INavigationGuard>(), present, ui);
});

// 모듈 등록
services.AddSingleton<IModule, DashboardModule>();
services.AddSingleton<IModule, UserModule>();

// ViewModel 등록 (Transient로 등록)
services.AddTransient<DashboardViewModel>();
services.AddTransient<UserViewModel>();

// MainWindow에 주입할 호스트와 MainViewModel
services.AddSingleton<ShellViewHost>(); // 코드비하인드에서 참조
services.AddTransient<MainViewModel>();

var sp = services.BuildServiceProvider();

// MainWindow 생성 및 데이터 컨텍스트 설정
var mainWindow = new MainWindow();
mainWindow.DataContext = sp.GetRequiredService<MainViewModel>();

// ShellViewHost에 접근해 ContentControl의 바인딩을 수동으로 연결 (또는 코드비하인드에서 바인딩)
var host = sp.GetRequiredService<ShellViewHost>();
mainWindow.ContentControl.Content = host.Content; // 간단한 연결 (실제로는 데이터바인딩을 통해 자동화)
```

`ShellViewHost`는 단순한 클래스입니다.

```csharp
public sealed class ShellViewHost
{
    public IControl? Content { get; set; }
}
```

MainWindow 코드비하인드에서 `ContentControl`을 `ShellViewHost.Content`에 바인딩하거나, 생성자에서 직접 설정합니다. 여기서는 편의를 위해 수동 연결로 예시를 보였습니다.

## 11. 딥링크 및 상태 복원

마지막 라우트를 저장하고 재시작 시 복원하려면 라우트 직렬화와 파일 저장이 필요합니다.

### 간단한 직렬화 도구

```csharp
public interface IRouteSerializer
{
    string Serialize(Route route);
    Route? Deserialize(string s);
}

public sealed class SimpleRouteSerializer : IRouteSerializer
{
    public string Serialize(Route route)
    {
        var typeName = route.ViewModelType.AssemblyQualifiedName!;
        var param = route.Parameter is null ? "" : Uri.EscapeDataString(JsonSerializer.Serialize(route.Parameter));
        return $"{typeName}|{param}";
    }

    public Route? Deserialize(string s)
    {
        var parts = s.Split('|');
        if (parts.Length == 0) return null;
        var type = Type.GetType(parts[0]);
        if (type is null) return null;
        object? param = null;
        if (parts.Length > 1 && !string.IsNullOrEmpty(parts[1]))
            param = JsonSerializer.Deserialize<object>(Uri.UnescapeDataString(parts[1]));
        return new Route(type, param);
    }
}
```

### 앱 종료 시 저장

```csharp
var ser = sp.GetRequiredService<IRouteSerializer>();
var nav = sp.GetRequiredService<INavigationService>();
if (nav.CurrentEntry is not null)
{
    var route = nav.CurrentEntry.Route;
    File.WriteAllText("last.route", ser.Serialize(route));
}
```

### 앱 시작 시 복원

```csharp
if (File.Exists("last.route"))
{
    var s = File.ReadAllText("last.route");
    var route = ser.Deserialize(s);
    if (route is not null)
        await nav.NavigateRouteAsync(route);
}
```

커맨드라인 인자나 URL 스킴을 처리하려면 `Environment.GetCommandLineArgs()`를 파싱하여 라우트로 변환하면 됩니다.

## 12. 테스트

### 네비게이션 서비스 단위 테스트

```csharp
[Fact]
public async Task Navigate_Adds_Back_Entry_And_Clears_Forward()
{
    var sp = BuildTestServiceProvider(); // 가짜 DI 컨테이너
    var presented = new List<IControl?>();
    var svc = new NavigationService(sp, Array.Empty<INavigationGuard>(),
        v => { presented.Add(v); return Task.CompletedTask; },
        new SynchronizationContext());

    await svc.NavigateAsync(typeof(DashboardViewModel));
    await svc.NavigateAsync(typeof(UserViewModel));

    Assert.True(svc.CanGoBack);
    Assert.False(svc.CanGoForward);
}
```

[Fact]
public async Task RoleGuard_Blocks_Settings_For_NonAdmin()

    Assert.False(result);

## 13. 성능 및 메모리 고려사항

- **히스토리 캐시**: `RouteEntry`에 View와 ViewModel을 캐싱하므로 메모리 사용량에 주의하세요. 필요에 따라 히스토리 길이를 제한하거나, Back/Forward 시 ViewModel을 재생성하는 정책을 선택할 수 있습니다.
- **Dispose 패턴**: 히스토리에서 제거될 때 `IDisposable`, `IAsyncDisposable`을 호출하여 리소스를 정리합니다.
- **가상화**: 메뉴 항목이 많다면 `ListBox`의 가상화를 활용하세요.
- **무거운 뷰**: 큰 데이터는 ViewModel에서 비동기로 로딩하고, 뷰는 단순하게 유지합니다.

## 14. 요약 표

| 구성 요소 | 역할 | 구현 포인트 |
|-----------|------|-------------|
| `MenuItem` / `Route` | 메뉴 항목과 라우트 정보 | ViewModel 타입 + 선택적 파라미터 |
| `ViewLocator` | ViewModel → View 변환 | 명명 규칙 또는 DI |
| `INavigationGuard` | 전환 전 검사 | 더티/권한/비즈니스 로직 |
| `INavigationService` | 라우팅 엔진 | 히스토리, 가드, DI, 파라미터 전달 |
| `IAcceptParameter` | 파라미터 주입 | ViewModel에서 구현 |
| `IModule` | 기능 확장 | 메뉴 제공 |
| `MainViewModel` | 메뉴 바인딩, 명령 | 메뉴 선택 시 `NavigateAsync` 호출 |
| `ShellViewHost` | ContentControl과 연결 | `present` 델리게이트와 함께 사용 |
| `IRouteSerializer` | 딥링크 복원 | 라우트 직렬화/역직렬화 |
