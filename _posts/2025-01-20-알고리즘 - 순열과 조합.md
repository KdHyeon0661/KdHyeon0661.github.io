# 순열과 조합

## 순열과 조합이란?

**순열(Permutation)** 은 순서를 고려하여 원소를 뽑는 방법입니다.  
예를 들어 `{1, 2, 3}`에서 두 개를 뽑을 때 `(1,2)`와 `(2,1)`은 서로 다른 순열입니다.

**조합(Combination)** 은 순서를 고려하지 않고 원소를 뽑는 방법입니다.  
같은 예에서 `{1,2}`와 `{2,1}`은 같은 조합으로 취급합니다.

팩토리얼 기호 `n!`은 1부터 n까지의 모든 자연수를 곱한 값입니다.

- 순열의 수:  
  $$ {}_nP_r = \frac{n!}{(n-r)!} $$
- 조합의 수:  
  $$ \binom{n}{r} = \frac{n!}{r!(n-r)!} $$

| 구분 | 순열 | 조합 |
|------|------|------|
| 순서 | 중요 | 중요하지 않음 |
| 개수 | \(\frac{n!}{(n-r)!}\) | \(\frac{n!}{r!(n-r)!}\) |
| 파이썬 라이브러리 | `itertools.permutations` | `itertools.combinations` |

## 간단한 예

`[1, 2, 3]`에서 2개를 뽑는 경우:

- 순열: `(1,2)`, `(2,1)`, `(1,3)`, `(3,1)`, `(2,3)`, `(3,2)` → 6개
- 조합: `(1,2)`, `(1,3)`, `(2,3)` → 3개

## 파이썬으로 생성하기

`itertools` 모듈을 사용하면 간단하게 모든 순열과 조합을 생성할 수 있습니다.

```python
from itertools import permutations, combinations

arr = [1, 2, 3]

# 순열
for p in permutations(arr, 2):
    print(p)  # (1,2), (1,3), (2,1), (2,3), (3,1), (3,2)

# 조합
for c in combinations(arr, 2):
    print(c)  # (1,2), (1,3), (2,3)
```

중복을 허용하는 경우:

- 중복 순열 (순서 중요, 중복 허용): `product(arr, repeat=r)` → 개수 \(n^r\)
- 중복 조합 (순서 무관, 중복 허용): `combinations_with_replacement(arr, r)` → 개수 \(\binom{n+r-1}{r}\)

```python
from itertools import product, combinations_with_replacement

# 중복 순열
for p in product(arr, repeat=2):
    print(p)  # (1,1), (1,2), (1,3), (2,1), ...

# 중복 조합
for c in combinations_with_replacement(arr, 2):
    print(c)  # (1,1), (1,2), (1,3), (2,2), (2,3), (3,3)
```

## 직접 구현하기 (재귀)

때로는 라이브러리 없이 직접 구현해야 하거나, 생성 과정에서 조건을 추가해야 할 수 있습니다.

### 순열 (백트래킹)

```python
def permute(arr, r):
    used = [False] * len(arr)
    path = []
    result = []

    def dfs():
        if len(path) == r:
            result.append(path[:])
            return
        for i in range(len(arr)):
            if not used[i]:
                used[i] = True
                path.append(arr[i])
                dfs()
                path.pop()
                used[i] = False

    dfs()
    return result
```

### 조합 (오름차순 인덱스)

```python
def combine(arr, r):
    path = []
    result = []

    def dfs(start):
        if len(path) == r:
            result.append(path[:])
            return
        for i in range(start, len(arr)):
            path.append(arr[i])
            dfs(i + 1)
            path.pop()

    dfs(0)
    return result
```

## 중복 원소가 있는 경우

배열에 중복된 값이 있으면, 단순한 순열/조합 생성 시 중복된 결과가 나올 수 있습니다. 이를 방지하는 방법입니다.

### 중복 원소를 포함한 순열

```python
from collections import Counter

def permute_multiset(arr):
    cnt = Counter(arr)
    path = []
    result = []

    def dfs():
        if len(path) == len(arr):
            result.append(path[:])
            return
        for x in list(cnt.keys()):
            if cnt[x] > 0:
                cnt[x] -= 1
                path.append(x)
                dfs()
                path.pop()
                cnt[x] += 1

    dfs()
    return result
```

### 중복 원소를 포함한 조합 (고유한 조합)

```python
def unique_combinations(arr, r):
    arr = sorted(arr)
    path = []
    result = []

    def dfs(start):
        if len(path) == r:
            result.append(path[:])
            return
        for i in range(start, len(arr)):
            # 같은 값이 연속으로 선택되는 것을 방지
            if i > start and arr[i] == arr[i-1]:
                continue
            path.append(arr[i])
            dfs(i + 1)
            path.pop()

    dfs(0)
    return result
```

## 유용한 공식과 성질

- 대칭성:  
  $$ \binom{n}{r} = \binom{n}{n-r} $$
- 파스칼 항등식 (DP로 조합 수 계산할 때 사용):  
  $$ \binom{n}{r} = \binom{n-1}{r} + \binom{n-1}{r-1} $$
- 전체 부분집합의 개수:  
  $$ \sum_{r=0}^{n} \binom{n}{r} = 2^n $$
- 중복 조합:  
  $$ \binom{n+r-1}{r} $$
- 이항정리:  
  $$ (x+y)^n = \sum_{r=0}^{n} \binom{n}{r} x^{n-r} y^{r} $$

## 대표 문제 풀이

### N과 M (1) – 순열 (BOJ 15649)

```python
n, m = map(int, input().split())
used = [False] * (n + 1)
path = []

def dfs():
    if len(path) == m:
        print(*path)
        return
    for x in range(1, n + 1):
        if not used[x]:
            used[x] = True
            path.append(x)
            dfs()
            path.pop()
            used[x] = False

dfs()
```

### N과 M (2) – 조합 (BOJ 15650)

```python
n, m = map(int, input().split())
path = []

def dfs(start):
    if len(path) == m:
        print(*path)
        return
    for x in range(start, n + 1):
        path.append(x)
        dfs(x + 1)
        path.pop()

dfs(1)
```

### 암호 만들기 (BOJ 1759) – 조합에 조건 추가

```python
from itertools import combinations

L, C = map(int, input().split())
chars = input().split()
chars.sort()
vowels = set('aeiou')

for comb in combinations(chars, L):
    v = sum(1 for ch in comb if ch in vowels)
    c = L - v
    if v >= 1 and c >= 2:
        print(''.join(comb))
```

## 선택 가이드

| 상황 | 추천 방법 |
|------|----------|
| n ≤ 10 | `itertools` 또는 재귀 모두 편리 |
| n이 10~15 정도 | 재귀 백트래킹 (조건 가지치기 가능) |
| n이 20 이상 | 모든 경우를 생성하는 것은 불가능 → 수식이나 DP로 개수만 계산 |
| 중복 원소 존재 | 중복을 처리하는 재귀 함수 구현 |
| 개수만 필요하고 생성은 불필요 | 공식 또는 DP 사용 (예: 조합 수 계산) |

## 마무리

순열과 조합은 “순서를 고려하는가?”라는 한 가지 질문으로 구분됩니다.  
`itertools`를 활용하면 간단히 모든 경우를 생성할 수 있고, 필요하다면 재귀 함수로 직접 구현해 조건을 추가할 수 있습니다.  
입력 크기가 커지면 생성 자체가 비현실적이므로, 개수만 계산하는 공식이나 DP를 사용해야 한다는 점을 기억해두세요.
