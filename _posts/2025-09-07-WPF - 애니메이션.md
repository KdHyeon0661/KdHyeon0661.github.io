# WPF 애니메이션 완전 정복

WPF 애니메이션은 시간에 따라 UI 요소의 속성을 변화시켜 역동적인 사용자 경험을 제공하는 강력한 도구입니다. 이 문서에서는 초중급 개발자를 대상으로 애니메이션의 기본 구조부터 실전 패턴까지 체계적으로 설명합니다.

## 애니메이션 계층 구조

WPF 애니메이션은 다음과 같은 계층 구조로 이루어집니다.

- **Timeline**: 시간 축의 기본 단위입니다. `Duration`, `BeginTime`, `RepeatBehavior`, `AutoReverse` 등의 속성을 가집니다.
- **AnimationTimeline**: 특정 의존 속성(DependencyProperty)의 값을 시간에 따라 변화시키는 클래스들의 기반입니다. `DoubleAnimation`, `ColorAnimation`, `ThicknessAnimation` 등이 있습니다.
- **Storyboard**: 여러 AnimationTimeline을 묶어서 대상과 속성에 적용하고 제어하는 컨테이너입니다.
- **Trigger / EventTrigger / VisualStateManager**: 특정 상태나 이벤트에서 Storyboard를 실행시키는 선언적 메커니즘입니다.
- **Code-behind 제어**: `Storyboard.Begin/Stop/Pause/Resume` 등으로 동적으로 애니메이션을 제어합니다.

**핵심 원칙**: 애니메이션의 대상은 반드시 의존 속성이어야 합니다. 예를 들어 `Opacity`, `Width`, `RenderTransform.(TranslateTransform.X)`, `BorderBrush.(SolidColorBrush.Color)` 등이 가능합니다.

## 기본 애니메이션 문법

### 페이드 인/아웃 (Opacity 애니메이션)

가장 간단한 애니메이션은 버튼 클릭 시 투명도를 0으로 만드는 것입니다.

```xml
<Button Content="Fade Me" x:Name="Btn" Opacity="1">
  <Button.Triggers>
    <EventTrigger RoutedEvent="Button.Click">
      <BeginStoryboard>
        <Storyboard>
          <DoubleAnimation Storyboard.TargetName="Btn"
                           Storyboard.TargetProperty="Opacity"
                           To="0" Duration="0:0:0.3" AutoReverse="True"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Button.Triggers>
</Button>
```

### 이동 애니메이션 (RenderTransform)

이동하려면 `TranslateTransform`을 사용합니다.

```xml
<Button Content="Move" x:Name="MoveBtn">
  <Button.RenderTransform>
    <TranslateTransform x:Name="MoveTT" X="0" Y="0"/>
  </Button.RenderTransform>
  <Button.Triggers>
    <EventTrigger RoutedEvent="Button.Click">
      <BeginStoryboard>
        <Storyboard>
          <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(TranslateTransform.X)"
                           To="120" Duration="0:0:0.4" AutoReverse="True"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Button.Triggers>
</Button>
```

**속성 경로 표기법**:
- 단일 속성: `Opacity`
- 첨부 속성: `(UIElement.RenderTransform).(TranslateTransform.X)`
- 브러시 색상: `(Border.Background).(SolidColorBrush.Color)`

## Storyboard의 주요 속성

| 속성 | 설명 |
|------|------|
| `BeginTime` | 시작 지연 시간 (예: `0:0:0.2` → 0.2초 후 시작) |
| `Duration` | 총 재생 시간 (예: `0:0:1.2` → 1.2초) |
| `RepeatBehavior` | 반복 설정 (`Forever`, `3x`, `0:0:2` 동안 반복) |
| `AutoReverse` | 왕복 재생 여부 |
| `SpeedRatio` | 속도 배수 (2.0 → 2배 빠름) |
| `FillBehavior` | `HoldEnd`(종료 후 마지막 값 유지) / `Stop`(종료 후 원래 값 복귀) |

### 예제: 반복 왕복 로딩 펄스

```xml
<Ellipse Width="18" Height="18" Fill="#3B82F6" x:Name="Dot">
  <Ellipse.RenderTransform>
    <ScaleTransform ScaleX="1" ScaleY="1" CenterX="9" CenterY="9"/>
  </Ellipse.RenderTransform>
  <Ellipse.Triggers>
    <EventTrigger RoutedEvent="FrameworkElement.Loaded">
      <BeginStoryboard>
        <Storyboard RepeatBehavior="Forever" AutoReverse="True">
          <DoubleAnimation Storyboard.TargetName="Dot"
                           Storyboard.TargetProperty="Opacity"
                           From="0.4" To="1" Duration="0:0:0.6"/>
          <DoubleAnimation Storyboard.TargetName="Dot"
                           Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleX)"
                           From="0.9" To="1.1" Duration="0:0:0.6"/>
          <DoubleAnimation Storyboard.TargetName="Dot"
                           Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleY)"
                           From="0.9" To="1.1" Duration="0:0:0.6"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Ellipse.Triggers>
</Ellipse>
```

## Triggers를 이용한 애니메이션 실행

### Property Trigger (상태 변화에 반응)

버튼에 마우스를 올리면 살짝 커지는 효과를 주는 스타일입니다.

```xml
<Style TargetType="Button">
  <Setter Property="RenderTransform">
    <Setter.Value><ScaleTransform ScaleX="1" ScaleY="1"/></Setter.Value>
  </Setter>
  <Style.Triggers>
    <Trigger Property="IsMouseOver" Value="True">
      <Trigger.EnterActions>
        <BeginStoryboard x:Name="GrowSB">
          <Storyboard>
            <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleX)"
                             To="1.05" Duration="0:0:0.08"/>
            <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleY)"
                             To="1.05" Duration="0:0:0.08"/>
          </Storyboard>
        </BeginStoryboard>
      </Trigger.EnterActions>
      <Trigger.ExitActions>
        <StopStoryboard BeginStoryboardName="GrowSB"/>
        <BeginStoryboard>
          <Storyboard>
            <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleX)"
                             To="1" Duration="0:0:0.08"/>
            <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleY)"
                             To="1" Duration="0:0:0.08"/>
          </Storyboard>
        </BeginStoryboard>
      </Trigger.ExitActions>
    </Trigger>
  </Style.Triggers>
</Style>
```

### EventTrigger (Storyboard 실행 전용)

`EventTrigger`는 애니메이션을 시작하는 용도로만 사용하며, 다른 로직을 실행하려면 `ICommand`나 `Behaviors`를 사용해야 합니다.

```xml
<Button Content="Pulse">
  <Button.Triggers>
    <EventTrigger RoutedEvent="Button.Click">
      <BeginStoryboard>
        <Storyboard>
          <DoubleAnimation Storyboard.TargetProperty="Opacity"
                           To="0.3" AutoReverse="True" Duration="0:0:0.12"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Button.Triggers>
</Button>
```

## KeyFrame 애니메이션 (복잡한 타이밍)

여러 구간을 나누어 각각 다른 보간 방식(Linear, Spline, Easing, Discrete)을 적용할 수 있습니다.

### DoubleAnimationUsingKeyFrames 예제

```xml
<Border x:Name="Panel" Background="#111827" Width="200" Height="6">
  <Border.Triggers>
    <EventTrigger RoutedEvent="Loaded">
      <BeginStoryboard>
        <Storyboard RepeatBehavior="3x">
          <DoubleAnimationUsingKeyFrames
              Storyboard.TargetName="Panel"
              Storyboard.TargetProperty="Width" Duration="0:0:1.5">
            <LinearDoubleKeyFrame Value="200" KeyTime="0:0:0.0"/>
            <SplineDoubleKeyFrame Value="380" KeyTime="0:0:0.6" KeySpline="0.25,0.1 0.25,1"/>
            <EasingDoubleKeyFrame Value="260" KeyTime="0:0:1.5">
              <EasingDoubleKeyFrame.EasingFunction>
                <CubicEase EasingMode="EaseOut"/>
              </EasingDoubleKeyFrame.EasingFunction>
            </EasingDoubleKeyFrame>
          </DoubleAnimationUsingKeyFrames>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Border.Triggers>
</Border>
```

### ColorAnimationUsingKeyFrames 예제

```xml
<Border x:Name="Chip" CornerRadius="12" Padding="6">
  <Border.Background>
    <SolidColorBrush Color="#2563EB"/>
  </Border.Background>
  <Border.Triggers>
    <EventTrigger RoutedEvent="MouseEnter">
      <BeginStoryboard>
        <Storyboard>
          <ColorAnimationUsingKeyFrames
              Storyboard.TargetProperty="(Border.Background).(SolidColorBrush.Color)">
            <DiscreteColorKeyFrame Value="#2563EB" KeyTime="0:0:0"/>
            <LinearColorKeyFrame Value="#1D4ED8" KeyTime="0:0:0.12"/>
            <LinearColorKeyFrame Value="#1E40AF" KeyTime="0:0:0.22"/>
          </ColorAnimationUsingKeyFrames>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Border.Triggers>
</Border>
```

**주의**: 공유 리소스(StaticResource)로 정의된 브러시에 애니메이션을 적용하면 모든 참조자가 영향을 받을 수 있습니다. 개별 컨트롤 전용 애니메이션은 로컬 브러시 인스턴스를 사용하거나 `x:Shared="False"`를 설정하세요.

## Easing 함수로 자연스러운 모션

Easing 함수는 애니메이션의 가속도를 조절합니다. `QuadraticEase`, `CubicEase`, `BounceEase`, `ElasticEase` 등이 있으며, `EaseIn`, `EaseOut`, `EaseInOut` 모드를 선택할 수 있습니다.

```xml
<DoubleAnimation Storyboard.TargetProperty="Opacity" From="0" To="1" Duration="0:0:0.45">
  <DoubleAnimation.EasingFunction>
    <SineEase EasingMode="EaseOut"/>
  </DoubleAnimation.EasingFunction>
</DoubleAnimation>
```

## VisualStateManager를 활용한 상태 기반 애니메이션

컨트롤 템플릿에서 상태 그룹을 정의하고 각 상태에 맞는 애니메이션을 연결할 수 있습니다. 코드에서는 `VisualStateManager.GoToState`로 상태를 전환합니다.

```xml
<ControlTemplate TargetType="Button">
  <Grid x:Name="Root">
    <Border x:Name="Chrome" Background="{TemplateBinding Background}" CornerRadius="10"/>
    <ContentPresenter HorizontalAlignment="Center" VerticalAlignment="Center"/>
  </Grid>
  <VisualStateManager.VisualStateGroups>
    <VisualStateGroup x:Name="CommonStates">
      <VisualState x:Name="Normal"/>
      <VisualState x:Name="MouseOver">
        <Storyboard>
          <DoubleAnimation Storyboard.TargetName="Chrome"
                           Storyboard.TargetProperty="Opacity"
                           To="0.92" Duration="0:0:0.08"/>
        </Storyboard>
      </VisualState>
      <VisualState x:Name="Pressed">
        <Storyboard>
          <DoubleAnimation Storyboard.TargetName="Root"
                           Storyboard.TargetProperty="(UIElement.RenderTransform).(ScaleTransform.ScaleY)"
                           To="0.98" Duration="0:0:0.06"/>
        </Storyboard>
      </VisualState>
      <VisualState x:Name="Disabled">
        <Storyboard>
          <DoubleAnimation Storyboard.TargetName="Root" Storyboard.TargetProperty="Opacity"
                           To="0.55" Duration="0:0:0.0"/>
        </Storyboard>
      </VisualState>
    </VisualStateGroup>
  </VisualStateManager.VisualStateGroups>
  <Grid.RenderTransform>
    <ScaleTransform ScaleX="1" ScaleY="1"/>
  </Grid.RenderTransform>
</ControlTemplate>
```

```csharp
// 코드에서 상태 전환
VisualStateManager.GoToState(this, "Pressed", useTransitions: true);
```

## 코드에서 동적 Storyboard 생성 및 제어

### 동적 생성

```csharp
var storyboard = new Storyboard { Duration = TimeSpan.FromSeconds(0.4) };
var animation = new DoubleAnimation { To = 1.0, Duration = storyboard.Duration, 
                                      EasingFunction = new CubicEase { EasingMode = EasingMode.EaseOut } };

Storyboard.SetTarget(animation, MyGrid);
Storyboard.SetTargetProperty(animation, new PropertyPath(UIElement.OpacityProperty));
storyboard.Children.Add(animation);

storyboard.Begin(); // 제어 가능: Pause, Resume, Stop, Seek
```

### 제어 메서드

```csharp
storyboard.Begin(this, true);        // isControllable: true
storyboard.Seek(this, TimeSpan.FromSeconds(0.5), TimeSeekOrigin.BeginTime);
storyboard.Pause(this);
storyboard.Resume(this);
storyboard.Stop(this);
```

## 레이아웃 변환 vs 렌더 변환

- **RenderTransform**: 그리기 단계에서만 변형 적용. 빠르며 레이아웃에 영향을 주지 않음. 애니메이션에 권장.
- **LayoutTransform**: 배치/측정 단계를 다시 수행. 느리지만 텍스트 회전 등 측정이 필요한 경우 유용.

## 자주 사용하는 타겟 속성

| 속성 | 설명 |
|------|------|
| `Opacity` | 투명도 |
| `(Border.Background).(SolidColorBrush.Color)` | 배경색 |
| `(UIElement.RenderTransform).(TranslateTransform.X)` | X축 이동 |
| `(UIElement.RenderTransform).(ScaleTransform.ScaleX)` | X축 확대 |
| `(UIElement.RenderTransform).(RotateTransform.Angle)` | 회전 각도 |
| `Width` / `Height` | 너비/높이 |
| `Margin` | 여백 (ThicknessAnimation) |

## 객체 및 가시성 애니메이션

### ObjectAnimationUsingKeyFrames (리소스 교체, Visibility 변경)

```xml
<ObjectAnimationUsingKeyFrames Storyboard.TargetProperty="Visibility" Duration="0:0:0">
  <DiscreteObjectKeyFrame KeyTime="0:0:0.0" Value="{x:Static Visibility.Visible}"/>
</ObjectAnimationUsingKeyFrames>
```

### Visibility와 페이드 동시 제어

WPF는 `Visibility`에 직접 더블 애니메이션을 적용할 수 없습니다. `Opacity`로 페이드 효과를 준 후, 애니메이션 완료 콜백이나 키프레임으로 `Visibility`를 변경합니다.

```xml
<Grid x:Name="Panel" Opacity="0" Visibility="Collapsed">
  <Grid.Triggers>
    <EventTrigger RoutedEvent="Loaded">
      <BeginStoryboard>
        <Storyboard>
          <ObjectAnimationUsingKeyFrames Storyboard.TargetProperty="Visibility">
            <DiscreteObjectKeyFrame KeyTime="0:0:0" Value="{x:Static Visibility.Visible}"/>
          </ObjectAnimationUsingKeyFrames>
          <DoubleAnimation Storyboard.TargetProperty="Opacity" To="1" Duration="0:0:0.25"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Grid.Triggers>
</Grid>
```

## 뷰 전환 애니메이션 패턴

두 개의 콘텐츠 영역을 교차 페이드하면서 슬라이드 효과를 주는 예제입니다.

```xml
<Grid x:Name="Host">
  <ContentPresenter x:Name="ViewA"/>
  <ContentPresenter x:Name="ViewB" Opacity="0">
    <ContentPresenter.RenderTransform>
      <TranslateTransform X="40"/>
    </ContentPresenter.RenderTransform>
  </ContentPresenter>
</Grid>

<!-- 전환 시 -->
<BeginStoryboard>
  <Storyboard FillBehavior="Stop">
    <DoubleAnimation Storyboard.TargetName="ViewA" Storyboard.TargetProperty="Opacity"
                     To="0" Duration="0:0:0.18"/>
    <DoubleAnimation Storyboard.TargetName="ViewB" Storyboard.TargetProperty="Opacity"
                     To="1" Duration="0:0:0.25"/>
    <DoubleAnimation Storyboard.TargetName="ViewB"
                     Storyboard.TargetProperty="(UIElement.RenderTransform).(TranslateTransform.X)"
                     From="40" To="0" Duration="0:0:0.25"/>
  </Storyboard>
</BeginStoryboard>
```

`FillBehavior="Stop"`을 사용하면 애니메이션 종료 후 속성이 원래 상태로 복귀합니다. 상태를 고정하려면 `HoldEnd`를 사용하거나 애니메이션 종료 후 속성을 직접 설정하세요.

## 성능 및 안정성 팁

1. **RenderTransform 우선**: 레이아웃 재계산을 피하기 위해 `RenderTransform`을 사용하세요.
2. **Freezable 객체 주의**: 공유 리소스(브러시 등)에 애니메이션을 적용하지 마세요. 개별 인스턴스를 사용하거나 `x:Shared="False"`를 설정합니다.
3. **트리거 복잡도 관리**: 너무 많은 트리거는 성능 저하를 일으킵니다. VSM으로 상태를 그룹화하여 관리하세요.
4. **애니메이션 경량화**: 많은 애니메이션을 동시에 실행하지 않도록 합니다.
5. **BitmapCache 활용**: 복잡한 시각 요소에 `CacheMode="BitmapCache"`를 설정하면 렌더링 성능이 향상될 수 있습니다(품질과 메모리 사용량 트레이드오프 고려).
6. **CompositionTarget.Rendering 주의**: 매 프레임 호출되는 이벤트는 남용하지 마세요.

## MVVM 친화적 패턴

### ViewModel 속성에 따른 상태 전환

Attached Property를 사용하여 ViewModel의 상태를 VSM에 바인딩할 수 있습니다.

```csharp
public static class VisualStateHelper
{
    public static readonly DependencyProperty StateProperty =
        DependencyProperty.RegisterAttached("State", typeof(string), typeof(VisualStateHelper),
            new PropertyMetadata(null, OnStateChanged));

    public static string GetState(DependencyObject obj) => (string)obj.GetValue(StateProperty);
    public static void SetState(DependencyObject obj, string value) => obj.SetValue(StateProperty, value);

    private static void OnStateChanged(DependencyObject d, DependencyPropertyChangedEventArgs e)
    {
        if (d is FrameworkElement element && e.NewValue is string stateName)
        {
            element.Loaded += (s, args) => VisualStateManager.GoToState(element, stateName, true);
        }
    }
}
```

```xml
<Grid local:VisualStateHelper.State="{Binding CurrentState}">
  <VisualStateManager.VisualStateGroups>
    <VisualStateGroup x:Name="AppStates">
      <VisualState x:Name="Loading"/>
      <VisualState x:Name="Loaded"/>
      <VisualState x:Name="Error"/>
    </VisualStateGroup>
  </VisualStateManager.VisualStateGroups>
</Grid>
```

### Behaviors 사용 (Microsoft.Xaml.Behaviors.Wpf)

```xml
<i:Interaction.Triggers>
  <i:EventTrigger EventName="SomeEventFromVM">
    <i:ControlStoryboardAction Storyboard="{StaticResource SlideIn}"/>
  </i:EventTrigger>
</i:Interaction.Triggers>
```

## 일반적인 오류와 해결 방법

| 오류 | 해결 |
|------|------|
| TargetProperty 경로 오타 | 괄호와 타입 이름을 정확히 입력. 예: `(UIElement.RenderTransform).(TranslateTransform.X)` |
| 공유 브러시에 Color 애니메이션 적용 안 됨 | 로컬 브러시 인스턴스를 사용하거나 `x:Shared="False"`로 설정 |
| Visibility 애니메이션이 동작하지 않음 | `Visibility`는 연속 값이 아님. `ObjectAnimationUsingKeyFrames` 사용 |
| FillBehavior 충돌 | 원하는 최종 상태에 맞게 `HoldEnd` 또는 `Stop` 설정 |
| EventTrigger에 다른 로직 포함 | `EventTrigger`는 Storyboard 실행 전용. 명령이나 코드로 분리 |

## 실전 스니펫

### FadeIn/FadeOut 리소스

```xml
<Window.Resources>
  <Storyboard x:Key="FadeIn">
    <DoubleAnimation Storyboard.TargetProperty="Opacity" From="0" To="1" Duration="0:0:0.22"/>
  </Storyboard>
  <Storyboard x:Key="FadeOut">
    <DoubleAnimation Storyboard.TargetProperty="Opacity" To="0" Duration="0:0:0.18"/>
  </Storyboard>
</Window.Resources>
```

### SlideUp 알림 패널

```xml
<Grid x:Name="Toast" Opacity="0" RenderTransformOrigin="0.5,0.5">
  <Grid.RenderTransform><TranslateTransform Y="20"/></Grid.RenderTransform>
  <Grid.Triggers>
    <EventTrigger RoutedEvent="Loaded">
      <BeginStoryboard>
        <Storyboard>
          <DoubleAnimation Storyboard.TargetProperty="Opacity" To="1" Duration="0:0:0.18"/>
          <DoubleAnimation Storyboard.TargetProperty="(UIElement.RenderTransform).(TranslateTransform.Y)"
                           From="20" To="0" Duration="0:0:0.2"/>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </Grid.Triggers>
</Grid>
```

### ProgressBar 컬러 스윕

```xml
<ProgressBar x:Name="Bar" Minimum="0" Maximum="100" Value="60" Height="10">
  <ProgressBar.Foreground>
    <SolidColorBrush Color="#22C55E"/>
  </ProgressBar.Foreground>
  <ProgressBar.Triggers>
    <EventTrigger RoutedEvent="Loaded">
      <BeginStoryboard>
        <Storyboard RepeatBehavior="Forever">
          <ColorAnimationUsingKeyFrames Storyboard.TargetProperty="(ProgressBar.Foreground).(SolidColorBrush.Color)">
            <LinearColorKeyFrame Value="#22C55E" KeyTime="0:0:0"/>
            <LinearColorKeyFrame Value="#F59E0B" KeyTime="0:0:0.6"/>
            <LinearColorKeyFrame Value="#EF4444" KeyTime="0:0:1.2"/>
          </ColorAnimationUsingKeyFrames>
        </Storyboard>
      </BeginStoryboard>
    </EventTrigger>
  </ProgressBar.Triggers>
</ProgressBar>
```

## 결론

WPF 애니메이션은 선언적 XAML 접근과 코드 제어가 균형을 이루는 강력한 도구입니다. 간단한 효과는 `Storyboard`와 `Trigger`로 쉽게 구현할 수 있고, 복잡한 상태 관리가 필요한 경우 `VisualStateManager`를 활용하면 체계적으로 구성할 수 있습니다. 위에서 제시한 스니펫과 패턴을 조합하여 페이지 전환, 로딩 인디케이터, 사용자 피드백 등 다양한 상황에 적용해 보세요. 성능과 유지보수성을 고려한 설계가 안정적인 애플리케이션의 핵심입니다.
