# 리눅스 명령어 기초와 디렉토리 구조

## 리눅스 명령어의 기본 구조

리눅스 명령어는 다음과 같은 구조로 이루어진다.

```bash
명령어 [옵션] [대상...]
```

예를 들어 `/etc` 디렉토리의 내용을 자세히 보려면 `ls -l /etc`를 입력한다. 여기서 `ls`는 명령어, `-l`은 옵션, `/etc`는 대상이다.

### 옵션과 인자 규칙

옵션은 여러 개를 합칠 수 있다. `ls -lah`는 `-l`, `-a`, `-h`를 결합한 것이다. 긴 옵션은 `--all`처럼 두 개의 대시를 사용한다.

여러 대상을 지정할 수도 있다.
```bash
cp a.txt b.txt /tmp/
```

파일명이 `-`로 시작할 경우 `--`를 사용해 옵션의 끝을 명시할 수 있다.
```bash
grep -n -- "-pattern" file.txt
```

### 인용(quoting)과 확장

이중따옴표 안에서는 변수가 확장되고, 단일따옴표 안에서는 확장되지 않는다.

```bash
echo "HOME is $HOME"    # HOME is /home/user
echo 'HOME is $HOME'    # HOME is $HOME
```

백슬래시는 특수 문자를 이스케이프한다.

### 글로빙(globbing)과 브레이스 확장

- 와일드카드: `*` (아무 문자열), `?` (한 문자), `[abc]` (문자 집합)
- 중괄호 확장: 중괄호 안의 목록을 반복 생성

```bash
ls *.log                 # 모든 .log 파일
cp app.{yml,yaml} /etc/  # app.yml과 app.yaml 복사
echo {1..5}              # 1 2 3 4 5
```

## 리눅스 디렉토리 구조 (FHS 핵심)

리눅스는 루트 디렉토리 `/`를 기준으로 계층 구조를 가진다. 아래 표는 핵심 디렉토리와 용도다.

| 디렉토리 | 용도 |
|----------|------|
| `/` | 최상위 루트, 모든 경로의 시작점 |
| `/bin` | 기본 사용자 명령어 (`ls`, `cp` 등) |
| `/sbin` | 시스템 관리자 명령어 (`reboot`, `fsck` 등) |
| `/etc` | 시스템 및 서비스 설정 파일 |
| `/home` | 일반 사용자의 홈 디렉토리 |
| `/root` | 루트 사용자의 홈 디렉토리 |
| `/usr` | 사용자 애플리케이션, 라이브러리, 문서 |
| `/var` | 가변 데이터 (로그, 캐시, 스풀) |
| `/tmp` | 임시 파일 (재부팅 시 사라질 수 있음) |
| `/dev` | 장치 파일 (디스크, 터미널 등) |
| `/proc` | 가상 파일 시스템, 프로세스 정보 |
| `/sys` | 가상 파일 시스템, 커널 객체 정보 |
| `/run` | 런타임 데이터 (PID 파일, 소켓) |
| `/mnt`, `/media` | 임시 마운트 지점 |

실제 구조를 확인하려면 `ls -l /`를 실행해보자. `/proc/self`는 현재 프로세스의 정보를 제공한다.

## 파일 및 디렉토리 조작

### 목록 보기
```bash
ls               # 기본 목록
ls -l            # 자세한 정보
ls -a            # 숨김 파일 포함
ls -lh           # 사람이 읽기 쉬운 크기
ls -lt           # 최근 수정 순
ls -lt | head    # 최근 수정 상위 10개
```

### 경로 이동
```bash
cd /home/user    # 절대 경로
cd ./user        # 상대 경로 (현재 디렉토리 아래)
cd ..            # 상위 디렉토리
cd ~             # 홈 디렉토리
cd -             # 이전 디렉토리
pwd              # 현재 경로 출력
```

### 생성과 삭제
```bash
mkdir test               # 디렉토리 생성
mkdir -p a/b/c           # 중간 디렉토리도 함께 생성
rmdir empty-dir          # 빈 디렉토리 삭제
rm -r non-empty-dir/     # 하위 내용 포함 삭제
rm -rf /                 # 절대 사용 금지!
```

### 복사, 이동, 이름 변경
```bash
touch file.txt           # 빈 파일 생성
cp a.txt b.txt           # 복사
cp -r dir1 dir2          # 디렉토리 복사
mv old.txt new.txt       # 이름 변경 또는 이동
mv file.txt /tmp/        # 파일 이동
```

### 링크
하드 링크는 같은 inode를 가리키며, 심볼릭 링크는 경로를 가리킨다.
```bash
ln original hardlink     # 하드 링크
ln -s /path/to/target symlink   # 심볼릭 링크
ls -li                   # inode 확인
```

### 압축과 아카이브
```bash
tar -czf logs.tgz /var/log       # 압축 아카이브 생성
tar -xzf logs.tgz -C /tmp/       # 압축 해제
zip -r data.zip data/            # zip 압축
unzip data.zip -d /data          # 압축 해제
```

## 파일 내용 확인

### 전체 보기와 페이지 단위 보기
```bash

```

```bash

```

## 검색: find와 grep

### find로 파일 찾기
```bash
find . -name "*.log"                       # 이름으로 검색
find /etc -type f -size +10M               # 10MB 초과 파일
find /var/www -type f -mtime -7 -name "*.php"  # 7일 내 수정된 PHP 파일
find . -type f -exec chmod 640 {} \;       # 권한 일괄 변경
find . -type f -print0 | xargs -0 wc -l    # 공백 안전하게 라인 수 계산
```

### grep으로 텍스트 검색
```bash
grep "error" file.txt                      # 기본 검색
grep -r "main" ./src/                      # 재귀 검색
grep -ni "fail(ed)?" app.log               # 대소문자 무시, 줄 번호, 정규표현식
grep -E "(WARN|ERROR)" app.log             # 확장 정규표현식
```

### 정규표현식 간단 규칙
- `.` : 임의의 한 문자
- `*` : 0회 이상 반복
- `+` : 1회 이상 반복 (`-E` 필요)
- `?` : 0 또는 1회 (`-E` 필요)
- `[abc]` : a, b, c 중 하나
- `(a|b)` : a 또는 b (`-E` 필요)

## 리다이렉션, 파이프, xargs

### 리다이렉션
```bash
ls -l > list.txt          # 표준출력을 파일에 저장 (덮어쓰기)
ls -l >> list.txt         # 추가
make 2> error.log         # 표준에러만 저장
cmd > all.log 2>&1        # 표준출력과 표준에러를 같은 파일로
```

### 파이프와 tee
파이프(`|`)는 한 명령의 출력을 다음 명령의 입력으로 연결한다. `tee`는 출력을 화면과 파일에 동시에 저장한다.
```bash
ps aux | grep nginx | grep -v grep | awk '{print $2}' | xargs -r sudo kill
dmesg | tee dmesg.txt | grep -i usb
```

### xargs로 인수 전달
`xargs`는 표준입력을 명령어의 인수로 변환한다.
```bash
# 개행으로 구분된 파일 목록을 인수로
cat files.txt | xargs -I{} cp {} /backup/

# 공백 안전하게 처리 (NUL 구분)
find . -type f -print0 | xargs -0 -I{} sha256sum "{}" >> checksums.txt
```

## 권한과 소유권

### 권한 표현
리눅스 파일 권한은 소유자(u), 그룹(g), 기타(o)에 대해 읽기(r=4), 쓰기(w=2), 실행(x=1)의 합으로 나타낸다.
$$
\text{perm} = 4\cdot I(r) + 2\cdot I(w) + 1\cdot I(x)
$$
예를 들어 `rwxr-x---`는 소유자 7, 그룹 5, 기타 0이므로 `chmod 750 file`이다.

### 기본 명령
```bash
chmod 755 script.sh
chmod +x myapp
chown user:group file.txt
stat file.txt
```

### 기호 방식
```bash
chmod u+x,g-w,o= file.sh   # 소유자 실행 추가, 그룹 쓰기 제거, 기타 권한 없음
```

### 특수 비트
- setuid (4) : 실행 시 소유자 권한으로 실행
- setgid (2) : 디렉토리 내 파일이 그룹 상속
- sticky (1) : 디렉토리 내 파일 소유자만 삭제 가능

```bash
chmod 4755 /usr/bin/passwd   # setuid
chmod 2755 shared-dir        # setgid
chmod 1777 /tmp              # sticky
```

### umask
`umask`는 새 파일/디렉토리 생성 시 기본 권한에서 제거할 비트를 설정한다.
```bash
umask           # 현재 값 (예: 0022)
umask 0027      # 더 보수적으로 설정
```

## 텍스트 처리 도구

### cut, paste, tr
```bash
cut -d, -f1,3 data.csv          # 콤마 구분 CSV에서 1,3열 추출
tr -d '\r' < win.txt > unix.txt # CR 제거 (Windows → Unix)
paste file1 file2               # 두 파일을 열로 결합
```

### sort, uniq
```bash
sort access.log | uniq -c | sort -nr | head   # 빈도 높은 상위 항목
sort -t, -k3,3n data.csv                      # 3열 숫자 기준 정렬
```

### awk
`awk`는 열 기반 데이터 처리에 강력하다.
```bash
# CSV의 세 번째 열 합계
awk -F, '{sum+=$3} END{print sum}' data.csv

# CPU 점유율 20% 초과 프로세스 출력
ps aux | awk '$3>20 {printf "%-8s %6s %5s%% %s\n",$1,$2,$3,$11}'
```

### sed
`sed`는 스트림 편집기로 텍스트 변환에 사용한다.
```bash
sed -n '1,100p' file.txt               # 1~100행 출력
sed 's/error/ERROR/g' app.log > out.log  # 치환
sed -E '/^\s*#/d;/^\s*$/d' conf        # 주석과 빈 줄 제거
```

### join, comm
집합 연산을 위해 `join`과 `comm`을 사용할 수 있다. `comm`은 정렬된 파일 간 비교를 수행한다.
```bash
sort a.txt > a.sorted
sort b.txt > b.sorted
comm -12 a.sorted b.sorted      # 교집합
```

## 시스템, 프로세스, 서비스 관리

### 시스템 정보
```bash
uname -a
cat /etc/os-release
lscpu
free -h
df -hT
du -sh * | sort -h
```

### 프로세스 확인과 제어
```bash
ps aux | head
top                # 실시간 모니터링 (htop 추천)
pidof nginx
kill -TERM <pid>   # 정상 종료 시도
kill -KILL <pid>   # 강제 종료
pkill -f "python app.py"
```

### 우선순위 (nice, renice)
```bash
nice -n 10 long_task.sh               # 낮은 우선순위로 실행
sudo renice -n -5 -p <pid>            # 기존 프로세스 우선순위 높임
```

### 백그라운드 작업과 nohup
```bash
long_task.sh &                        # 백그라운드 실행
jobs                                  # 작업 목록
fg %1                                 # 포그라운드로 전환
bg %1                                 # 중단된 작업 백그라운드 재개
nohup long_task.sh > run.log 2>&1 &   # 로그아웃 후에도 실행
```

### systemd 서비스
```bash
sudo systemctl status nginx
sudo systemctl enable --now nginx
sudo systemctl restart nginx
sudo journalctl -u nginx --since "1 hour ago"
```

## 로그, 진단, 보안 기초

### 로그 확인
```bash
sudo journalctl -b                     # 부팅 이후 전체 로그
sudo journalctl -u ssh --since "today"
sudo tail -f /var/log/syslog           # Debian/Ubuntu
sudo tail -f /var/log/messages         # RHEL 계열
```

### 방화벽 (UFW)
```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw allow 80,443/tcp
sudo ufw enable
sudo ufw status verbose
```

### SSH 보안 강화
```bash
# 키 생성
ssh-keygen -t ed25519 -C "me@example.com"
ssh-copy-id user@server

# 설정 파일 수정 (PasswordAuthentication no, PermitRootLogin prohibit-password)
sudoedit /etc/ssh/sshd_config
sudo systemctl restart ssh
```

## 스케줄러: cron과 at

### cron (주기적 작업)
```bash
crontab -e
# 매일 03:00 백업 스크립트 실행
0 3 * * * /usr/local/bin/backup.sh
crontab -l   # 현재 사용자 크론 목록
```

### at (일회성 작업)
```bash
echo "bash /home/user/run_once.sh" | at 23:00
atq           # 대기 중인 작업 확인
atrm <job>    # 작업 삭제
```

## 실전 시나리오 모음

### 시나리오 1: 로그에서 에러 빈도 분석
```bash
zcat app-*.log.gz \
| grep -Ei "(ERROR|FATAL)" \
| awk '{print $1}' \
| sort | uniq -c | sort -nr | head -10
```

### 시나리오 2: 디스크 공간 부족 시 대용량 파일 찾기
```bash
df -hT
du -sh /* 2>/dev/null | sort -h | tail
find /var/log -type f -size +200M -exec ls -lh {} \;
sudo journalctl --vacuum-time=7d
```

### 시나리오 3: 서비스 장애 대응
```bash
sudo systemctl status myapp
sudo journalctl -u myapp --since "30 min ago"
ss -tulpn | grep :8080
sudo lsof -i :8080
```

### 시나리오 4: 파일 인코딩 변환 (CRLF → LF)
```bash
find . -type f -name "*.txt" -print0 | xargs -0 sed -i 's/\r$//'
```

### 시나리오 5: 백업과 무결성 검증
```bash
# rsync 미러링
rsync -a --delete /srv/data/ backup@host:/backup/data/

# 체크섬 생성 및 검증
find /srv/data -type f -print0 | xargs -0 sha256sum > data.sha256
sha256sum -c data.sha256
```

## 결론

리눅스 명령어의 힘은 각 도구가 작은 역할에 집중하고, 파이프와 리다이렉션을 통해 이들을 조합하는 데 있다. 이 문서는 초중급 사용자가 가장 많이 접하게 될 명령어와 실무에서 자주 등장하는 패턴을 중심으로 구성되었다.

처음에는 디렉토리 구조와 기본 파일 조작에 익숙해지는 것이 좋다. 그다음 권한 관리, 텍스트 처리 도구(grep, sed, awk), 프로세스 및 서비스 관리 순서로 확장해 나가면 체계적으로 실력을 쌓을 수 있다. 문제 해결 시에는 로그 확인 → 프로세스 상태 점검 → 리소스(디스크, 네트워크) 확인이라는 접근법이 효과적이다.

모든 명령어의 상세 옵션은 `man 명령어`나 `--help`로 확인할 수 있다. 이 문서를 기초로 셸 스크립트와 자동화로 나아가길 바란다.
