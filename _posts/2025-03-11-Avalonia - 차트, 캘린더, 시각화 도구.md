# Avalonia에서 차트, 캘린더, 시각화 도구 사용하기

Avalonia 애플리케이션에서 데이터 시각화를 구현하려면 차트 라이브러리와 캘린더 컨트롤을 잘 조합해야 합니다. 이 글에서는 **LiveCharts2**와 **OxyPlot** 두 가지 차트 라이브러리를 소개하고, 날짜 선택 및 간단한 달력을 구성하는 방법, 그리고 이들을 MVVM 패턴과 연동하는 실전 예제를 다룹니다.

---

## 프로젝트 준비

시작하기 전에 필요한 NuGet 패키지를 추가합니다.

```bash
dotnet add package LiveChartsCore.SkiaSharpView.Avalonia
dotnet add package OxyPlot.Avalonia
dotnet add package ReactiveUI
```

XAML에서 사용할 네임스페이스를 선언합니다.

```xml
xmlns:lvc="clr-namespace:LiveChartsCore.SkiaSharpView.Avalonia;assembly=LiveChartsCore.SkiaSharpView.Avalonia"
xmlns:oxy="clr-namespace:OxyPlot.Avalonia;assembly=OxyPlot.Avalonia"
```

## LiveCharts2 빠르게 시작하기

LiveCharts2는 SkiaSharp 기반의 현대적인 차트 라이브러리로, 애니메이션과 실시간 업데이트에 강점이 있습니다.

### 기본 꺾은선 차트

**ViewModel**

```csharp
using LiveChartsCore;
using LiveChartsCore.SkiaSharpView;

public class MainViewModel
{
    public ISeries[] LineSeries { get; }
    public string[] Labels { get; }

    public MainViewModel()
    {
        LineSeries = new ISeries[]
        {
            new LineSeries<double>
            {
                Values = new double[] { 3, 5, 7, 4, 6, 8 },
                Name = "판매량"
            }
        };
        Labels = new[] { "1월", "2월", "3월", "4월", "5월", "6월" };
    }
}
```

**XAML**

```xml
<lvc:CartesianChart Series="{Binding LineSeries}">
  <lvc:CartesianChart.XAxes>
    <lvc:Axis Labels="{Binding Labels}" Name="X" />
  </lvc:CartesianChart.XAxes>
  <lvc:CartesianChart.YAxes>
    <lvc:Axis Name="Y" MinLimit="0" MaxLimit="10" />
  </lvc:CartesianChart.YAxes>
</lvc:CartesianChart>
```

- `ISeries[]`는 여러 시리즈를 담는 배열입니다.
- `Axis`의 `Labels`는 범주형 라벨을 지정합니다.
- `MinLimit`, `MaxLimit`으로 Y축 범위를 고정할 수 있습니다.

### 막대 차트

## 실시간 업데이트

LiveCharts2는 `ObservableValue`를 통해 값이 변경될 때마다 자동으로 차트를 갱신할 수 있습니다.

### 단일 값 실시간 추적

```csharp
using LiveChartsCore.Defaults;

public class RealtimeViewModel
{
    private readonly ObservableValue _value = new(0);

    public ISeries[] Series { get; }

    public RealtimeViewModel()
    {
        Series = new ISeries[]
        {
            new LineSeries<ObservableValue> { Values = new[] { _value } }
        };

        // 0.5초마다 값 증가
        var timer = new System.Threading.Timer(_ =>
        {
            _value.Value += 1;
        }, null, 0, 500);
    }
}
```

### 롤링 버퍼 (최근 N개 유지)

```csharp
public class RollingViewModel
{
    private readonly List<ObservableValue> _buffer = new();

    public ISeries[] Series { get; }

    public RollingViewModel()
    {
        for (int i = 0; i < 50; i++) _buffer.Add(new ObservableValue(0));

        Series = new ISeries[]
        {
            new LineSeries<ObservableValue> { Values = _buffer }
        };

        var rnd = new Random();
        var timer = new System.Threading.Timer(_ =>
        {
            Avalonia.Threading.Dispatcher.UIThread.Post(() =>
            {
                _buffer.Add(new ObservableValue(rnd.Next(0, 10)));
                if (_buffer.Count > 120) _buffer.RemoveAt(0);
            });
        }, null, 0, 250);
    }
}
```

## OxyPlot – 가벼운 정적 차트

OxyPlot은 학술/보고서용 정적 차트에 적합하며, 줌/팬 기능이 내장되어 있습니다.

```xml
<oxy:PlotView Model="{Binding PlotModel}" />
```

```csharp
using OxyPlot;
using OxyPlot.Axes;
using OxyPlot.Series;

public class OxyPlotViewModel
{
    public PlotModel PlotModel { get; } = new PlotModel { Title = "샘플 그래프" };

    public OxyPlotViewModel()
    {
        PlotModel.Axes.Add(new LinearAxis { Position = AxisPosition.Left, Title = "Y" });
        PlotModel.Axes.Add(new LinearAxis { Position = AxisPosition.Bottom, Title = "X" });

        var line = new LineSeries { Title = "추세" };
        line.Points.Add(new DataPoint(0, 0));
        line.Points.Add(new DataPoint(10, 18));
        line.Points.Add(new DataPoint(20, 12));
        PlotModel.Series.Add(line);
    }
}
```

OxyPlot은 `PngExporter`를 통해 이미지로 내보내기 쉽고, 상호작용(줌, 팬)이 직관적입니다.

## 캘린더와 날짜 선택

Avalonia는 기본 `DatePicker` 컨트롤을 제공하지만, 월별 달력이 필요한 경우 직접 구현할 수 있습니다.

### DatePicker 사용

```xml
<DatePicker SelectedDate="{Binding SelectedDate}" />
```

```csharp
private DateTimeOffset? _selectedDate = DateTimeOffset.Now;
public DateTimeOffset? SelectedDate
{
    get => _selectedDate;
    set => this.RaiseAndSetIfChanged(ref _selectedDate, value);
}
```

### 간단한 월 달력 (UniformGrid 기반)

**ViewModel**

```csharp
public record CalendarCell(DateTime Date, bool IsCurrentMonth, bool HasEvents);

public class CalendarViewModel : ReactiveObject
{
    private DateTime _current = DateTime.Today;
    public ObservableCollection<CalendarCell> Cells { get; } = new();
    public string MonthTitle => _current.ToString("yyyy MMMM");

    public ReactiveCommand<Unit, Unit> PrevMonth { get; }
    public ReactiveCommand<Unit, Unit> NextMonth { get; }

    private readonly HashSet<DateTime> _eventDays = new(); // 이벤트가 있는 날짜

    public CalendarViewModel()
    {
        PrevMonth = ReactiveCommand.Create(() => { _current = _current.AddMonths(-1); Build(); });
        NextMonth = ReactiveCommand.Create(() => { _current = _current.AddMonths(1); Build(); });
        Build();
    }

    private void Build()
    {
        Cells.Clear();
        var first = new DateTime(_current.Year, _current.Month, 1);
        int offset = ((int)first.DayOfWeek + 6) % 7; // 월요일 시작
        var start = first.AddDays(-offset);
        for (int i = 0; i < 42; i++)
        {
            var d = start.AddDays(i);
            Cells.Add(new CalendarCell(d, d.Month == _current.Month, _eventDays.Contains(d.Date)));
        }
        this.RaisePropertyChanged(nameof(MonthTitle));
    }
}
```

**XAML (간략화)**

```xml
<Grid RowDefinitions="Auto,Auto,*">
  <StackPanel Orientation="Horizontal">
    <Button Command="{Binding PrevMonth}" Content="<"/>
    <TextBlock Text="{Binding MonthTitle}"/>
    <Button Command="{Binding NextMonth}" Content=">"/>
  </StackPanel>

  <UniformGrid Grid.Row="1" Columns="7" Rows="1">
    <TextBlock Text="월"/><TextBlock Text="화"/><TextBlock Text="수"/><TextBlock Text="목"/>
    <TextBlock Text="금"/><TextBlock Text="토"/><TextBlock Text="일"/>
  </UniformGrid>

  <ItemsControl Grid.Row="2" Items="{Binding Cells}">
    <ItemsControl.ItemsPanel>
      <ItemsPanelTemplate><UniformGrid Columns="7" Rows="6"/></ItemsPanelTemplate>
    </ItemsControl.ItemsPanel>
    <ItemsControl.ItemTemplate>
      <DataTemplate>
        <Border Background="{Binding IsCurrentMonth, Converter={StaticResource BoolToBrush}}">
          <TextBlock Text="{Binding Date.Day}"/>
        </Border>
      </DataTemplate>
    </ItemsControl.ItemTemplate>
  </ItemsControl>
</Grid>
```

- `BoolToBrushConverter`로 현재월과 다른 월의 배경을 구분합니다.
- 날짜 클릭 시 `SelectedDate`를 업데이트하는 로직을 추가하면 차트와 연동할 수 있습니다.

## 캘린더와 차트 연동

달력에서 날짜를 선택하면 해당 날짜의 데이터를 차트에 표시하는 예제입니다.

**통합 ViewModel**

```csharp
public class DashboardViewModel : ReactiveObject
{
    public CalendarViewModel Calendar { get; }
    public MetricsChartViewModel Chart { get; }

    public DashboardViewModel(IMetricService metricService)
    {
        Calendar = new CalendarViewModel();
        Chart = new MetricsChartViewModel(metricService);

        // 날짜 선택 시 차트 업데이트
        this.WhenAnyValue(x => x.Calendar.SelectedDate)
            .Where(d => d.HasValue)
            .Subscribe(async d => await Chart.LoadAsync(d.Value.DateTime));
    }
}
```

**MetricsChartViewModel** (LiveCharts2 사용)

```csharp
public class MetricsChartViewModel : ReactiveObject
{
    private readonly IMetricService _service;
    public ObservableCollection<ISeries> Series { get; } = new();

    public MetricsChartViewModel(IMetricService service) => _service = service;

    public async Task LoadAsync(DateTime day, CancellationToken ct = default)
    {
        var data = await _service.GetHourlyAsync(day, ct);
        Series.Clear();
        Series.Add(new LineSeries<double>
        {
            Values = data.Select(x => x.value).ToArray(),
            Name = day.ToShortDateString()
        });
    }
}
```

**IMetricService** 구현 예:

```csharp
public interface IMetricService
{
    Task<IReadOnlyList<(DateTime time, double value)>> GetHourlyAsync(DateTime day, CancellationToken ct = default);
}
```

이렇게 하면 달력에서 날짜를 클릭할 때마다 차트가 해당 날짜의 시간별 데이터를 보여줍니다.

## 차트 내보내기 (이미지 저장)

Avalonia의 `RenderTargetBitmap`을 이용해 차트 컨트롤을 PNG로 저장할 수 있습니다.

```csharp
using Avalonia;
using Avalonia.Controls;
using Avalonia.Media.Imaging;

public static class VisualExport
{
    public static async Task SaveToPngAsync(Control control, string path)
    {
        var size = new Size(control.Bounds.Width, control.Bounds.Height);
        var pixelSize = new PixelSize((int)size.Width, (int)size.Height);

        control.Measure(size);
        control.Arrange(new Rect(size));

        using var rtb = new RenderTargetBitmap(pixelSize, new Vector(96, 96));
        rtb.Render(control);

        await using var fs = File.Open(path, FileMode.Create);
        rtb.Save(fs);
    }
}
```

OxyPlot은 자체 `PngExporter`를 제공해 더 간단하게 이미지로 저장할 수 있습니다.

```csharp
using OxyPlot;

var exporter = new PngExporter { Width = 800, Height = 600 };
exporter.Export(plotModel, "chart.png");
```

## 성능 및 최적화 팁

| 항목 | 권장 |
|------|------|
| 데이터 포인트 수 | 수천 개 이상이면 다운샘플링 또는 집계 |
| 업데이트 주기 | 100~500ms 단위로 배치 업데이트 |
| 바인딩 | `ObservableValue`로 직접 갱신, 컬렉션 재할당 최소화 |
| 축 라벨 | 회전, 포맷을 간결하게 유지 |
| 렌더링 | SkiaSharp는 CPU 렌더링, 많은 시리즈는 개수 제한 |

## LiveCharts2 vs OxyPlot 비교

| 항목 | LiveCharts2 | OxyPlot |
|------|-------------|---------|
| 렌더링 | SkiaSharp, 애니메이션 중심 | 벡터 기반, 정적 |
| 실시간 | 강함 (`ObservableValue`, 버퍼링) | 가능하나 애니메이션 부족 |
| 상호작용 | 줌/팬 기본 제공 | 줌/팬 강함 |
| 내보내기 | 컨트롤 캡처 필요 | `PngExporter`, `SvgExporter` 내장 |
| 사용 용도 | 현대적 UI, 대시보드 | 학술 보고서, 분석 도구 |

두 라이브러리를 동일 앱에서 상황에 따라 혼용해도 무방합니다.

## 자주 겪는 문제와 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| 차트 갱신 안 됨 | 컬렉션 참조 유지 | `ObservableValue` 사용 또는 새 배열 할당 |
| 프레임 드랍 | 데이터 과다 | 포인트 다운샘플링, 업데이트 주기 조절 |
| 라벨 겹침 | 축 범위/회전 미설정 | `LabelsRotation`, `MinStep` 설정 |
| 다크 테마에서 가독성 저하 | 기본 색상 어두움 | 축/글자 색을 명시적으로 지정 |

## 결론

Avalonia에서 차트와 캘린더를 구현할 때는 LiveCharts2와 OxyPlot의 특성을 이해하고, MVVM 패턴에 맞게 ViewModel에 데이터를 노출하는 것이 중요합니다. 실시간 데이터에는 LiveCharts2가 적합하고, 정적 분석이나 보고서에는 OxyPlot이 유리합니다. 캘린더는 `DatePicker`로 충분할 때가 많지만, 필요한 경우 UniformGrid 기반 커스텀 달력을 만들어 다양한 시각화 요소와 연동할 수 있습니다.

이 글에서 소개한 예제들을 바탕으로 여러분의 애플리케이션에 맞는 시각화 도구를 선택하고, 사용자 경험을 향상시키세요.
