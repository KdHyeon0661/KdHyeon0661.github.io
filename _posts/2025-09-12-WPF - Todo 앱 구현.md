# WPF Todo 앱 구현 가이드

이 글에서는 WPF와 MVVM 패턴을 활용하여 실무 수준의 Todo 애플리케이션을 처음부터 구현하는 방법을 설명합니다. 초중급 개발자를 대상으로 하며, 깔끔한 아키텍처 분리, 테스트 가능성, 사용자 경험까지 고려한 구현을 목표로 합니다.

---

## 전체 아키텍처

애플리케이션을 네 개의 계층으로 나누어 유지보수성과 확장성을 확보합니다.

```
TodoApp/
  TodoApp.App/           # WPF UI (뷰, 뷰모델, 변환기, 스타일)
  TodoApp.Domain/        # 도메인 (모델, 인터페이스, 검증)
  TodoApp.Storage/       # 데이터 접근 (JSON 파일 저장소)
  TodoApp.Tests/         # 단위 테스트
```

계층 간 의존성은 **안쪽으로만** 향합니다. UI 계층은 도메인과 저장소를 참조하고, 저장소는 도메인만 참조합니다. 이렇게 하면 나중에 JSON 대신 SQLite나 REST API로 교체할 때 UI나 도메인을 건드리지 않고 저장소 구현만 바꾸면 됩니다.

public interface ITodoStore

    Task<IReadOnlyList<TodoItem>> GetAllAsync();
    Task<TodoItem?> GetByIdAsync(Guid id);
    Task AddAsync(TodoItem item);
    Task UpdateAsync(TodoItem item);
    Task DeleteAsync(Guid id);
    Task SaveChangesAsync(); // 필요한 경우

## 2. 저장소 계층 (Storage)

JSON 파일을 이용한 로컬 저장소 구현입니다. `System.Text.Json`을 사용합니다.

```csharp
// TodoApp.Storage/JsonFileStore.cs
public class JsonFileStore : ITodoStore
{
    private readonly string _filePath;
    private List<TodoItem> _items;

    public JsonFileStore()
    {
        var folder = Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
            "TodoApp");
        Directory.CreateDirectory(folder);
        _filePath = Path.Combine(folder, "todos.json");
        LoadFromFile();
    }

    private void LoadFromFile()
    {
        if (File.Exists(_filePath))
        {
            var json = File.ReadAllText(_filePath);
            _items = JsonSerializer.Deserialize<List<TodoItem>>(json) ?? new();
        }
        else
        {
            _items = new();
        }
    }

    private void SaveToFile()
    {
        var json = JsonSerializer.Serialize(_items, new JsonSerializerOptions { WriteIndented = true });
        File.WriteAllText(_filePath, json);
    }

    public Task<IReadOnlyList<TodoItem>> GetAllAsync() 
        => Task.FromResult<IReadOnlyList<TodoItem>>(_items.ToList());

    public Task<TodoItem?> GetByIdAsync(Guid id)
        => Task.FromResult(_items.FirstOrDefault(x => x.Id == id));

    public Task AddAsync(TodoItem item)
    {
        _items.Add(item);
        SaveToFile();
        return Task.CompletedTask;
    }

    public Task UpdateAsync(TodoItem item)
    {
        var existing = _items.FirstOrDefault(x => x.Id == item.Id);
        if (existing != null)
        {
            var index = _items.IndexOf(existing);
            _items[index] = item;
            SaveToFile();
        }
        return Task.CompletedTask;
    }

    public Task DeleteAsync(Guid id)
    {
        _items.RemoveAll(x => x.Id == id);
        SaveToFile();
        return Task.CompletedTask;
    }

    public Task SaveChangesAsync() => Task.CompletedTask; // 이미 자동 저장됨
}
```

> **원자적 저장**: 실제 프로덕션에서는 임시 파일에 쓰고 바꾸는 방식으로 파일 손상을 방지하는 것이 좋습니다. 여기서는 단순화했습니다.

## 3. 뷰모델 계층 (App)

`CommunityToolkit.Mvvm`을 사용하여 코드를 간결하게 유지합니다. 패키지 설치:

```bash
dotnet add TodoApp.App package CommunityToolkit.Mvvm
```

### TodoItemViewModel

단일 항목을 표현합니다. 편집 모드와 상태 변경 명령을 포함합니다.

```csharp
// TodoApp.App/ViewModels/TodoItemViewModel.cs
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using TodoApp.Domain.Models;

public partial class TodoItemViewModel : ObservableObject
{
    private readonly TodoItem _model;

    public TodoItemViewModel(TodoItem model)
    {
        _model = model;
    }

    public Guid Id => _model.Id;

    public string Title
    {
        get => _model.Title;
        set
        {
            if (_model.Title != value)
            {
                _model.Title = value;
                OnPropertyChanged();
                // 필요 시 업데이트 명령 호출
            }
        }
    }

    public bool IsCompleted
    {
        get => _model.IsCompleted;
        set
        {
            if (_model.IsCompleted != value)
            {
                _model.IsCompleted = value;
                OnPropertyChanged();
            }
        }
    }

    public DateTime? DueDate
    {
        get => _model.DueDate;
        set
        {
            if (_model.DueDate != value)
            {
                _model.DueDate = value;
                OnPropertyChanged();
            }
        }
    }

    public TodoItem GetModel() => _model;
}
```

### MainViewModel

전체 목록 관리, 필터, 정렬, 추가/삭제, 실행 취소/다시 실행 기능을 담당합니다.

```csharp
// TodoApp.App/ViewModels/MainViewModel.cs
using CommunityToolkit.Mvvm.ComponentModel;
using CommunityToolkit.Mvvm.Input;
using System.Collections.ObjectModel;
using System.ComponentModel;
using System.Windows.Data;

public partial class MainViewModel : ObservableObject
{
    private readonly ITodoStore _store;
    private List<TodoItemViewModel> _allItems = new();

    public ObservableCollection<TodoItemViewModel> Items { get; } = new();
    public ICollectionView FilteredItems { get; private set; }

    [ObservableProperty]
    private string _newTitle = "";

    [ObservableProperty]
    private string _filterText = "";

    [ObservableProperty]
    private string _selectedFilter = "전체"; // "전체", "미완료", "완료"

    public MainViewModel(ITodoStore store)
    {
        _store = store;
        FilteredItems = CollectionViewSource.GetDefaultView(Items);
        FilteredItems.Filter = FilterPredicate;

        LoadCommand = new AsyncRelayCommand(LoadAsync);
        AddCommand = new AsyncRelayCommand(AddAsync, CanAdd);
        DeleteCommand = new AsyncRelayCommand<TodoItemViewModel>(DeleteAsync);
        ToggleCompleteCommand = new RelayCommand<TodoItemViewModel>(ToggleComplete);
        // 정렬 명령들
        SortByDueDateCommand = new RelayCommand(() => ApplySort("DueDate"));
        SortByTitleCommand = new RelayCommand(() => ApplySort("Title"));
        // 실행 취소/다시 실행은 별도로 구현 (생략)
    }

    public ICommand LoadCommand { get; }
    public ICommand AddCommand { get; }
    public ICommand DeleteCommand { get; }
    public ICommand ToggleCompleteCommand { get; }
    public ICommand SortByDueDateCommand { get; }
    public ICommand SortByTitleCommand { get; }

    private async Task LoadAsync()
    {
        var models = await _store.GetAllAsync();
        _allItems = models.Select(m => new TodoItemViewModel(m)).ToList();
        Items.Clear();
        foreach (var vm in _allItems)
            Items.Add(vm);
        RefreshFilter();
    }

    private bool CanAdd() => !string.IsNullOrWhiteSpace(NewTitle);

    private async Task AddAsync()
    {
        var newModel = new TodoItem
        {
            Id = Guid.NewGuid(),
            Title = NewTitle,
            CreatedAt = DateTime.Now
        };
        var vm = new TodoItemViewModel(newModel);
        _allItems.Add(vm);
        Items.Add(vm);
        await _store.AddAsync(newModel);
        NewTitle = "";
        RefreshFilter();
    }

    private async Task DeleteAsync(TodoItemViewModel? vm)
    {
        if (vm == null) return;
        _allItems.Remove(vm);
        Items.Remove(vm);
        await _store.DeleteAsync(vm.Id);
        RefreshFilter();
    }

    private void ToggleComplete(TodoItemViewModel? vm)
    {
        if (vm == null) return;
        vm.IsCompleted = !vm.IsCompleted;
        // 저장소 업데이트
        _store.UpdateAsync(vm.GetModel()).ConfigureAwait(false);
        RefreshFilter();
    }

    private bool FilterPredicate(object obj)
    {
        if (obj is not TodoItemViewModel vm) return false;

        // 필터 텍스트
        var matchText = string.IsNullOrWhiteSpace(FilterText) ||
                        vm.Title.Contains(FilterText, StringComparison.OrdinalIgnoreCase);

        // 완료 상태 필터
        bool matchStatus = SelectedFilter switch
        {
            "미완료" => !vm.IsCompleted,
            "완료" => vm.IsCompleted,
            _ => true
        };
        return matchText && matchStatus;
    }

    private void ApplySort(string propertyName)
    {
        FilteredItems.SortDescriptions.Clear();
        FilteredItems.SortDescriptions.Add(new SortDescription(propertyName, ListSortDirection.Ascending));
    }

    partial void OnFilterTextChanged(string value) => RefreshFilter();
    partial void OnSelectedFilterChanged(string value) => RefreshFilter();

    private void RefreshFilter() => FilteredItems.Refresh();
}
```

> `AsyncRelayCommand`는 별도로 구현하거나 `CommunityToolkit.Mvvm`의 `AsyncRelayCommand`를 사용합니다. 여기서는 생략.

### 변환기 (BoolToStrike)

완료된 항목에 취소선을 표시합니다.

```csharp
public class BoolToStrikeConverter : IValueConverter
{
    public object Convert(object value, Type targetType, object parameter, CultureInfo culture)
        => (value is bool b && b) ? TextDecorations.Strikethrough : null;

    public object ConvertBack(object value, Type targetType, object parameter, CultureInfo culture)
        => throw new NotSupportedException();
}
```

리소스에 등록합니다.

```xml
<Window.Resources>
    <local:BoolToStrikeConverter x:Key="BoolToStrike"/>
</Window.Resources>
```

## 5. 의존성 주입과 앱 시작

`Microsoft.Extensions.Hosting`을 사용하여 서비스를 등록하고 앱을 시작합니다.

```csharp
// App.xaml.cs
public partial class App : Application
{
    private IHost _host;

    protected override async void OnStartup(StartupEventArgs e)
    {
        _host = Host.CreateDefaultBuilder()
            .ConfigureServices((context, services) =>
            {
                services.AddSingleton<ITodoStore, JsonFileStore>();
                services.AddTransient<MainViewModel>();
                services.AddSingleton<MainWindow>();
            })
            .Build();

        await _host.StartAsync();

        var mainWindow = _host.Services.GetRequiredService<MainWindow>();
        mainWindow.DataContext = _host.Services.GetRequiredService<MainViewModel>();
        mainWindow.Show();
    }

    protected override async void OnExit(ExitEventArgs e)
    {
        using (_host) await _host.StopAsync();
        base.OnExit(e);
    }
}
```

`App.xaml`의 StartupUri를 제거하고 `Startup` 이벤트를 처리하도록 합니다.

## 7. 성능 및 사용성 향상

- **ListView 가상화**: 기본적으로 활성화되어 있지만, `VirtualizingStackPanel.IsVirtualizing="True"`를 명시해도 좋습니다.
- **비동기 명령**: 저장소 호출은 모두 `async`/`await`로 UI 스레드를 차단하지 않습니다.
- **필터/정렬 갱신**: `CollectionView.Refresh()`는 필터 조건이 바뀔 때만 호출합니다.
- **입력 지연**: 검색 필터에 `Delay`를 추가하여 타이핑 중 잦은 갱신을 방지합니다.

```xml
<TextBox Text="{Binding FilterText, Delay=500, UpdateSourceTrigger=PropertyChanged}"/>
```

---

## 확장 가능성

- **실행 취소/다시 실행**: 명령 패턴과 명령 히스토리 도입.
- **알림**: `DueDate`가 지나면 알림 표시.
- **태그**: `TodoItem`에 `List<string> Tags` 추가하고 필터에 반영.
- **테마**: 리소스 사전 교체로 다크 모드 지원.

## 결론

이 가이드에서는 WPF Todo 앱을 MVVM 패턴으로 구현하는 방법을 단계별로 살펴보았습니다. 주요 특징은 다음과 같습니다.

| 계층 | 역할 | 기술 |
|------|------|------|
| Domain | 엔티티, 인터페이스 | 순수 C# |
| Storage | JSON 파일 저장 | System.Text.Json |
| ViewModel | 비즈니스 로직, 상태 | CommunityToolkit.Mvvm |
| View | UI 표시 | XAML, 데이터 바인딩 |

이 구조는 테스트하기 쉽고, 저장소 교체나 기능 확장이 간단합니다. 실무에서도 충분히 활용할 수 있는 견고한 기반을 제공합니다.
