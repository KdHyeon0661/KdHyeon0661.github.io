# WPF 다크모드 테마 적용

WPF 애플리케이션에 다크모드를 구현하는 것은 단순한 색상 변경을 넘어 체계적인 리소스 관리가 필요한 작업입니다. 이 글에서는 초중급 개발자가 실무에서 바로 적용할 수 있는 다크모드 구현 방법을 단계별로 설명합니다.

---

## 다크모드 구현의 핵심 원리

다크모드의 핵심은 **리소스 사전 교체**입니다. 라이트 테마와 다크 테마에서 같은 의미를 가진 리소스 키(예: `Palette.Background`)에 다른 색상 값을 할당해 두고, 테마를 변경할 때 현재 사용 중인 리소스 사전을 통째로 바꾸면 모든 UI가 자동으로 갱신됩니다.

```
[리소스 사전 교체] → [DynamicResource 참조] → [UI 자동 갱신]
```

---

## 프로젝트 구조

간단한 구조로 시작합니다.

```
YourApp/
├── Themes/
│   ├── LightTheme.xaml      # 라이트 테마 색상
│   ├── DarkTheme.xaml       # 다크 테마 색상
│   └── ControlStyles.xaml   # 컨트롤 스타일 (테마 독립적)
├── Services/
│   └── ThemeManager.cs      # 테마 전환 서비스
├── App.xaml
└── MainWindow.xaml
```

## 1. 테마별 색상 리소스 정의

먼저 **의미 기반의 리소스 키**를 정합니다. 실제 색상 값은 테마 파일에서만 다르게 설정합니다.

### LightTheme.xaml
```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <!-- 배경 -->
    <SolidColorBrush x:Key="Palette.Background" Color="#FFFFFF"/>
    <SolidColorBrush x:Key="Palette.Surface" Color="#F9FAFB"/>
    <!-- 텍스트 -->
    <SolidColorBrush x:Key="Palette.Foreground" Color="#111827"/>
    <SolidColorBrush x:Key="Palette.SecondaryText" Color="#6B7280"/>
    <!-- 강조 -->
    <SolidColorBrush x:Key="Palette.Primary" Color="#2563EB"/>
    <SolidColorBrush x:Key="Palette.PrimaryHover" Color="#1D4ED8"/>
    <!-- 경계선 -->
    <SolidColorBrush x:Key="Palette.Border" Color="#E5E7EB"/>
</ResourceDictionary>
```

### DarkTheme.xaml
```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <!-- 배경 (어두운 톤) -->
    <SolidColorBrush x:Key="Palette.Background" Color="#0F172A"/>
    <SolidColorBrush x:Key="Palette.Surface" Color="#1E293B"/>
    <!-- 텍스트 (밝은 톤) -->
    <SolidColorBrush x:Key="Palette.Foreground" Color="#F1F5F9"/>
    <SolidColorBrush x:Key="Palette.SecondaryText" Color="#94A3B8"/>
    <!-- 강조 (약간 밝게) -->
    <SolidColorBrush x:Key="Palette.Primary" Color="#3B82F6"/>
    <SolidColorBrush x:Key="Palette.PrimaryHover" Color="#2563EB"/>
    <!-- 경계선 -->
    <SolidColorBrush x:Key="Palette.Border" Color="#475569"/>
</ResourceDictionary>
```

**주의**: 두 파일에서 리소스 키는 완전히 동일해야 합니다. 값만 다릅니다.

## 2. 컨트롤 스타일에서 DynamicResource 사용

테마 전환 시 UI가 즉시 반응하려면 스타일에서 `DynamicResource`를 사용해야 합니다.

### ControlStyles.xaml
```xml
<ResourceDictionary xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
                    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml">
    <Style TargetType="Window">
        <Setter Property="Background" Value="{DynamicResource Palette.Background}"/>
        <Setter Property="Foreground" Value="{DynamicResource Palette.Foreground}"/>
    </Style>

    <Style TargetType="Button" x:Key="PrimaryButton">
        <Setter Property="Background" Value="{DynamicResource Palette.Primary}"/>
        <Setter Property="Foreground" Value="{DynamicResource Palette.Background}"/>
        <Setter Property="BorderThickness" Value="0"/>
        <Setter Property="Padding" Value="12,8"/>
        <Setter Property="Cursor" Value="Hand"/>
        <Style.Triggers>
            <Trigger Property="IsMouseOver" Value="True">
                <Setter Property="Background" Value="{DynamicResource Palette.PrimaryHover}"/>
            </Trigger>
        </Style.Triggers>
    </Style>

    <Style TargetType="TextBox">
        <Setter Property="Background" Value="{DynamicResource Palette.Surface}"/>
        <Setter Property="Foreground" Value="{DynamicResource Palette.Foreground}"/>
        <Setter Property="BorderBrush" Value="{DynamicResource Palette.Border}"/>
        <Setter Property="BorderThickness" Value="1"/>
        <Setter Property="Padding" Value="8,6"/>
        <Style.Triggers>
            <Trigger Property="IsKeyboardFocused" Value="True">
                <Setter Property="BorderBrush" Value="{DynamicResource Palette.Primary}"/>
                <Setter Property="BorderThickness" Value="2"/>
            </Trigger>
        </Style.Triggers>
    </Style>
</ResourceDictionary>
```

## 3. 애플리케이션 리소스 구성

App.xaml에서 기본 리소스 사전을 로드합니다.

```xml
<Application x:Class="YourApp.App"
             xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             StartupUri="MainWindow.xaml">
    <Application.Resources>
        <ResourceDictionary>
            <ResourceDictionary.MergedDictionaries>
                <!-- 기본 테마 (라이트) -->
                <ResourceDictionary Source="Themes/LightTheme.xaml"/>
                <!-- 공통 스타일 -->
                <ResourceDictionary Source="Themes/ControlStyles.xaml"/>
            </ResourceDictionary.MergedDictionaries>
        </ResourceDictionary>
    </Application.Resources>
</Application>
```

## 4. 테마 관리 서비스 구현

테마 전환 기능을 제공하는 간단한 서비스를 만듭니다.

```csharp
using System;
using System.Linq;
using System.Windows;

public static class ThemeManager
{
    public enum AppTheme { Light, Dark }

    private static AppTheme _currentTheme = AppTheme.Light;
    public static AppTheme CurrentTheme => _currentTheme;

    public static void ApplyTheme(AppTheme theme)
    {
        var app = Application.Current;
        if (app == null) return;

        // 현재 로드된 테마 리소스 사전을 찾기
        var themeDict = app.Resources.MergedDictionaries
            .FirstOrDefault(d => d.Source?.OriginalString?.Contains("Theme") == true);

        // 새 테마 사전 생성
        var newThemeUri = theme == AppTheme.Dark
            ? new Uri("Themes/DarkTheme.xaml", UriKind.Relative)
            : new Uri("Themes/LightTheme.xaml", UriKind.Relative);
        var newThemeDict = new ResourceDictionary { Source = newThemeUri };

        // 교체
        if (themeDict != null)
        {
            int index = app.Resources.MergedDictionaries.IndexOf(themeDict);
            app.Resources.MergedDictionaries[index] = newThemeDict;
        }
        else
        {
            app.Resources.MergedDictionaries.Insert(0, newThemeDict);
        }

        _currentTheme = theme;
        SaveUserPreference(theme);
    }

    public static void Initialize()
    {
        // 저장된 사용자 설정 불러오기
        var saved = LoadUserPreference();
        ApplyTheme(saved);
    }

    private static AppTheme LoadUserPreference()
    {
        // Properties.Settings 또는 파일에서 읽기
        return AppTheme.Light;
    }

    private static void SaveUserPreference(AppTheme theme) { }
}
```

## 5. 메인 윈도우에 테마 전환 버튼 추가

간단한 토글 버튼으로 테마를 전환합니다.

```xml
<Window x:Class="YourApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="다크모드 데모" Height="450" Width="800">
    <Grid>
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
        </Grid.RowDefinitions>

        <StackPanel Grid.Row="0" Orientation="Horizontal" HorizontalAlignment="Right" Margin="12">
            <ToggleButton x:Name="ThemeToggle" Content="다크 모드" 
                          Checked="ThemeToggle_Checked" Unchecked="ThemeToggle_Unchecked"/>
        </StackPanel>

        <Border Grid.Row="1" Margin="20" CornerRadius="8"
                Background="{DynamicResource Palette.Surface}"
                BorderBrush="{DynamicResource Palette.Border}"
                BorderThickness="1">
            <StackPanel Margin="16">
                <TextBlock Text="Hello, Dark Mode!" FontSize="20"
                           Foreground="{DynamicResource Palette.Foreground}"/>
                <Button Content="클릭" Style="{StaticResource PrimaryButton}" Margin="0,12,0,0"/>
                <TextBox Text="입력 필드" Margin="0,12,0,0"/>
            </StackPanel>
        </Border>
    </Grid>
</Window>
```

```csharp
public partial class MainWindow : Window
{
    public MainWindow()
    {
        InitializeComponent();
        ThemeToggle.IsChecked = (ThemeManager.CurrentTheme == ThemeManager.AppTheme.Dark);
    }

    private void ThemeToggle_Checked(object sender, RoutedEventArgs e)
        => ThemeManager.ApplyTheme(ThemeManager.AppTheme.Dark);

    private void ThemeToggle_Unchecked(object sender, RoutedEventArgs e)
        => ThemeManager.ApplyTheme(ThemeManager.AppTheme.Light);
}
```

## 6. OS 테마 동기화 (선택 사항)

사용자 설정에 따라 Windows 시스템 테마를 따라가도록 할 수 있습니다. Windows 테마는 레지스트리에서 확인합니다.

```csharp
public static class SystemThemeWatcher
{
    public static bool IsDarkThemeEnabled()
    {
        const string keyPath = @"Software\Microsoft\Windows\CurrentVersion\Themes\Personalize";
        const string valueName = "AppsUseLightTheme";
        try
        {
            using var key = Microsoft.Win32.Registry.CurrentUser.OpenSubKey(keyPath);
            var value = key?.GetValue(valueName, 1);
            return value is int intValue && intValue == 0;
        }
        catch
        {
            return false;
        }
    }
}
```

그리고 ThemeManager에 "OS 테마 따라가기" 옵션을 추가합니다.

## 7. 성능과 주의사항

| 항목 | 권장 사항 |
|------|-----------|
| **리소스 키** | 의미 기반으로 정의 (예: `Palette.Background`) |
| **바인딩 방식** | 테마 변경이 필요한 부분은 `DynamicResource` 사용 |
| **리소스 사전** | 테마 사전과 스타일 사전 분리 (스타일은 변경하지 않음) |
| **초기 로드** | 앱 시작 시 저장된 테마 또는 OS 테마 적용 |
| **메모리** | 리소스 사전 교체 시 이전 사전은 GC 수거됨 |

---

## 결론

WPF 다크모드 구현은 다음과 같은 핵심 단계로 요약됩니다:

1. **의미 기반 리소스 키**를 정의하고 테마별로 다른 색상 값을 할당한다.
2. **컨트롤 스타일**에서 `DynamicResource`를 사용하여 리소스를 참조한다.
3. **리소스 사전 교체** 방식으로 테마를 전환한다.
4. **사용자 설정을 저장**하고, 원한다면 **OS 테마 변경을 감지**하여 자동 전환한다.

이 구조는 코드 변경 없이 새로운 테마를 쉽게 추가할 수 있으며, 유지보수성이 뛰어납니다. 처음에는 라이트/다크 두 가지 테마로 시작해도 충분하며, 필요에 따라 고대비 테마 등으로 확장할 수 있습니다.
