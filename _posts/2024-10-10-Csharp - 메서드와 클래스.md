# C# 메서드와 클래스: 객체 지향의 기본

C#은 철저한 객체 지향 프로그래밍(OOP) 언어입니다. 프로그램의 모든 요소는 객체(Object)라는 단위로 구성되며, 이 객체를 생성하기 위한 설계도가 바로 클래스(Class)입니다. 클래스는 데이터(상태)를 저장하는 필드와 프로퍼티, 그리고 그 데이터를 조작하고 행동을 정의하는 메서드(Method)로 이루어집니다.

이 글에서는 초중급 개발자를 기준으로 클래스와 메서드의 기본 개념부터, 객체 지향의 핵심 원칙, 그리고 실무에서 자주 사용되는 현대적 기능까지 체계적으로 정리합니다.

---

## 클래스: 데이터와 행동의 설계도

클래스는 특정 종류의 객체가 가져야 할 데이터와 행동을 하나의 단위로 묶는 템플릿입니다. 클래스 자체는 메모리에 실체가 없는 개념이며, `new` 키워드를 통해 인스턴스(객체)를 생성해야 실제로 사용할 수 있습니다.

```csharp
public class Car
{
    // 필드: 객체의 데이터를 저장
    public string Model;
    public int Year;
}

// 인스턴스 생성
Car myCar = new Car();
myCar.Model = "Tesla Model 3";
myCar.Year = 2023;
```

### 필드 대신 프로퍼티를 사용하는 이유

클래스의 필드를 `public`으로 직접 노출하면 외부에서 데이터를 마음대로 조작할 수 있어 객체 지향의 핵심 원칙인 **캡슐화(Encapsulation)** 에 위배됩니다. 실무에서는 데이터를 보호하면서도 유연하게 접근할 수 있도록 **프로퍼티(Property)** 를 사용합니다. 프로퍼티는 내부적으로 getter/setter 메서드로 동작하여 유효성 검사나 추가 로직을 삽입할 수 있습니다.

```csharp
public class Car
{
    // 자동 구현 프로퍼티: 컴파일러가 숨겨진 필드를 자동 생성
    public string Model { get; set; } = string.Empty;
    
    // Init-only 프로퍼티: 생성 시에만 값을 할당할 수 있음 (불변성)
    public int Year { get; init; }
    
    // 계산된 프로퍼티: 저장 없이 호출 시점에 값을 계산
    public string Description => $"{Model} ({Year})";
}

var myCar = new Car { Model = "Hyundai Ioniq 5", Year = 2024 };
// myCar.Year = 2025; // 컴파일 오류: init 프로퍼티는 변경 불가
```

## 메서드: 객체의 행동

메서드는 객체가 수행할 수 있는 구체적인 작업을 정의합니다. 데이터를 입력받아 가공하고, 상태를 변경하거나 결과를 반환합니다.

### 메서드의 구조와 다양한 표현

```csharp
public class Calculator
{
    // 일반 인스턴스 메서드
    public int Add(int a, int b)
    {
        return a + b;
    }
    
    // 정적 메서드: 클래스 이름으로 직접 호출 (객체 불필요)
    public static int Multiply(int a, int b)
    {
        return a * b;
    }
    
    // 식 본문 메서드: 한 줄짜리 메서드를 간결하게 표현
    public double Square(double x) => x * x;
}
```

### 매개변수 전달 기법

C#은 매개변수 전달 방식을 세밀하게 제어할 수 있는 한정자를 제공합니다.

```csharp
public class ParameterDemo
{
    // 선택적 매개변수: 기본값 지정 가능
    public void Greet(string name = "Guest")
    {
        Console.WriteLine($"Hello, {name}!");
    }
    
    // params: 가변 개수 인수
    public int Sum(params int[] numbers)
    {
        int total = 0;
        foreach (int n in numbers) total += n;
        return total;
    }
    
    // out: 메서드 내에서 반드시 값을 할당해야 하는 출력 전용 매개변수
    public bool TryParseToInt(string input, out int result)
    {
        return int.TryParse(input, out result);
    }
    
    // in: 읽기 전용 참조 전달 (큰 구조체의 복사 비용 절감)
    public double Distance(in Point p1, in Point p2)
    {
        double dx = p2.X - p1.X;
        double dy = p2.Y - p1.Y;
        return Math.Sqrt(dx * dx + dy * dy);
    }
}
```

### 로컬 함수

메서드 내부에서만 사용되는 반복 로직이 있다면, 로컬 함수로 정의하여 가독성을 높일 수 있습니다.

```csharp
public double CalculateHypotenuse(double a, double b)
{
    double Square(double x) => x * x;
    return Math.Sqrt(Square(a) + Square(b));
}
```

## 생성자: 객체의 초기화

생성자는 클래스와 같은 이름을 가지며, 객체가 생성될 때 자동으로 호출되는 특수 메서드입니다. 객체가 유효한 상태로 시작할 수 있도록 초기 설정을 담당합니다.

```csharp
public class Person
{
    public string Name { get; }
    public int Age { get; }
    
    // 기본 생성자
    public Person()
    {
        Name = "Unknown";
        Age = 0;
    }
    
    // 매개변수 생성자 (필수 값 강제)
    public Person(string name, int age)
    {
        if (string.IsNullOrWhiteSpace(name))
            throw new ArgumentException("이름은 필수입니다.");
        Name = name;
        Age = age;
    }
    
    // 생성자 체이닝: this로 다른 생성자 호출 (코드 중복 제거)
    public Person(string name, int age, string email) : this(name, age)
    {
        Console.WriteLine($"이메일 설정: {email}");
    }
}
```

정적 필드만 초기화해야 하는 경우에는 **정적 생성자**를 사용할 수 있습니다. 정적 생성자는 클래스가 처음 사용되기 직전에 한 번만 호출됩니다.

## 접근 제한자: 정보 은닉

객체 지향에서는 내부 구현을 숨기고 필요한 것만 외부에 공개하는 것이 원칙입니다. 접근 제한자를 통해 이를 제어합니다.

- **public**: 모든 곳에서 접근 가능
- **private**: 해당 클래스 내부에서만 접근 가능
- **protected**: 해당 클래스와 파생 클래스에서 접근 가능
- **internal**: 같은 어셈블리(프로젝트) 내에서만 접근 가능

실무에서는 기본적으로 `private`으로 시작하여 점진적으로 필요한 범위만 개방하는 것이 안전합니다.

## 상속과 다형성

상속은 기존 클래스의 기능을 물려받아 새로운 클래스를 확장하는 방법입니다. 다형성(Polymorphism)은 동일한 타입의 참조 변수로 다양한 객체를 다룰 수 있게 합니다.

```text
[상속과 인터페이스 구조]

   << interface >>
     IDrawable
         │
         ▼
  abstract class Shape
         │
    ┌────┴────┐
    ▼         ▼
  Circle    Square
```

```csharp
// 추상 클래스: 인스턴스화 불가, 자식에게 구현 강제
public abstract class Shape
{
    public abstract double CalculateArea();
}

// 인터페이스: 행동 계약
public interface IDrawable
{
    void Draw();
}

// 상속과 인터페이스 구현
public class Square : Shape, IDrawable
{
    public double Side { get; set; }
    
    public override double CalculateArea() => Side * Side;
    
    public void Draw() => Console.WriteLine($"한 변이 {Side}인 정사각형");
}

// 다형성 활용
Shape shape = new Square { Side = 5 };
Console.WriteLine(shape.CalculateArea()); // Square의 메서드가 호출됨
```

`virtual`과 `override` 키워드를 사용하면 부모 클래스의 메서드를 자식 클래스에서 재정의할 수 있습니다. 추상 클래스와 인터페이스는 다형성을 구현하는 핵심 도구입니다.

## 제네릭: 타입 안전성과 성능

제네릭(Generic)을 사용하면 클래스나 메서드를 다양한 타입에 대해 재사용할 수 있습니다. 구체적인 타입은 사용 시점에 결정됩니다. 제네릭은 박싱(Boxing)을 방지하여 성능을 높이고, 타입 캐스팅 오류를 컴파일 타임에 잡아줍니다.

```csharp
// 제네릭 클래스
public class Box<T>
{
    public T Content { get; set; }
    public Box(T content) => Content = content;
}

// 제네릭 메서드 (where로 타입 제약)
public class Utility
{
    public static T Max<T>(T a, T b) where T : IComparable<T>
    {
        return a.CompareTo(b) > 0 ? a : b;
    }
}

// 사용
var intBox = new Box<int>(42);
string larger = Utility.Max("apple", "banana");
```

`List<T>`는 제네릭 컬렉션의 대표적인 예로, `ArrayList`(비제네릭)를 사용할 때 발생하던 박싱 문제를 해결했습니다.

## 확장 메서드

확장 메서드는 기존 타입에 새로운 메서드를 추가하는 방법입니다. 원본 코드를 수정할 수 없는 라이브러리 클래스에도 쉽게 기능을 덧붙일 수 있습니다.

```csharp
public static class StringExtensions
{
    public static string Repeat(this string str, int count)
    {
        return string.Concat(Enumerable.Repeat(str, count));
    }
}

string text = "Hello";
Console.WriteLine(text.Repeat(3)); // HelloHelloHello
```

## 비동기 메서드: async / await

파일 읽기, 네트워크 호출 등 I/O 작업이 오래 걸리는 경우, `async`와 `await`를 사용해 메인 스레드의 블로킹을 방지합니다. 비동기 메서드는 `Task` 또는 `Task<T>`를 반환합니다.

```csharp
public class DataService
{
    public async Task<string> FetchDataAsync(string url)
    {
        using var client = new HttpClient();
        string content = await client.GetStringAsync(url);
        return content;
    }
}
```

`await`를 만나면 메서드는 일시 중단되고 제어권을 호출자에게 반환합니다. 작업이 완료되면 이후 코드가 재개됩니다.

## 자원 관리: IDisposable과 using

가비지 컬렉터(GC)는 메모리를 자동으로 회수하지만, 파일 핸들이나 데이터베이스 연결 등 관리되지 않는 리소스는 개발자가 직접 해제해야 합니다. `IDisposable` 인터페이스를 구현하고 `using` 구문을 사용하면 간편하게 처리할 수 있습니다.

```csharp
public class FileLogger : IDisposable
{
    private StreamWriter _writer;
    
    public FileLogger(string path)
    {
        _writer = new StreamWriter(path, append: true);
    }
    
    public void Log(string message) => _writer.WriteLine(message);
    
    public void Dispose()
    {
        _writer?.Dispose();
    }
}

// using 구문: 블록 종료 시 Dispose 자동 호출
using (var logger = new FileLogger("log.txt"))
{
    logger.Log("안전하게 기록됨");
}
```

C# 8.0부터는 중괄호 없이 선언만으로도 블록 끝에서 자동 해제되는 `using` 선언을 사용할 수 있습니다.

## 실무 응용: 간단한 작업 관리 예제

지금까지 배운 개념들을 하나로 합쳐 간단한 할 일 관리 프로그램을 만들어 봅니다.

```csharp
// 엔티티 클래스
public class TaskItem
{
    public int Id { get; }
    public string Title { get; private set; }
    public bool IsCompleted { get; private set; }
    
    public TaskItem(int id, string title)
    {
        Id = id;
        Title = title;
        IsCompleted = false;
    }
    
    public void MarkComplete() => IsCompleted = true;
    public override string ToString() => $"[{(IsCompleted ? "V" : " ")}] {Title}";
}

// 리포지토리 인터페이스 (저장소 규격)
public interface ITaskRepository
{
    Task<IEnumerable<TaskItem>> GetAllAsync();
    Task AddAsync(TaskItem task);
}

// 메모리 기반 리포지토리 구현
public class InMemoryTaskRepository : ITaskRepository
{
    private readonly Dictionary<int, TaskItem> _tasks = new();
    private int _nextId = 1;
    
    public Task<IEnumerable<TaskItem>> GetAllAsync() =>
        Task.FromResult<IEnumerable<TaskItem>>(_tasks.Values);
    
    public Task AddAsync(TaskItem task)
    {
        var newTask = new TaskItem(_nextId++, task.Title);
        if (task.IsCompleted) newTask.MarkComplete();
        _tasks[newTask.Id] = newTask;
        return Task.CompletedTask;
    }
}

// 확장 메서드
public static class TaskExtensions
{
    public static bool IsOverdue(this TaskItem task, int days) =>
        !task.IsCompleted && (DateTime.UtcNow - task.CreatedAt).TotalDays > days;
}

// 실행
class Program
{
    static async Task Main()
    {
        ITaskRepository repo = new InMemoryTaskRepository();
        await repo.AddAsync(new TaskItem(0, "C# 객체 지향 학습"));
        await repo.AddAsync(new TaskItem(0, "디자인 패턴 복습"));
        
        var tasks = await repo.GetAllAsync();
        foreach (var t in tasks)
            Console.WriteLine(t);
    }
}
```

## 마무리

C#의 클래스와 메서드는 단순한 문법 요소를 넘어, 복잡한 비즈니스 로직을 체계적으로 구조화하고 데이터 무결성을 보호하는 핵심 도구입니다. 초중급 개발자로서 다음 내용을 익히면 좋습니다.

- 필드 대신 프로퍼티를 사용하여 캡슐화를 지킵니다.
- 생성자를 통해 객체의 유효한 상태를 보장합니다.
- 접근 제한자로 정보를 적절히 숨깁니다.
- 상속과 인터페이스로 다형성을 활용합니다.
- 제네릭으로 타입 안전성과 성능을 높입니다.
- 비동기 메서드로 I/O 작업을 효율적으로 처리합니다.
- `IDisposable`과 `using`으로 리소스 누수를 방지합니다.

객체 지향 설계 원칙을 코드에 자연스럽게 녹여내는 연습을 꾸준히 하면, 유지보수하기 쉽고 견고한 애플리케이션을 만들 수 있습니다.
