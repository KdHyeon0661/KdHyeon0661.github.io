# Avalonia 다국어 지원 및 리소스 로딩 구조

Avalonia 애플리케이션에서 다국어(i18n)를 지원하려면 문자열 리소스를 문화권별로 분리하고, 런타임에 언어를 전환할 수 있어야 합니다. 이 글에서는 **표준 .resx 기반**의 다국어 시스템 구축부터 **실시간 언어 전환**, **문화권별 날짜/숫자 포맷**, **JSON 동적 리소스**(선택), **DI와 테스트 가능한 설계**까지 초중급 개발자 기준으로 단계별로 설명합니다.

---

## 프로젝트 구조

```
MyApp/
├── Resources/
│   ├── Strings.resx          # 기본(한국어) 리소스

│   └── Strings.ja.resx       # 일본어 리소스 (선택)

├── Views/
```

## .resx 리소스 파일 작성

Visual Studio에서 `Resources` 폴더에 `.resx` 파일을 추가합니다.

**Strings.resx (기본: 한국어)**

| Name         | Value                 |
|--------------|-----------------------|
| App_Title    | Avalonia 예제          |
| Greeting     | 안녕하세요              |
| ItemsCount   | 항목 수: {0}개         |

**Strings.en.resx (영어)**

| Name         | Value                 |
|--------------|-----------------------|
| App_Title    | Avalonia Sample       |
| Greeting     | Hello                 |
| ItemsCount   | Items: {0}            |

> 리소스 키는 중복되지 않게 관리합니다. `{0}` 같은 형식 항목은 `string.Format`에서 사용됩니다.

빌드 시 위성 어셈블리가 생성됩니다. 출력 폴더 구조는 다음과 같습니다.

```
bin/Debug/net8.0/
├── MyApp.exe
├── en/
│   └── MyApp.resources.dll
└── ko/
    └── MyApp.resources.dll
```

## 로컬라이저 인터페이스와 구현

### ILocalizer 인터페이스

```csharp
// I18n/ILocalizer.cs
using System.Globalization;

namespace MyApp.I18n;

public interface ILocalizer
{
    CultureInfo CurrentCulture { get; }
    string this[string key] { get; }
    string Format(string key, params object[] args);
}
```

### ResxLocalizer 구현

```csharp
// I18n/ResxLocalizer.cs
using System.Globalization;
using System.Resources;

namespace MyApp.I18n;

public sealed class ResxLocalizer : ILocalizer
{
    private readonly ResourceManager _resourceManager;
    private CultureInfo _culture;

    public ResxLocalizer(string baseName, Type anchorType, CultureInfo initialCulture)
    {
        _resourceManager = new ResourceManager(baseName, anchorType.Assembly);
        _culture = initialCulture;
    }

    public CultureInfo CurrentCulture => _culture;

    public void SetCulture(CultureInfo culture) => _culture = culture;

    public string this[string key]
        => _resourceManager.GetString(key, _culture) ?? $"!!{key}!!";

    public string Format(string key, params object[] args)
    {
        var format = this[key];
        return string.Format(_culture, format, args);
    }
}
```

`baseName`은 `"MyApp.Resources.Strings"` 형태로, `anchorType`은 리소스가 포함된 어셈블리의 아무 타입(예: `typeof(App)`)을 전달합니다.

## 언어 전환 관리자

언어가 바뀔 때 뷰모델과 뷰에 알리기 위해 이벤트를 제공하는 허브를 만듭니다.

```csharp
// I18n/LocalizationManager.cs
using System.Globalization;

namespace MyApp.I18n;

public sealed class LocalizationManager
{
    public event EventHandler? LanguageChanged;

    public ILocalizer Localizer { get; }

    public LocalizationManager(ILocalizer localizer) => Localizer = localizer;

    public CultureInfo CurrentCulture => Localizer.CurrentCulture;

    public void SetCulture(CultureInfo culture)
    {
        if (Equals(culture, CurrentCulture)) return;

        if (Localizer is ResxLocalizer resxLocalizer)
            resxLocalizer.SetCulture(culture);

        // 현재 스레드의 문화권도 변경 (날짜/숫자 포맷에 영향)
        Thread.CurrentThread.CurrentCulture = culture;
        Thread.CurrentThread.CurrentUICulture = culture;

        LanguageChanged?.Invoke(this, EventArgs.Empty);
    }
}
```

## App 초기화 및 DI 등록

```csharp
// App.axaml.cs
using Microsoft.Extensions.DependencyInjection;
using MyApp.I18n;
using MyApp.Services;
using System.Globalization;

public partial class App : Application
{
    public static ServiceProvider Services { get; private set; } = default!;

    public override void Initialize() => AvaloniaXamlLoader.Load(this);

    public override void OnFrameworkInitializationCompleted()
    {
        var services = new ServiceCollection();

        // 사용자 설정에서 언어 복원 (초기값은 "ko-KR")
        var initialCulture = LoadSavedCultureOrDefault("ko-KR");

        // 로컬라이저 및 관리자 등록
        var localizer = new ResxLocalizer("MyApp.Resources.Strings", typeof(App), initialCulture);
        var localizationManager = new LocalizationManager(localizer);
        services.AddSingleton<ILocalizer>(localizer);
        services.AddSingleton(localizationManager);

        // 서비스 등록
        services.AddSingleton<SettingsService>();

        // 뷰모델 등록
        services.AddTransient<MainViewModel>();
        services.AddTransient<SettingsViewModel>();

        Services = services.BuildServiceProvider();

        if (ApplicationLifetime is IClassicDesktopStyleApplicationLifetime desktop)
        {
            var mainWindow = new MainWindow
            {
                DataContext = Services.GetRequiredService<MainViewModel>()
            };
            desktop.MainWindow = mainWindow;
        }

        base.OnFrameworkInitializationCompleted();
    }

    private CultureInfo LoadSavedCultureOrDefault(string fallback)
    {
        // SettingsService를 직접 생성하여 언어 설정 읽기 (DI 이전)
        var tempService = new SettingsService();
        var cultureName = tempService.LoadLanguageOrDefault(fallback);
        return new CultureInfo(cultureName);
    }
}
```

## ViewModel에서 사용 – 실시간 갱신

뷰모델은 `LocalizationManager`를 주입받고, `LanguageChanged` 이벤트를 구독하여 바인딩 속성을 갱신합니다.

```csharp
// ViewModels/MainViewModel.cs
using MyApp.I18n;
using ReactiveUI;

public class MainViewModel : ReactiveObject
{
    private readonly LocalizationManager _localizationManager;
    private int _count = 5;

    public MainViewModel(LocalizationManager localizationManager)
    {
        _localizationManager = localizationManager;
        _localizationManager.LanguageChanged += (_, _) =>
        {
            this.RaisePropertyChanged(nameof(AppTitle));
            this.RaisePropertyChanged(nameof(Greeting));
            this.RaisePropertyChanged(nameof(Summary));
        };
    }

    public string AppTitle => _localizationManager.Localizer["App_Title"];
    public string Greeting => _localizationManager.Localizer["Greeting"];

    public int Count
    {
        get => _count;
        set
        {
            this.RaiseAndSetIfChanged(ref _count, value);
            this.RaisePropertyChanged(nameof(Summary));
        }
    }

    public string Summary => _localizationManager.Localizer.Format("ItemsCount", Count);
}
```

### 뷰 (XAML)

```xml
<!-- Views/MainView.axaml -->
<UserControl xmlns="https://github.com/avaloniaui"
```

## 언어 전환 UI와 설정 저장

사용자가 언어를 선택하면 `LocalizationManager.SetCulture()`를 호출하고, 선택한 언어를 저장합니다.

```csharp
// ViewModels/SettingsViewModel.cs
using MyApp.I18n;
using MyApp.Services;
using ReactiveUI;
using System.Globalization;
using System.Reactive;

public class SettingsViewModel : ReactiveObject
{
    private readonly LocalizationManager _localizationManager;
    private readonly SettingsService _settingsService;

    public SettingsViewModel(LocalizationManager localizationManager, SettingsService settingsService)
    {
        _localizationManager = localizationManager;
        _settingsService = settingsService;

        SwitchToKorean = ReactiveCommand.Create(() => SwitchCulture("ko-KR"));
        SwitchToEnglish = ReactiveCommand.Create(() => SwitchCulture("en-US"));
        SwitchToJapanese = ReactiveCommand.Create(() => SwitchCulture("ja-JP"));
    }

    public ReactiveCommand<Unit, Unit> SwitchToKorean { get; }
    public ReactiveCommand<Unit, Unit> SwitchToEnglish { get; }
    public ReactiveCommand<Unit, Unit> SwitchToJapanese { get; }

    private void SwitchCulture(string cultureName)
    {
        var culture = new CultureInfo(cultureName);
        _localizationManager.SetCulture(culture);
        _settingsService.SaveLanguage(cultureName);
    }
}
```

```xml
<!-- Views/SettingsView.axaml -->
<StackPanel Margin="20" Spacing="8">
  <Button Content="한국어" Command="{Binding SwitchToKorean}"/>
  <Button Content="English" Command="{Binding SwitchToEnglish}"/>
  <Button Content="日本語" Command="{Binding SwitchToJapanese}"/>
</StackPanel>
```

### SettingsService (JSON 파일 저장)

```csharp
// Services/SettingsService.cs
using System.Text.Json;

public sealed class SettingsService
{
    private const string FilePath = "settings.json";

    public void SaveLanguage(string culture)
    {
        var data = new { Language = culture };
        var json = JsonSerializer.Serialize(data, new JsonSerializerOptions { WriteIndented = true });
        File.WriteAllText(FilePath, json);
    }

    public string LoadLanguageOrDefault(string fallback)
    {
        if (!File.Exists(FilePath)) return fallback;
        try
        {
            var json = File.ReadAllText(FilePath);
            var doc = JsonDocument.Parse(json);
            if (doc.RootElement.TryGetProperty("Language", out var langProp))
                return langProp.GetString() ?? fallback;
        }
        catch { }
        return fallback;
    }
}
```

## 문화권 포맷 도우미 (날짜, 숫자, 통화)

```csharp
// I18n/CultureFormatters.cs
using System.Globalization;

namespace MyApp.I18n;

public static class CultureFormatters
{
    public static string Date(DateTime date, CultureInfo culture, string? format = null)
        => format == null ? date.ToString(culture) : date.ToString(format, culture);

    public static string Number(double value, CultureInfo culture, string? format = "N")
        => value.ToString(format, culture);

    public static string Currency(decimal value, CultureInfo culture, string? format = "C")
        => value.ToString(format, culture);
}
```

뷰모델에서 사용:

```csharp
public string Today => CultureFormatters.Date(DateTime.Today, _localizationManager.CurrentCulture, "D");
public string Price => CultureFormatters.Currency(12345.67m, _localizationManager.CurrentCulture);
```

## 복수형 처리

영어 등 복수형 규칙이 필요한 언어는 키를 분기하여 처리합니다.

```
Strings.en.resx
- Items_Zero = No items
- Items_One  = 1 item
- Items_Many = {0} items
```

```csharp
public string ItemsText(int count)
{
    var loc = _localizationManager.Localizer;
    return count switch
    {
        0 => loc["Items_Zero"],
        1 => loc["Items_One"],
        _ => loc.Format("Items_Many", count)
    };
}
```

## JSON 동적 리소스 (선택)

실시간으로 번역을 갱신해야 한다면 JSON 파일 기반 로컬라이저를 사용할 수 있습니다.

### JSON 파일 예 (ko.json)

```json
{
  "App_Title": "Avalonia 예제",
  "Greeting": "안녕하세요",
  "ItemsCount": "항목 수: {0}개"
}
```

### JsonLocalizer 구현 (핵심)

```csharp
// I18n/JsonLocalizer.cs
using System.Collections.Concurrent;
using System.Text.Json;

public sealed class JsonLocalizer : ILocalizer, IDisposable
{
    private readonly string _basePath;
    private CultureInfo _culture;
    private ConcurrentDictionary<string, string> _dictionary = new();
    private FileSystemWatcher? _watcher;

    public JsonLocalizer(string basePath, CultureInfo initialCulture, bool watch = true)
    {
        _basePath = basePath;
        _culture = initialCulture;
        Load();
        if (watch) StartWatcher();
    }

    public CultureInfo CurrentCulture => _culture;

    public void SetCulture(CultureInfo culture)
    {
        _culture = culture;
        Load();
    }

    public string this[string key] => _dictionary.TryGetValue(key, out var value) ? value : $"!!{key}!!";

    public string Format(string key, params object[] args)
        => string.Format(_culture, this[key], args);

    private void Load()
    {
        var fileName = $"{_culture.TwoLetterISOLanguageName}.json";
        var path = Path.Combine(_basePath, fileName);
        if (!File.Exists(path))
            path = Path.Combine(_basePath, "en.json");

        var json = File.ReadAllText(path);
        var map = JsonSerializer.Deserialize<Dictionary<string, string>>(json) ?? new();
        _dictionary = new ConcurrentDictionary<string, string>(map);
    }

    private void StartWatcher()
    {
        _watcher = new FileSystemWatcher(_basePath, "*.json")
        {
            NotifyFilter = NotifyFilters.LastWrite | NotifyFilters.FileName
        };
        _watcher.Changed += (_, _) => Load();
        _watcher.Created += (_, _) => Load();
        _watcher.EnableRaisingEvents = true;
    }

    public void Dispose() => _watcher?.Dispose();
}
```

> 프로덕션 환경에서는 파일 감시에 따른 성능 이슈를 고려해 배치 갱신 방식으로 대체할 수 있습니다.

## XAML 마크업 확장 (선택)

정적 문자열에 간편하게 키를 지정하려면 `MarkupExtension`을 사용할 수 있습니다. 실시간 전환은 지원되지 않으므로, 동적 갱신이 필요한 문자열은 ViewModel을 경유하는 것이 좋습니다.

```csharp
// I18n/LocExtension.cs
using Avalonia.Markup.Xaml;

public class LocExtension : MarkupExtension
{
    public string Key { get; set; }

    public LocExtension(string key) => Key = key;

    public override object ProvideValue(IServiceProvider serviceProvider)
    {
        var manager = App.Services.GetService<LocalizationManager>();
        return manager?.Localizer[Key] ?? $"!!{Key}!!";
    }
}
```

XAML 사용:

```xml
<TextBlock Text="{i18n:Loc App_Title}"/>
```

## 단위 테스트

```csharp
[Fact]
public void ResxLocalizer_Returns_Fallback_For_Missing_Key()
{
    var localizer = new ResxLocalizer("MyApp.Resources.Strings", typeof(App), new CultureInfo("en-US"));
    var result = localizer["MissingKey"];
    Assert.Equal("!!MissingKey!!", result);
}

[Fact]
public void ViewModel_Updates_On_Language_Change()
{
    var localizer = new ResxLocalizer("MyApp.Resources.Strings", typeof(App), new CultureInfo("ko-KR"));
    var manager = new LocalizationManager(localizer);
    var vm = new MainViewModel(manager);

    var initial = vm.AppTitle;
    manager.SetCulture(new CultureInfo("en-US"));
    Assert.NotEqual(initial, vm.AppTitle);
}
```

## 배포 시 주의사항

- **위성 어셈블리 포함**: Self-contained 배포 시 `MyApp.resources.dll` 파일이 각 언어 폴더에 포함되어야 합니다.
- **SingleFile 게시**: `PublishSingleFile` 사용 시 위성 어셈블리가 누락될 수 있으므로 `IncludeAllContentForSelfExtract` 설정 등을 확인합니다.
- **지원 언어 제한**: MSBuild 속성 `<SatelliteResourceLanguages>ko;en</SatelliteResourceLanguages>`로 필요한 언어만 포함할 수 있습니다.

## 문제 해결

| 문제 | 원인 | 해결 |
|------|------|------|
| 문자열이 영어로만 표시됨 | 위성 어셈블리 누락 | 빌드 출력 폴더에 `ko/MyApp.resources.dll` 확인 |
| 언어 전환이 적용 안 됨 | ViewModel에서 `RaisePropertyChanged` 누락 | `LanguageChanged` 이벤트에서 갱신해야 할 속성 모두 호출 |
| 날짜/숫자 포맷이 안 바뀜 | `Thread.CurrentCulture` 미설정 | `SetCulture`에서 함께 설정 |
| MarkupExtension이 갱신 안 됨 | 확장은 초기 한 번만 평가 | ViewModel 경유로 변경 |

## 결론

Avalonia에서 다국어를 지원하려면 `.resx` 기반의 위성 어셈블리를 사용하는 것이 안정적이며, `LocalizationManager`와 이벤트를 통해 실시간 전환을 구현할 수 있습니다. ViewModel에서 `ILocalizer`를 사용해 문자열을 가져오고, 문화권 포맷 도우미로 날짜/숫자를 일관되게 표시합니다. JSON 기반 동적 리소스는 외부 번역 관리나 핫 리로드가 필요할 때 선택적으로 도입하면 됩니다. 이 구조는 DI와 테스트에도 적합하며, 애플리케이션 규모가 커져도 유지보수하기 쉽습니다.
