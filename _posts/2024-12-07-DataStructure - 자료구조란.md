# 자료구조란 무엇인가?

## 자료구조의 정의

**자료구조(Data Structure)**란 컴퓨터가 데이터를 효율적으로 저장하고, 관리하고, 사용할 수 있도록 만든 **데이터의 조직 방식**입니다.  
쉽게 말해, 데이터를 담는 그릇이라고 생각하면 됩니다. 그릇(자료구조)의 모양에 따라서 데이터를 넣고 빼고 찾는 방법이 달라지고, 성능도 크게 차이납니다.

---

## 왜 자료구조를 배워야 할까?

같은 문제라도 어떤 자료구조를 선택하느냐에 따라 프로그램의 속도가 크게 달라집니다.

- **시간**: 적절한 자료구조를 쓰면 몇 시간 걸리던 계산이 1초 만에 끝날 수 있습니다.  
  예를 들어, 100만 개의 데이터에서 특정 값을 찾을 때 배열을 쓰면 최대 100만 번 확인해야 하지만, 해시 테이블을 쓰면 거의 한 번에 찾습니다.
- **메모리**: 데이터를 어떻게 저장하느냐에 따라 메모리 사용량도 달라집니다.
- **확장성**: 데이터가 점점 쌓여도 프로그램이 느려지지 않게 만들 수 있습니다.

---

## 자료구조의 종류

자료구조는 크게 **선형 구조**와 **비선형 구조**로 나눕니다.

### 선형 자료구조

데이터가 일렬로 연결된 모양입니다.

- **배열** - 같은 자료형의 데이터를 빈틈없이 나란히 저장
- **연결 리스트** - 데이터를 줄줄이 연결 (중간에 끼워넣기 쉬움)
- **스택** - 위로 쌓는 구조, 먼저 넣은 게 나중에 나옴
- **큐** - 줄서기, 먼저 온 사람 먼저 처리
- **덱** - 양쪽에서 넣고 뺄 수 있는 큐

### 비선형 자료구조

데이터가 계층이나 복잡한 연결을 이룹니다.

- **트리** - 나무처럼 가지를 뻗는 구조 (폴더 구조, 가계도)
- **그래프** - 점과 선으로 연결된 구조 (지하철 노선도, SNS 친구 관계)
- **해시 테이블** - 키(key)를 이용해 데이터를 빠르게 찾아주는 구조

---

## 자주 쓰이는 자료구조 7가지

### 배열 (Array)

데이터를 **연속된 칸**에 저장합니다. 번호가 적힌 우편함과 같아서 몇 번째 데이터인지 알면 즉시 접근할 수 있습니다.

- **장점**: 인덱스를 이용한 접근이 빠름 $$O(1)$$
- **단점**: 중간에 데이터를 끼워 넣거나 빼려면 뒤의 데이터를 모두 이동시켜야 함 $$O(n)$$

**C++ 예시** (`std::vector`):

```cpp
#include <vector>
#include <iostream>

int main() {
    std::vector<int> arr = {10, 20, 30, 40};
    std::cout << arr[2] << std::endl;      // 30 (즉시 출력)

    arr.insert(arr.begin() + 1, 99);       // [10, 99, 20, 30, 40] (뒤에 것들이 이동)
    return 0;
}
```

---

### 연결 리스트 (Linked List)

데이터를 **화살표**로 연결합니다. 각 데이터는 다음 데이터의 위치를 함께 저장합니다. 보물찾기 쪽지와 비슷합니다.

- **장점**: 중간에 새 데이터를 끼우거나 빼기가 빠름 (위치를 알고 있다면 $$O(1)$$)
- **단점**: n번째 데이터를 찾으려면 첫 번째부터 화살표를 따라 n번 이동해야 함 $$O(n)$$

**C++ 예시** (단일 연결 리스트의 핵심 개념):

```cpp
struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

// A -> B -> C
Node* A = new Node(10);
Node* B = new Node(20);
Node* C = new Node(30);
A->next = B;
B->next = C;
```

---

### 스택 (Stack)

한쪽 끝에서만 데이터를 넣고 빼는 구조입니다. **LIFO(Last In First Out)** 방식입니다. 프링글스 통과 같아서 나중에 넣은 것이 먼저 나옵니다.

- **사용 예**: 웹브라우저 뒤로가기, 실행 취소(Undo)

**C++ 예시** (`std::stack`):

```cpp
#include <stack>
#include <iostream>

int main() {
    std::stack<int> st;
    st.push(1);
    st.push(2);
    int top = st.top();  // 맨 위 값 확인 (2)
    st.pop();            // 맨 위 제거
    std::cout << top << std::endl;  // 2
    return 0;
}
```

---

### 큐 (Queue)

한쪽 끝에서 넣고, 반대쪽 끝에서 빼는 구조입니다. **FIFO(First In First Out)** 방식입니다. 줄서기와 같아서 먼저 온 사람이 먼저 처리됩니다.

- **사용 예**: 프린터 인쇄 대기열, 게임 매칭 대기열

**C++ 예시** (`std::queue`):

```cpp
#include <queue>
#include <iostream>

int main() {
    std::queue<int> q;
    q.push(1);
    q.push(2);
    int first = q.front(); // 맨 앞 확인 (1)
    q.pop();               // 맨 앞 제거
    std::cout << first << std::endl; // 1
    return 0;
}
```

---

### 해시 테이블 (Hash Table)

**키(key)**와 **값(value)**을 한 쌍으로 저장하고, 키를 이용해 값을 빠르게 찾아줍니다. 사전과 같아서 영어 단어(키)를 찾으면 뜻(값)이 바로 나옵니다.

- **장점**: 평균적으로 $$O(1)$$ 시간에 검색, 삽입, 삭제 가능

**C++ 예시** (`std::unordered_map`):

```cpp
#include <unordered_map>
#include <string>
#include <iostream>

int main() {
    std::unordered_map<std::string, std::string> phone;
    phone["Tom"] = "010-1234";
    phone["Jane"] = "010-5678";

    std::cout << phone["Tom"] << std::endl;   // 010-1234 즉시 출력
    return 0;
}
```

---

### 트리 (Tree) - 이진 탐색 트리 (BST)

나무 거꾸로 모양의 계층 구조입니다. 이진 탐색 트리는 **왼쪽 자식은 나보다 작고, 오른쪽 자식은 나보다 크게** 저장합니다. 덕분에 데이터를 찾을 때마다 절반씩 범위를 좁힐 수 있습니다.

- **특징**: 검색, 삽입, 삭제가 $$O(\log n)$$에 가능 (균형 잡힌 경우)

**텍스트 다이어그램 예시**:

```
//      50
//     /  \
//   30   70
//   / \   \
// 20  40  80
```

**C++ 구조체 예시**:

```cpp
struct TreeNode {
    int value;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int val) : value(val), left(nullptr), right(nullptr) {}
};
```

---

### 힙 (Heap) / 우선순위 큐

항상 **가장 큰 값(또는 가장 작은 값)**이 맨 위에 오도록 정렬된 트리입니다. 응급실과 같아서 위급한 환자(우선순위 높은)가 먼저 치료받습니다.

- **사용 예**: 운영체제의 작업 스케줄링, 다익스트라 최단경로 알고리즘

**C++ 예시** (`std::priority_queue`):

```cpp
#include <queue>
#include <iostream>

int main() {
    // 기본은 최대 힙 (큰 값이 top)
    std::priority_queue<int> pq;
    pq.push(5);
    pq.push(1);
    pq.push(3);
    int first = pq.top();  // 가장 큰 값 (5)
    std::cout << first << std::endl;
    return 0;
}

// 최소 힙 (작은 값이 top)을 원한다면:
// std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;
```

### 그래프 (Graph) 간단히

그래프는 **점(vertex)**과 **선(edge)**으로 이루어진 구조입니다. 지하철 노선도, 페이스북 친구 관계 등을 표현할 수 있습니다.

- **탐색 방법**: 
  - **BFS(너비 우선 탐색)** – 큐 사용, 최단 경로 찾기에 적합
  - **DFS(깊이 우선 탐색)** – 스택 또는 재귀 사용, 미로 찾기 등에 적합

**C++ 인접 리스트 표현 예시**:

```cpp
#include <vector>

int main() {
    int n = 5; // 정점 개수
    std::vector<std::vector<int>> graph(n);

    // 간선 추가 (0-1, 1-2, 2-3, 3-4, 4-0)
    graph[0].push_back(1);
    graph[0].push_back(4);
    graph[1].push_back(0);
    graph[1].push_back(2);
    graph[2].push_back(1);
    graph[2].push_back(3);
    graph[3].push_back(2);
    graph[3].push_back(4);
    graph[4].push_back(3);
    graph[4].push_back(0);
    return 0;
}
```

## 자료구조 선택하는 간단한 팁

1. **데이터를 순서대로 저장하고, 중간에 끼워넣거나 삭제할 일이 많다?**  
   → 연결 리스트 (C++에서는 `std::list`)

2. **n번째 데이터를 자주 조회한다?**  
   → 배열 (C++에서는 `std::vector`)

3. **데이터를 넣은 순서의 반대로 꺼낸다?**  
   → 스택 (`std::stack`)

4. **먼저 넣은 데이터를 먼저 처리한다?**  
   → 큐 (`std::queue`)

5. **키를 이용해 값을 아주 빠르게 찾아야 한다?**  
   → 해시 테이블 (`std::unordered_map`)

6. **항상 가장 작은(또는 큰) 값을 빠르게 꺼내야 한다?**  
   → 힙 (`std::priority_queue`)

7. **데이터를 정렬된 상태로 유지하면서 빠르게 검색/삽입/삭제해야 한다?**  
   → 이진 탐색 트리 (`std::set` 또는 `std::map`이 균형 트리로 구현됨)

## 초보자를 위한 학습 로드맵

1. **배열, 연결 리스트** – 가장 기본, 메모리 동작 이해
2. **스택, 큐** – 일상적인 예제로 감각 익히기
3. **해시 테이블** – 키-값 저장의 편리함 체험
4. **트리 (이진 탐색 트리, 힙)** – 비선형 구조 입문
5. **그래프** – BFS/DFS로 탐색 맛보기
6. **고급** – 균형 트리, 세그먼트 트리, 유니온 파인드 등 (필요할 때 학습)

## 자주 쓰는 연산의 시간 복잡도 (간단 버전)

| 자료구조               | 접근 (읽기) | 검색      | 삽입               | 삭제               | 비고                          |
|------------------------|-------------|-----------|--------------------|--------------------|-------------------------------|
| 배열 (`vector`)        | $$O(1)$$    | $$O(n)$$  | 끝: $$O(1)$$ (평균), 중간: $$O(n)$$ | 중간: $$O(n)$$ | 인덱스로 바로 접근 가능       |
| 연결 리스트 (`list`)   | $$O(n)$$    | $$O(n)$$  | 앞/뒤: $$O(1)$$ (위치 알면) | 앞/뒤: $$O(1)$$ (위치 알면) | 임의 접근 느림                |
| 스택/큐                | -           | -         | $$O(1)$$           | $$O(1)$$           | 맨 위/앞만 접근                |
| 해시 테이블 (`unordered_map`)| -     | 평균 $$O(1)$$ | 평균 $$O(1)$$      | 평균 $$O(1)$$      | 최악의 경우 $$O(n)$$ 가능      |
| 이진 탐색 트리 (`set`/`map`)| $$O(\log n)$$ | $$O(\log n)$$ | $$O(\log n)$$      | $$O(\log n)$$      | 균형 유지 (레드-블랙 트리)     |
| 힙 (`priority_queue`)  | -           | -         | $$O(\log n)$$      | $$O(\log n)$$      | 최대/최소값 조회 $$O(1)$$     |

> $$O(1)$$: 데이터 개수와 상관없이 항상 같은 시간  
> $$O(\log n)$$: 데이터가 2배 늘어나도 1번만 더 확인하면 됨  
> $$O(n)$$: 데이터 수에 비례해서 시간 증가

## 마무리

자료구조는 단순히 이론이 아니라, 실제 프로그램의 성능을 좌우하는 핵심 도구입니다.  
모든 것을 한 번에 외우려고 하지 말고, 하나씩 익히며 **"이 상황에서 왜 이 자료구조를 쓰면 좋을까?"** 를 생각해보세요.

C++에서는 표준 라이브러리가 이미 많은 자료구조를 효율적이고 안전하게 구현해 놓았습니다. 각 자료구조의 특징과 시간 복잡도를 이해하고 적절히 활용하는 것이 중요합니다.
